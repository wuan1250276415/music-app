# ADR-197：选定发行版的在线封面来源查询

日期：2026-10-12。源码 0.191.0；最新内部试用安装包仍为 0.190.0。本次推进 FR06／WP08，完整范围 FR01–14／WP01–11／G1–5／AC01–19 不缩减。仅 ASIO 实机验证暂停。

## 问题和结果

已有封面服务优先读取音乐文件内嵌正面图片，其次其他内嵌图片，再回退同目录封面。用户提供的《晴天》FLAC 实际没有图片元数据，不能凭空获得内嵌封面。此前 Cover Art Archive（CAA）虽登记为数据源，但没有注册查询能力，候选审核也没有封面来源入口。

本次增加 CAA 发行版 JSON 索引查询、候选关联校验和来源文字面板。用户在 MusicBrainz 候选中选择具体发行版后，可以查询其正面、背面和其他图片条目的整理信息，并主动打开对应来源网页。默认关闭 CAA；启用和暂停继续使用已有设置版本、命令回执和审计。

**本次实现的是来源条目查询，尚未实现在线图片下载、显示、持久缓存、导出或应用为曲库封面。** 不改写本地图片引用的 embedded／sidecar 类型，也不把在线图片伪装成旁置封面。CAA 社区编辑确认状态不是图片使用许可；接口返回的图片地址不会传给界面或发起图片请求。

## 查询与生命周期

1. 界面提交本地曲目 ID、候选 token、审核资料指纹、独立请求 ID 和可选跳过缓存标志，不提交远程 URL 或自行指定发行编号。
2. Library Service 解析仍有效且属于该曲目的 MusicBrainz 候选；检查元数据查询和 CAA 均已启用，且资料指纹仍匹配。
3. 适配器以候选发行 MBID 请求 `https://coverartarchive.org/release/{id}/`。查询只发送发行编号和公开应用标识，不发送文件路径、完整音频或本地资料指纹。
4. 返回后再次检查取消信号、数据源设置、原候选对象和曲目资料指纹。过期、取消或资料变化时丢弃迟到结果。返回预览期限取索引与候选期限较早值。
5. 切换候选、关闭面板、修改曲库、暂停来源或关闭在线查询时取消相关工作。全局清缓存、维护和退出沿用原网络调度的取消／排空机制。仅切换 CAA 设置不会作废已有 MusicBrainz 候选。

界面独立校验返回曲目、token、指纹和发行编号；过期预览隐藏。文字由 React 转义展示，来源网页仅用户点击时打开。Main 来源网址白名单扩展到合法 MusicBrainz 发行版的 `/cover-art`，拒绝假域名、查询后缀及任意跳转地址。

## 网络边界

CAA 官方接口用 307 将发行索引定位到 Internet Archive，本轮真实请求进一步观察到 302 到 Archive 存储节点。统一调度增加按能力配置的有限手动跳转，MusicBrainz 能力仍不允许跳转。

- 最多 3 跳，必须 HTTPS，禁止凭据、额外端口、片段、查询参数和循环地址。
- 仅接受同一 MBID 的 `archive.org/download/mbid-{id}/index.json`，或 Archive 子域下 `/{number}/items/mbid-{id}/index.json`。禁止其他实体、图片路径及非 Archive 域名。
- 跨主机只保留 Accept 和公开 User-Agent；不转发 Cookie 或 Authorization。每一跳继续受调度间隔、取消和单次／总期限约束。
- CAA 每个请求至少间隔 1100ms；单次尝试最多 18 秒，总期限 45 秒，最多 3 次尝试和 16 项等待。沿用 429／临时服务错误退避。
- 响应最多 2,000,000 字节，校验内容类型和 JSON；最多 256 条图片索引、每条 16 种类型，限制文字长度，拒绝重复／不安全数值 ID 和不属于当前发行版的索引。
- 404 作为未找到索引，不做负缓存；正常预览仅短期内存缓存，最多 60 秒，并尊重服务端禁止缓存指令。候选审核上限 10 分钟，清除／维护时作废。

这些权限仅针对文字索引预览。返回单独的 indexRights 和 imageRights，在线图片操作均为未核实／不可用。现有 provider 持久设置和备份结构未改变，schema73／音频 IPC1.23／媒体14 保持；provider 备份组件版本仍为 1，不新增持久在线图片记录。
