# ADR-029：人工录音/发行曲目关联、专辑概念与曲库 v7

状态：已实现开发版，2026-09-30。对应架构 §7–8、FR04/05、WP03/05；完整架构目标继续保留。

## 用户行为与身份范围

曲目右侧“⇄”和播放详情“整理关联”打开人工确认窗口。用户搜索另一曲目，核对歌名、艺人、发行日期、音质、时长和路径后，选择以下一种关系：

- 同一录音：多个文件共享一个确认 Recording，各自的具体发行版与发行曲目仍独立。
- 同一发行曲目的文件版本：共享确认 Recording 和 ReleaseTrack，具体文件、PlayableItem、播放范围、收藏、评分和歌单 entry 都保留。
- 同一专辑概念：至少两个具体发行版关联到 ReleaseGroup，发行版本身保留，按“专辑概念”视图聚合浏览。
- 恢复本地候选：只解除所选文件的人工身份关联，返回该文件最新的扫描候选；其他版本继续保留自己的确认关系。

这是人工确认，不是自动相似度合并，也不修改音乐文件。每次关联和恢复都生成持久修订；修订记录支持分页、重启后查看和撤销。源文件的标签、音频和可播放版本不因关联被删除。

## 扫描候选与确认快照

v6 的每个文件仍有独立录音/发行曲目候选。确认时从目标复制不可变的 Recording、ReleaseTrack 与署名快照，再通过 item_catalog_binding 关联具体 PlayableItem。不同发行版可有不同的确认 ReleaseTrack，同时共享 Recording。

扫描按 local_key 更新该文件的候选，不更新确认快照；人工绑定在扫描、元数据确认/撤销和重启后持续生效。文件标签发生变化时仍保留其观察值，曲库修订递增，用户可以重新审核或恢复候选。详情和专辑行使用关联的发行名称；文件标签本身仍独立保留。在线外部 ID 认证、来源决策和艺人身份合并未因本次本地关系实现而完成。

## 持久性与撤销

v7 新增 item_catalog_binding、item_catalog_state 和 catalog_change。绑定使用显式 FK，ReleaseTrack/Recording 组合另有复合 FK，阻止结构上相互矛盾的关系。状态保存有效关系与展示事实的指纹，重扫无变化时修订不递增；标签/身份/专辑概念变化触发修订。

命令 UUID、参数指纹和结果复用持久回执，与关联、搜索索引和审计一起在单写事务提交。相同命令跨重启重放先于再次读取当前对象；不同参数复用 ID 拒绝。客户端参数字段顺序不改变命令身份。每次最多选择 100 个文件，超过容量明确拒绝。

修订保存 before/after 的绑定、发行概念关系、修订号，以及当时的歌名/艺人/专辑/路径与实体 ID。撤销先检查全部参与项和发行版的后续修订及当前绑定；发现后续修改拒绝直接撤销。成功撤销生成新审计并标记原修订；复用撤销命令仍只执行一次。实体快照不在撤销时物理删除，避免破坏其他版本与审计引用。后续需制定审计与孤立快照的归档策略。

v6→v7 在 DDL/回填前生成一致 pre-v7 备份，版本推进与回填在事务内执行。迁移失败回滚新表和索引；候选 ID、收藏、评分和歌单保留。0.23.0 无法直接打开 v7，回退需要迁移前一致备份，后续修订不在旧快照中。

## 版本展示与播放

可选“折叠文件版本”只按已共享的 ReleaseTrack 折叠，不按曲名或 Recording 折叠。先执行搜索/角色/收藏等过滤，再选代表项与分页；优先当前可用文件，其次稳定 ID。歌单视图始终保留独立重复条目。

版本选择分页列出实际文件及源音质，并禁用不可用文件。用户选定版本后创建当前已加载视图的播放上下文，同一发行曲目的其他编码文件不再重复入队；保留其他曲目。当前视图播放上下文仍受已有 50 条加载页和队列上限约束，更大库的完整上下文/键集分页属于后续工作，不能称为已经解决。

## 验证与未完成项

新增测试覆盖跨发行录音关联、确认快照不被重扫覆盖、同一发行曲目多版本、先过滤后折叠、可用代表项、重复歌单保留、绑定复合 FK、撤销/恢复/冲突、参数顺序无关和跨重启回执、专辑概念全体曲目更新，以及 v6→v7 备份与失败回滚。

桌面测试从隔离 v6 升级，确认 MP3/WAV 测试版本，折叠并实际播放指定 WAV，建立/浏览/撤销专辑概念，恢复/撤销文件关联，重启后核对绑定、修订、评分及重复歌单。既有封面、歌词、分类、歌单和 UI 压力回归保留；最终发行版结果见 README 0.24.0。

发行实体整体合并/拆分、艺人身份确认和连接词编辑、外部引用验证、智能歌单、扫描任务恢复、呈现时钟播放历史、十万曲性能、完整 CUE 改写身份对账、更多音频格式及所有硬件/发布门禁仍未完成。本次不将 WP03/05 或整体目标标记为验收完成；ASIO 实机验证继续按用户要求暂停。
