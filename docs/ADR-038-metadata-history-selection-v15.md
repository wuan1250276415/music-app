# ADR-038：单值来源历史与显式选择

状态：0.33.0 源码实现，2026-10-01；schema v15 迁移与运行验收留到 MVP。对应 WP03/WP08，沿用 ADR-037 的来源记录和字段锁。完整 FR01–FR14 目标继续实施。

## 行为与入口

歌曲播放详情、整理关联、在线匹配和艺人管理的“来源与字段锁”入口中，每个单值字段增加“查看历史与选择来源”。页面展示当前值、默认或显式选择状态、授权说明、首次记录时间和可确认的来源链接。保存字段锁草稿后才能进入历史，避免丢失未保存修改。

可以采用某一条历史观察值，恢复最新已记录的本地扫描／候选值，或明确清空非名称字段。指定来源和清空决定会保留，后续扫描继续记录新值而不替换用户选择。恢复自动来源要求先解除锁且已有可用扫描基线，不用“最新首次记录时间”猜测最新扫描值。名称不能为空；可选字段的清空值按已有数据契约保存为空字符串或 NULL，并单独保存用户清空状态。

选定历史来源可以主动修改已锁定字段，锁继续保留；锁防止自动覆盖，不阻止用户确认。人工资料编辑和主动确认新的在线结果会替代旧的显式选择，但保留锁。复制实体时复制已知观察来源、字段锁和选择状态，并复制可确认的自动来源基线；未知来源仍保留未知标识。这里只处理单值字段，署名角色、连接词、有序多值集合与风格仍由各资料编辑入口管理。

## 模型和扫描

schema v15 增加 `metadata_selection`、`metadata_auto_source` 和 `metadata_selection_change`。选择行绑定同实体字段的现有决定；自动来源通过归属触发器绑定同一实体和字段的观察值。升级前使用已有一致备份策略；不根据旧观察记录的创建时间回填自动来源。旧物理文件下次扫描时补读缺少自动来源的标签，未获得基线的字段显示需要重新扫描。

观察值按值、来源与来源引用去重，展示的是不同观察值的历史，不是每次扫描或每次网络请求的事件日志。例如 A→B→A 会再次把自动指针指向 A，即使 A 的首次记录时间早于 B。当前值、显式选择、锁、来源修订和受影响成员共同参加并发校验。新扫描改变自动指针也递增策略修订，不能把更早的预览静默应用到新状态。

录音候选更新分别检查名称、时长和版本的选择／锁。已确认资料仍受保护；用户明确恢复自动来源的单值字段可以重新采用候选，署名和其他确认资料保持原来的管理方式。未确认录音采用单值来源后不伪造整个录音资料“已确认”；播放详情按显式选择状态展示相应版本与时长。

歌曲层通过已有覆盖层保存指定值和明确清空，原始标签仍继续更新。默认文件来源解除锁时，同时恢复最新扫描的值及对应来源记录，避免值更新而来源仍显示旧记录。清空歌曲歌手后不创建空名艺人；清空专辑原文后规范发行候选沿用“未知专辑”的显示回退。

## 命令、预览与撤销

单次命令允许 1–8 个不同字段、最多影响 5000 个文件，必须使用闭合实体／字段集合、合法观察 UUID 和所见实体修订／指纹。观察必须属于当前实体和字段，权限允许展示与保存，且未超过有效期。字段类型、名称、文本大小和发行日期重新校验，不能直接利用旧观察值绕过资料约束。

所有选择和撤销在独占写事务内保存审计与持久回执；相同命令与请求重放返回原结果，不同请求不能复用命令 ID。UI 展示修改前后值，按确认的实体指纹提交。来源历史每页 50 条，使用字段作用域绑定的键集游标；追加页发现实体指纹变化时要求刷新后重新选择。

撤销生成补偿修订，恢复原值、原覆盖层、原锁和原选择模式，修订继续递增，不倒退自动来源指针。当前实现保守检查整个实体及成员状态，存在后续变更时拒绝直接撤销。架构要求的逐字段冲突报告／部分补偿仍待实现，不能将本轮视为完整 AC11 验收。
