# ADR-105：先读取内嵌封面，再读取目录图片；播放详情跟随完善

- 状态：源码与编译检查通过，真实文件及界面留到 MVP
- 版本：0.99.0
- 日期：2026-10-02
- 关联：用户封面及播放详情反馈，FR04／FR10／FR11，WP04／WP05／WP10；延续 ADR-098／101／103

## 问题与实施边界

播放栏封面入口、当前歌曲独立读取、完整专辑图片、歌手／专辑／风格点击检索、逐行歌词跟随／点击定位、随机和循环模式、队列跳转／重排／移出已存在。本批处理这条路径的剩余读取与交互问题，不把这些既有功能全部记为新实现。

原封面服务在启动 worker 或回读持久封面之前调用统一指纹函数，检查音乐文件、目录和最多 18 个常规图片路径。因此即使音乐文件具有可显示的内嵌封面，目录图片属性读取缓慢也会拖延内嵌封面。代码可以确认这条依赖存在；没有取得用户实际文件并复现，不能将它断言为用户缺图的唯一原因。

## 封面读取路径

服务先计算只包含音乐路径与完整整数文件观察的内嵌指纹。在线持久缓存查找必须同时匹配该指纹和 `embedded` 来源。未命中时发出只读取内嵌图片的监督任务；该阶段不枚举、检查或读取同名及目录图片。

仍先选择内嵌正面封面，再选择其他内嵌图片；保留前 64 标签、单图 16 MiB、标签读取 32 MiB、16 次去重转换和尺寸／像素限制。读取后出现标签错误时，已取得的可用内嵌图片仍能返回。没有可用内嵌图片且读取未完成，则返回错误，不能推进目录候选。正常读完但图片缺失、预算内候选被安全拒绝或被资源恢复明确排除，才返回空选择并进入目录阶段。这不保证预算外图片能被发现。

目录阶段单独生成目录及候选指纹，并只允许 `sidecar` 缓存命中；其次发出只读取同名及目录图片的监督任务。每阶段任务各自经过句柄／路径核对及进程退出确认。目录阶段开始前、指纹形成后、worker 返回后以及结果返回前核对音乐观察，避免用旧文件的“没有内嵌图片”判断处理新文件。目录候选仍保留原读取前后观察、授权目录和符号链接限制。

媒体协议升级到 8，缩略图请求增加必填 `artworkSource`；回执图片来源必须与请求阶段一致。媒体客户端类型要求调用方明确选择阶段，服务负责编排先后。请求共享键包含阶段、指纹、曲目观察、尺寸和排除集合；失败与空图片不保存为成功内存缓存。刷新同时清理两个阶段的在途缓存选择。没有新图片且全部阶段正常完成后才清理原选择；故障保留明确标记的 stale／offline 旧缓存。

选择指纹分别使用 `embedded-first-isolated-v5` 与 `sidecar-after-complete-embedded-v5`。旧在线引用重新探测，离线图片可继续读取；规范 JPEG 像素算法仍为 `wic-webp-srgb-jpeg-v3`，无需新增缓存 schema。音频 IPC 1.19／schema v42／系统媒体协议 1 保持。

内嵌图片命中时避免了目录候选 I/O；仍需要音乐路径与授权根核对，不声称全部文件系统 I/O 已硬隔离。没有内嵌图片时会产生两个顺序监督任务，延续原等待／执行预算，不代表两阶段整体延迟已达标。目录阶段仍须读取候选属性，网络目录故障与跨平台继续验收。

## 播放详情交互

歌词跟随状态现在根据当前曲目及歌词来源身份重置。刷新同一曲目的资料或偏好时，即使歌词对象重新构造，也不强制取消用户的手动浏览状态；切换曲目或实际来源时重新跟随。短暂重新加载同一来源不被当成切换来源。

跟随开启且歌词面板可见时，观察歌词视口及当前行的尺寸，合并到一帧重算居中位置，处理暂停期间的窗口缩放及换行变化；关闭面板、手动浏览或切换当前行时释放观察器及待处理帧。滚动仅限歌词容器，尊重减少动态效果设置。

详情队列加入“定位当前曲目”和当前序号；跳转播放或重新打开队列仍定位当前项。同一当前项的队列修订不再强制拉回滚动位置，重排／移出时保留浏览；手动定位按钮可以随时返回。既有封面、循环／随机、歌曲信息检索与歌词／队列切换继续保留。

## 编译证据与 MVP 检查

Main／Renderer 类型检查、Main／界面构建（106 模块）、全部原生组件编译、发行／分发清单一致性及 41 个 CommonJS 源文件语法检查通过。Renderer 主块 374.90 kB／gzip 118.19 kB。只维护既有封面回归 helper 的分阶段调用，并将无封面场景的损坏 RIFF 替换为完整 PCM WAV；没有新增或执行测试。

MVP 验证：

- FLAC／WAV-ID3／MP3／DSF 与 CUE 源文件有内嵌正面、其他图片及目录封面时的优先级；无内嵌、损坏标签、候选预算拒绝及转换器故障。
- 可读取音乐但目录图片慢／不可访问时，内嵌阶段无需等待目录候选；两阶段等待、取消／退出监督与真实 NAS 延迟。
- 旧在线引用重探测、离线回读、资源恢复排除、两个尺寸、重复请求和内嵌判断后的文件变化。
- 点击播放栏封面进入歌词页，检索歌手／专辑／风格，切歌与列表外资料，歌词偏移／点击定位／手动浏览／刷新／缩放／隐藏面板与减少动态效果。
- 随机／顺序／单曲和列表循环、队列重排／移出／定位、重复歌曲条目、缩略图资源租约与可视化。

没有执行应用、图片解码、音频播放、SQL／迁移、Provider、安装器或 gold EXE。本批没有新安装包，最新已验证安装包仍是 0.29.0；源码更新不会自动更新已安装程序。完整架构研发继续，仅 ASIO 实机验证搁置。
