# ADR-200：录音发行版分页与生产封面保存流程 MVP

日期：2026-10-13；源码0.194.0；schema74；媒体协议15；音频IPC1.23。完整V1未完成，仅ASIO实机验证暂停。

## 结果与用户操作

匹配结果中的单个录音可能关联多个地区、介质和再版。初始搜索仍显示有限摘要；增加主动“查看其他发行版”，按页显示专辑、地区、介质、日期、版本说明、状态和条码。用户明确选择发行版后，再查询该版本的封面来源。仅选择候选或浏览分页不会保存资料或图片。

修复保存封面后候选面板被通用曲库刷新清空，以及无关后台扫描取消当前查询的问题。封面修改按曲目刷新图片并关闭已保存的临时预览，保留当前候选和来源索引；其他曲库通知重新核对当前歌曲的资料修订与指纹。资料实际变化时仍拒绝旧候选和图片，要求重新匹配。数据源启用状态改为读取独立开关，避免为显示封面查询按钮而等待整份凭据列表。

原有本地内嵌／同目录封面优先、在线补缺、明确首选／清除／最新修改撤销、离线资产和权利限制保持。没有为缺图发行版自动替换其他版本图片。

## 查询与有效性边界

新增窄IPC：provider:enabled、metadata:review-state、metadata:editions。发行版请求只接受当前曲目、候选令牌、资料指纹、请求UUID及可选分页令牌／刷新选项。Main核对调用者与请求结构，Service在请求前后核对当前歌曲、候选归属、网络状态和指纹；失败或取消撤销该请求产生的候选和分页令牌。

MusicBrainz通过 recording-linked release browse 查询，单页25条、附带media。分页按实际返回条数推进offset，不按请求limit固定增加；MusicBrainz的发行查询受每页曲目预算影响，可能返回不足limit的发行版，参见[MusicBrainz API Browse](https://musicbrainz.org/doc/MusicBrainz_API#Browse)。生产查询复用原受控代理、公开联系标识、缓存／期限／取消和至少1100ms的请求间隔。

页返回数、总数、offset、发行ID唯一性与介质数量均受限。分页令牌是不透明UUID，绑定曲目、录音、offset、期限和签发请求，上限128；候选上限400。每页生成当前曲目所属候选，期限不超过原候选、页和游标期限。切换发行版清空上一发行版的艺人署名详情，避免把旧发行的署名归给新版。界面保留当前页、有限分页历史和最多40条候选；不预取全部发行版，不自动联网。

临时预览的通用曲库通知按其歌曲指纹重新核对；未变化的预览保留，变化或查询失败的预览释放。窗口退出／文档切换、网络暂停、维护及到期仍按原规则清理。保存仍经过Main内部资源与Service候选验证，Renderer不能提供外部图片地址或字节作为保存权限。
