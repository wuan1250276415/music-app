# ADR-217：批量指纹关联与逐首录音审核 MVP

状态：0.210.0源码集中MVP通过，完整V1未完成。2026-10-15。

对应架构FR06、WP08及AC10／11中的批量审核、来源约束和取消。本轮将0.209独立单曲指纹加入既有1–100首批量审核会话，保持识别、录音资料读取、发行版选择、字段保存、身份关联和文件写回的独立确认。没有扩大为自动绑定或只看排序的自动覆盖。

Find与Choice闭合请求新增可选reviewToken；独立单曲原请求形状保持。Library用MusicBrainz私有批量缓存核对范围成员、存活和截止时间，拒绝客户端给出的候选、音频路径或原始指纹。AcoustID关联私有Grant绑定批量令牌与当前歌曲来源／元数据快照，取短于父审核和远程确认期的期限。Choice必须提供与Grant完全一致的范围，省略、伪造、转到另一批次或范围外曲目均失败；Renderer返回对象修改不扩大授权。

独立识别仍四份；批量最多四个有存活关联的范围、每范围最多100首、每首一份关联，全体Grant序列化16MiB上限。真正的父批量缓存也限制四会话／100首；新增路径不会通过伪造容量绕过。识别成功后只替换当前行旧Grant，容量或响应失败不会暗中逐出已完成行。每份响应仍走既有固定HTTPS只读POST、400ms间隔、正文／回应预算、超时取消及内存缓存，不上传音频或路径、不贡献数据。源文件读取和真实解码时长／当前CUE边界仍由既有有界原生进程完成。没有新原生算法或输出后端行为。

Find完成时将当前行来源／资料观察纳入批量缓存，尚未选录音也能在曲库变化时报告该行失效。明确选中关联录音才从MusicBrainz读取资料，前后实际检查来源文件与资料修订；MusicBrainz候选保留到同一范围，避开普通400条候选淘汰。派生发行版与署名沿用批量范围。关闭范围会取消标记为该范围的所有在途Find／Choice及普通Match，释放AcoustID Grant并关闭MusicBrainz审核；晚回应不能获得存活范围或保存候选。维护与来源暂停沿用统一失效路径。

批量界面增加“按音频识别剩余歌曲”及逐行识别、取样／曲目时长、关联分页（每页20录音）、明确录音读取和关闭当前关联。一次处理一首，显示本次尝试进度，失败定位到行；取消当前请求后已完成的行保留，继续只查尚无存活关联或资料候选的行。可以直接改用普通标题／已确认录音／编码，重新查询只清空当前行的选择。没有自动勾选候选、发行版、字段或本地身份。来源变更只清空对应草稿行，其他选择保持；AcoustID设置／密钥变化清空所属预览。关闭或重启后关联需重新识别，界面有明确说明。

审核保存沿用schema75文本计划及命令回执，不新增持久原始指纹或关联数据库。逐首选定的MusicBrainz资料与公共领域的AcoustID／MusicBrainz标识映射、本地算法、字段来源及确认期限随计划持久保存；在预览关闭后可独立离线执行或补偿，录音及发行身份不自动建立。原数据库、媒体16和音频IPC1.23不变，不承诺旧二进制直接共享当前数据库的降级兼容。

集中数据／原生MVP15项：实际受监督扫描WAV／CUE的八个可播放项、生产Native读取、八份关联／首末可选而未自动读取MusicBrainz、闭合读者／越界范围在传输前拒绝、跨批次与省略范围拒绝、明确读取后的批量候选跨普通400条淘汰仍可用、两首计划公共映射／离线执行／补偿、范围关闭清理、成功重识别局部替换、在途关闭取消晚回应、父期限过期及来源变化、100行关联容量、第五范围及第五单曲拒绝、16MiB实际大回应超限不逐出完成项、SQLite完整性和音频摘要保持。100行容量用明确合成曲目身份／来源回调与实际Native生成的摘要，只证明缓存／来源契约容量，不是100首独立音频扫描性能或真实识别准确率。

实际Windows凭据／Main／preload／Service／Electron10项：隔离曲库八首、真实本地CUE指纹、第二首在途回应取消、首行保留及七首继续、八行16关联而未自动读录音、两行明确录音／候选／歌名选择、另一行录音来源变化使该行失效且同行选择保持、保存两首计划、断网实际执行及撤销、伪造／省略批量范围拒绝、实际关闭在途Service查询和晚回应丢弃、媒体离线重启保持补偿与公共标识／算法。使用独立测试范围假密钥，结束移除该范围client-key及aural command-key；未读取或写入用户凭据。源音乐由测试产生，摘要保持；没有修改用户原始曲库或音乐。截图已检查。

原单曲Native18项（包括官方独立fpcalc字节对照）、单曲桌面9项、批量审核26项和原有完整桌面组合81项回归通过；最终构建、类型、发行生成／清单检查通过。原生源码／构建配方及二进制在0.209检查点覆盖的字节全部一致，本轮复用这些二进制，不宣称新原生编译。首次构建发现主题色ink-secondary不在正式色表，改用既有ink-muted；首次新桌面测试使用了错误凭据请求字段，改为实际slot／operation契约后10项通过。失败证据保留，后续集中检查全部针对最终源码。

本轮不是完整FR06验收：没有真实AcoustID服务匹配真值、300曲全格式真值、100首音频全链路／输出负载压力、长批次过期续审、整库跨页识别或统一持久任务中心。预览暂停／取消和当前会话继续不等于重启后自动恢复后台识别；需要后续持久任务设计和故障矩阵。最新未签名Windows试用包仍0.201.0，本轮没有0.210打包、实际安装升级卸载或新增硬件证据。完整多来源／更多字段、实体关系与合并、完整写回／恢复、规模性能、歌词可视化和发布继续，只有ASIO实机验证按用户要求暂停。
