# ADR-234：备份保留批次、自动清理与新增备份空间检查

日期：2026-10-17。状态：本阶段集中MVP通过；整体架构目标继续。

## 用户行为

备份空间页新增“批量与自动清理”。后端从完整空间清单派生本批固定范围，每批最多100份，保存任务修订、原执行、备份工件、原日志摘要与文件大小。预览只保存范围；用户另行勾选并确认开始。每份沿用既有独立原生核对、明确删除意图、持久化阶段回执、句柄删除与实际正常退出流程。

暂停和取消等待当前文件完整结束，不再开始下一份。异常项保留原操作，可打开逐份记录独立核对，并明确跳过后继续其余项。原始命令、子操作身份及固定范围保存，丢回应或重启不会换身份重复删除。完整成功子操作可以仅根据原回执接纳结果；缺失完整结果必须另行核对。

自动清理默认关闭。用户开启后定期核对，按保留期建立后台批次；启动和设置改变会触发核对，空清单或无法建立范围时显示原因，正常空闲轮询间隔一小时，单批完成后可继续核对下一批。已有未完成批次时不创建另一个批次。重启不会自动继续中断批次。

自动设置绑定曲库来源和恢复激活身份；恢复后的旧设置保留历史但不生效，需重新确认。保留策略和自动设置在删除授权前重新检查；关闭自动设置时，尚未发出删除ACK的操作停止，文件保留。已发出删除授权后的当前文件可能完成，结果按原回执记录。

## 空间限制

默认保留30天、已关联备份空间上限10GiB，0表示不设置逻辑上限。新的暂存操作先核对完整备份清单及当前策略，要求新增来源备份不会超过上限，并检查所在磁盘可用空间及16MiB余量；核对不完整、策略改变、可用空间未知或不足时，不创建执行记录或备份工件。单文件暂存串行，不并行超额预留。

上限统计逻辑文件大小，未关联文件单独显示。外部程序、稀疏／压缩分配、磁盘竞争及写入中途失败仍由原生组件报告；此预检不声称预分配或文件系统事务。降低上限不会删除受保护备份。保留期和恢复约束始终优先，到期备份释放空间后可复用原暂存命令重试。

原清理有未独立核对的中断结果时，该备份在空间清单中归入保护范围，新候选选择也拒绝；独立观察完成前不会由新自动批次绕过。

## 数据与生命周期

schema86新增调度历史、批次、成员及不可变命令回执四张表；范围和子操作身份不可改写，修订单调。当前只允许一个未结束批次，避免多个窗口重复核对相同范围。维护、退出、恢复暂停与系统入口均接入执行排空；恢复暂停构造不会启动定时任务。

整库快照保存新表以及已有逐文件清理日志。十二域恢复检查核对原范围、策略和调度授权、子操作绑定、实际删除退出事实，以及原始开始、取消和明确跳过回执。旧schema83–85保持可读取和保留，当前整库应用仍要求显式迁移，不在暂停恢复阶段自动升级。
