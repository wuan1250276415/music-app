# ADR-201：专辑上下文排序与发行曲目表审核 MVP

日期：2026-10-13；源码0.195.0；schema74；媒体15；音频IPC1.23。完整FR01–14／WP01–11／G1–5／AC01–19继续，仅ASIO实机验证暂停。

## 用户行为

元数据候选按歌名、歌手、专辑及曲长比较排序，显示各项“一致／相近／有差异／信息不足”。专辑名称包含发行版注记时提示继续核对版本，歌名中的现场、混音等版本文字保留。分数为工程排序值，不是正确概率，仍须明确确认发行版和字段。

选定具体发行版后，可主动“读取专辑上下文”，查看专辑艺人、发行组概念、地区／日期／状态／版本说明、条码、唱片公司及目录号、各碟介质和曲目表。当前录音按外部Recording ID标出其碟号／轨号；同一录音多次出现时提示歧义。比较查询时本地专辑的碟数／轨数和当前曲目顺序，数量或顺序不同提示可能缺曲或选错发行版。

该面板只审核，不自动修改录音／发行／曲目身份，也不保存完整曲目表。读取有独立取消按钮；切换候选、暂停网络、离开面板或到期清除结果。新增面板与封面面板使用不同的React key前缀，避免切换发行版时重复或错误复用审核内容。

## 排序与缓存

context-v1使用标题35、艺人25、专辑25、时长10、Provider排序5的权重。规范化复用已有NFKC／繁简转换；文本比较使用受限二元字组。专辑括号中仅已识别的发行／重制注记可参与标题核心比较，现场／混音／不插电等音乐版本不被去除。该比较只提示版本待确认，不认定两个发行身份相同。

时长差在max(2秒,1%)以内视为接近，在max(15秒,10%)以上标为明显差异，中间递减。无本地信息的分项无法比较；本地已知但候选缺失的分项保留权重且不获分，避免缺资料候选因省略分母而排在完整匹配之前。Unknown开头的真实艺人名不当作未知占位值。

Provider缓存保存与歌曲无关的已解析网络结果，排序在获取后按本次本地资料计算。候选令牌同时绑定本次不可变本地比较快照，后续发行分页／署名详情按该快照重新评分，不能套用另一次搜索的专辑信息。

最多召回8个录音及每个录音最多25个关联发行摘要，先比较再保留每录音3个、总体20个候选。避免服务器先排演唱会、正确发行在第25条时被过早裁掉。搜索仍只发送曲名／艺人，没有新增路径或音频上传。发行分页仍可继续明确查看其他版本。召回限制和排序未经真值集校准，不能据此宣称自动匹配准确率。

## 上下文与进程约束

新增metadata:release-context窄IPC，严格接受曲目／候选／资料指纹／请求UUID及可选刷新，不接受cursor或其他字段。Main检查可信调用者，Service在联网前后检查歌曲、候选、网络、资料指纹及本地Release快照。审核指纹补充时长、碟号和轨号，防止这些匹配依据改变后仍沿用旧结果。

Provider仅能查询受控MusicBrainz具体Release路径，使用artist-credits、labels、recordings、release-groups子查询，复用生产代理的公开联系标识、限速、缓存、请求边界和取消。身份、文字、署名、组、唱片公司、介质及曲目数量受限；返回Release ID必须与请求一致，轨ID和介质／轨序不重复。最多64介质、1000条已载入常规轨、2MB响应；非完整曲目表保留已载入数和总数，明确不完整。隐藏前轨／数据轨目前标为尚待审核，不能冒充完整列表，完整解析继续开发。

结果期限不超过原候选和Provider回执期限，不铸造新保存权限。曲目与Recording ID分别保留，发行组不充当具体Release。当前面板未应用或写回标题以外的专辑字段，原资料差异确认与艺人署名审核继续使用原有独立事务。

API形态依据：[MusicBrainz API](https://musicbrainz.org/doc/MusicBrainz_API)、[录音搜索字段](https://musicbrainz.org/doc/MusicBrainz_API/Search/RecordingSearch)。该实现仍遵守一次请求／秒的约束，使用1100ms间隔；本地工程权重来自架构11.2，不是MusicBrainz提供的置信度算法。

## 继续工作

本轮完成排序依据与具体发行曲目表的主动审核，没有完成架构中的全专辑匹配、历史文件ID校验、指纹／ISRC召回、年份／顺序／目录号／条码组合召回、真值集校准、按专辑接受、全部字段来源和批量审核。隐藏前轨／数据轨、超范围和复杂发行仍需扩展。具体发行资料、Recording／ReleaseTrack归属、字段锁与跨实体ChangeSet需要独立审核事务，不能借面板预览静默应用。

多来源、现实有图歌曲完整保存、在线多尺寸／清理／完整恢复、完整写回及权利认证继续。十万真实规模、冷启动／完整内存／八小时、复杂CUE／DSD、可视化、插件／多窗口、macOS／Linux和Windows安装更新门禁仍未完整验收。仅ASIO实机暂停。
