# ADR-122 FLAC 内嵌封面独立读取与播放详情合并布局

日期：2026-10-03  
状态：0.116.0 源码实现；类型、编译和静态发行检查通过，实际歌曲及界面验证留至 MVP。

## 范围与证据

本轮优先处理用户提出的歌曲封面缺失和播放详情需求。已有实现提供播放栏封面入口、歌曲／专辑／歌手／风格信息及实体检索、完整封面、滚动歌词、模式设置和队列操作，本轮修正封面解析依赖并增加同时查看歌词与队列的布局。尚未获得并运行用户缺图歌曲，不能确认该案例的根因或宣称已实机修复。

## 封面读取

原通用解析器需要解析整份标签后返回图片；若较早的文字标签解析失败，后面的 FLAC PICTURE 块可能没有进入图片候选。新增 `flac-artwork.ts` 在现有一次性受监督媒体进程、原只读句柄和授权边界内，按 [RFC 9639 §8.1](https://www.rfc-editor.org/rfc/rfc9639.html#section-8.1) 与 [§8.8](https://www.rfc-editor.org/rfc/rfc9639.html#section-8.8) 检查元数据块链和图片载荷偏移，跳过其他块的内容。图片读取不依赖 Vorbis 文字标签成功解析。

- 仅识别文件开头的标准 `fLaC`；其他容器与带前置标签的 FLAC 保留通用解析器。原有 WAV／DSF／DFF 等格式不添加新能力声明。
- 整个块链须满足文件边界、首个唯一 STREAMINFO、有效终止及存在后续音频载荷；限制 1024 块、32 MiB 元数据、64 图片。每个图片描述只保存偏移、长度和正面标记，不一次性保存全部图片字节。
- MIME 长度最多 1024，描述最多 64 KiB，载荷长度与块末尾一致；URL 图片 `-->` 不取回，最大图片 16 MiB。单张图片逐个读取、内容嗅探和受监督缩略图转换，沿用 16 次转换／去重／拒绝 token 预算。
- 标准 FLAC 正面图片先试；随后通用解析器的正面图片、其他原生图片及其他通用候选。文字解析失败但存在可转换的原生图片时仍可显示；无可用内嵌图且文字解析失败时保留明确错误，不默认为无图并访问目录。
- 文件前后属性与观察、授权目录、图片转换、租约和旧请求隔离沿用现有实现。内嵌指纹算法升为 v6，在线旧选择会重新核对；离线／读取失败时仍按内嵌优先恢复已保存图片。未修改音频文件、数据库结构或元数据。
- 补齐服务 `artworkCandidate` 的完整读取登记，覆盖封面候选获取前后的源句柄与属性核对，避免标签暂存协调仅登记旧 `artwork` 入口。

## 播放详情

播放栏封面继续进入歌词详情，播放列表按钮继续进入队列。已有信息检索、独立详情歌曲查询、切歌更新、封面重读和状态提示保留。

新增第三个“歌词＋列表”标签：宽屏并列显示歌曲信息／封面、歌词和可编辑队列；中等宽度将歌词及队列放在右侧上下独立滚动；窄窗口纵向展示。方向键、Home／End 在三个标签之间循环，并提供对应标签面板关联。合并布局下两个面板都保持可见，队列封面租约与歌词跟随按实际可见状态工作。

歌词区域任意位置的指针按下都暂停跟随，覆盖拖动行文本和滚动条的情况；点击有时间的歌词行完成跳转后恢复跟随。滚轮、触摸和键盘浏览继续暂停跟随，“回到当前歌词”恢复。没有改变播放时钟、文件或队列顺序。

1. 正面 PICTURE 在文字块之前／之后；文字内容损坏但块链完整；前置 ID3、旧注释图片及其他格式。

3. 内嵌无图后目录回退、在线旧缓存重读、离线保存图、重读错误和切歌旧结果隔离。
4. 封面进入详情、歌手／专辑／风格点击检索，三标签键盘操作及宽窄窗口布局。
5. 合并视图歌词自动跟随、拖动／滚动暂停、点击歌词跳转、队列搜索／定位／移动／移除、模式保存。
6. 标签暂存期间封面候选服务读取的停止等待与重新读取。
