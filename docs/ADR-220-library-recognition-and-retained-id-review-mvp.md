# ADR-220：整库跨页识别与持久标识续审 MVP

状态：0.213.0源码集中MVP通过，完整V1未完成。2026-10-15。

对应FR06／WP08及任务进度、来源解释和恢复。新增整库模式，保留原单页后台准备。整库按创建时固定ordinal推进，每页最多100首；每完成一项保存当前位置，页结束释放所属工作页和短期预览，再进入统一四项队列，下一轮可让其他较早排队任务处理。单一实际执行器继续隔离原生指纹读取与播放。后来导入的歌曲不进入旧范围，已保存计划／明确跳过项不被再次认领。

schema78在识别运行记录增加mode与cursor，新增metadata_recognition_mapping。每项仅保存公共领域AcoustID／MusicBrainz标识对、原先获取时间、本地解码算法／采样范围描述以及来源观察、资料和身份上下文摘要。所有读者闭合校验数量、UUID、范围、键集合和32KiB单项预算；不保存原始指纹、远端标题、艺人、时长、排序或凭据。原始指纹仍只进入既有短期Broker查询。原生解码描述来自本地计算，不把外部响应文字混入长期依据。

成功结果先按当前页归属和代次验证再持久保存；完成或分类失败后推进ordinal。单曲失败可继续其他项；鉴权、来源关闭、容量或限流停止，需明确继续。再次启动整库可从头检查，并复用仍对应当前来源的有效映射；失效记录删除后重新读取，不把旧标识自动用于新文件。父页期限接近时释放后重新领取剩余项，避免把已到期预览无限延长。暂停／取消排空当前实际工作，释放本页并保存已完成标识，独立审核计划及其补偿不变。

正常重开释放原页、标为中断并要求用户继续，不自动发送外部请求。已保存映射及cursor保持；继续从未推进的ordinal处理。崩溃发生在映射已保存而cursor未推进时，下一轮会重新检查已有映射和当前来源，无需把旧授权令牌当作恢复凭据。长批次全部处理后仍保持工作清单待审核，不能把“识别结束”当作曲库已经更新。

审核入口领取当前最多100项，保存的映射仅成为待查阅依据。每次读取重新校验当前文件属性、音频范围、资料与录音引用上下文，并在异步文件核对后再次校验；签发归属当前页的新私有预览。重建只展示标识和本地范围，明确提示没有留存远端标题／艺人／排序，不显示伪造的来源排名。用户选择一个录音后才通过MusicBrainz读取其当前资料，仍需选择版本、字段和最终确认；计划不自动绑定录音身份。审核后的独立计划支持离线执行与补偿，未选项继续待审，可明确跳过本页后审核余下项目。

关闭、过期、来源禁用、资料／文件变化继续撤销私有授权；即使长期映射仍在，伪造的页令牌、任意外部录音或已变化的文件不能转用。恢复检查将映射纳入既有background-recognition领域，仍为十一域；旧68–77归档可以识别，但完整应用要求显式升级到78，暂停恢复不静默改写。77→78前保存并核对快照，DDL与版本在同一事务提交。
