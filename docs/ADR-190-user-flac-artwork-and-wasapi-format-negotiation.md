# ADR-190：用户 FLAC 封面复现与 WASAPI 格式协商

日期：2026-10-12。源码 0.184.0；schema 72、音频 IPC 1.23、媒体契约 14 保持。完整架构范围保持，ASIO 实机验证继续搁置。

## 用户文件与封面结论

用户提供《周杰伦 - 03.晴天.flac》。只读检查 FLAC 元数据：STREAMINFO、VORBIS_COMMENT、SEEKTABLE、PADDING，没有 PICTURE 块；九个评论字段中也没有 METADATA_BLOCK_PICTURE 或 COVERART。原目录没有歌曲同名图片或 cover/folder/front 常规候选。该文件本身没有可读取的本地封面，不能把占位图算作读取失败，也不能宣称已从内嵌元数据恢复专辑图片。

隔离测试只复制该文件，未导入整个下载目录或写标签。真实扫描识别《晴天》、周杰伦、叶惠美（环球日版）、44.1 kHz／16 位；真实 Electron 曲库、静音共享播放、播放栏和详情展示无封面的占位状态，详情提供重新读取与歌手检索。输入文件前后 SHA-256 相同。音频原文件不纳入源码分发；测试必须通过环境变量指定已授权文件。测试报告与截图仅保存必要的元数据和显示状态。

无图文件可通过本地同名图片、常规目录封面，或已有的在线数据源审核流程补充。在线来源、保留规则及字段审核保持原行为，不因本轮测试修改用户资料或开启网络设置。有内嵌图片的 MP3／FLAC 与 CUE 仍须维持前封面优先于背封面、目录图片的选择规则。

## WASAPI 的实际失败与修正

MOONRIVER 3 的驱动查询声明支持 PCM16 双声道 44.1／48 kHz。此前原始独占请求 16 位／44.1 kHz，却实际打开设备默认的 24 位／96 kHz，产生转换并被原始格式守卫正确拒绝。定位到固定版本 miniaudio 0.11.25：桌面独占初始化始终读取 AudioEngine_DeviceFormat，而没有先尝试请求的音源格式。

维护一个可复现的本地补丁：先用请求的整数 PCM、采样率及声道布局查询独占支持；明确返回 S_OK 才接受。标准单／双声道允许再试传统 PCM 描述；其他布局不丢弃声道掩码。失败时保留设备默认格式的既有转换路径，真正不支持或原始路径发生转换仍拒绝，不自动改成共享模式。浮点转换路径保留默认设备格式的选择策略。设备初始化失败不等同于成功，仍由实际状态和格式守卫确认。

中间补丁实测暴露结构体填充问题：MA_WAVEFORMATEX 的 sizeof 含两字节填充，而 Windows 描述符固定部分是 18 字节。已修正扩展 cbSize 和设备默认属性的长度校验，避免拒绝合法的 40 字节扩展描述。属性复制有长度上限，初始化诊断限错误／警告、每宿主最多 32 条、单条 1024 字符；原始格式拒绝也记录有限的格式／采样率及转换事实，不记录音源路径或标签。

SOURCE.txt 同时保留上游 SHA-256、修改后头文件 SHA-256、补丁 SHA-256；补丁由已验证的 0.183 原始头文件生成。分发清单校验补丁身份，SBOM 和版权告知明确包含本地修改。许可证选择继续是 MIT No Attribution，不把修改后头文件冒称为未修改上游。

## 有界退出

失败流程正常退出时曾出现晚到的歌词、封面候选请求访问已退出 Library。Main 开始退出时停止向 Renderer 发布可能引发新读取的播放通知，继续保留 Main 的历史／控制观察；原可信 IPC 维护入口、frame 校验、恢复受控读取通道保持。跟踪原 Renderer 请求并纳入既有 1.5 秒收尾，新请求明确拒绝。超时仍不代表工作已排空；没有改变恢复事务、私有维护请求或历史保存的所有权规则。

## 十万条性能结论与后续

原十万条生成任务已实际结束并保存一致 SQLite 备份；没有重复启动入库。数据库约 1.84 GB，合成目录入库约 1539 秒。它加载分页优化前的中间 0.183，查询性能不作为当前代码验收。

随后在同一固定语料和备份上运行最终分页代码的三次诊断：真值、100 首分页详情、多署名／双碟、重开检查完成；风格＋中文词核心 p95 约 2661 ms，超过 200 ms 架构预算；首屏／深页约 9174／12224 ms，单字近全库约 16839 ms。该诊断存在同时进行的构建／音频工作，不是无竞争的正式性能证书，但明确证明十万规模门槛尚未通过。不能用少量精确／错拼请求的快速结果替代此失败，不能更改预算或省略组合筛选请求。下一步需要定位宽召回、目录关联／排序的访问计划，随后在隔离环境按最终源码复测；物理文件扫描、Electron 端到端、冷启动、内存与持续运行仍未验收。

最终运行证据见本轮状态及 validation 记录。本检查点没有新安装包，也没有完整 G1–G5、AC01–AC19 或硬件 bit-perfect 认证声明。
