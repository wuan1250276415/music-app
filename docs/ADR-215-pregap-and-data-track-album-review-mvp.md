# ADR-215：隐藏前轨及数据轨的专辑上下文与来源审核 MVP

状态：0.208.0 源码集中MVP通过；完整V1未完成。2026-10-14。

MusicBrainz返回的介质普通曲目表、pregap和data-tracks属于不同范围。按官方[Medium JSON序列化实现](https://github.com/metabrainz/musicbrainz-server/blob/master/lib/MusicBrainz/Server/WebService/Serializer/JSON/2/Medium.pm)核对：track-count只计算CD-TOC普通音频轨，前轨和数据轨分别返回；[实体Medium实现](https://github.com/metabrainz/musicbrainz-server/blob/master/lib/MusicBrainz/Server/Entity/Medium.pm)区分全部曲目、音频和TOC曲目。本次实现根据其语义独立设计，没有复制上游代码。

内部介质保留普通tracks，新增可选pregap和dataTracks，曲目kind区分audio／pregap／data。保持原MBID、印刷编号、来源位置、标题、时长、曲目和录音各自署名；不以专辑艺人替代曲目署名。前轨必须位置0，普通与数据必须正数；跨整个发行版检查曲目ID唯一，同碟所有类别位置唯一。全部类别合计最多1000条，最多64碟，并继续经过统一Broker的字节预算、限速、期限和取消。空介质／仅数据介质允许展示，但不制造可播放曲目。

完整性要求已加载普通音频数量等于track-count、正数位置由普通与数据全部连续覆盖，且track-offset不为非零；缺条目、位置缺口或部分返回保持不完整。前轨单独计入音频数量，数据另行显示。界面展开介质可看到隐藏前轨、普通轨和数据资料；数据不能被当前录音高亮误作可采用歌曲。完整特殊轨曲目表不再因类别存在而整体判为未审核，现有本地成员对应和身份冲突检查继续。

统一音频曲目访问函数供上下文、发行字段、整专辑匹配和对应使用。推荐及手工浏览只包含音频，隐藏前轨只允许对应本地第0轨，普通条目不能占用前轨。前端禁用错误片段采用按钮；服务端仍从私有来源审核推导可对应曲目，对数据ID和跨类别对应拒绝，不依赖前端禁用。文本保存、多人署名、录音／发行曲目身份和概念关联共享同一个对应权限入口，因此不能通过其他入口将数据录音映射为歌曲。

前轨计划在已接受候选albumContext增加可选trackKind=pregap及真实position=0；闭合读取只允许audio或pregap、类型与位置相符，拒绝data及无类型的0。普通旧绑定不添加新键，历史正数位置与持久请求回执形状保持。身份修订的来源上下文同样保留前轨类型。没有修改SQL结构，schema75、媒体16和音频IPC1.23保持；备份的应用版本准入仍拒绝比读者更新的版本。旧软件直接降级打开新版曲库的兼容尚未验收，不能据此宣称已完成跨版本发布门禁。

集中验证：生产Provider／Broker／解析器／SQLite14项，包含实际来源结构的前轨／普通／数据保留、数据前置物理编号、空及仅数据介质、缺轨／空洞／偏移、跨列表／介质重复、非法对象、统一1000预算、音频页／数据隔离、错误对应拒绝、类型0闭合读取、具体前轨身份来源、离线执行／独立补偿以及schema75备份重开／完整性。数据层音乐文件观察为显式夹具，不是实际扫描证据。

另用隔离生成的3秒WAV和实际外部CUE进行受监督扫描：前1秒为隐藏0，后2秒为普通轨。实际Main／preload／Service／Electron9项覆盖显示／手选、普通行禁止前轨、数据候选排除、可信IPC对伪造ID拒绝、发行身份可审核、字段和范围勾选／持久计划、离线执行／撤销、媒体离线重启和原音频摘要保持。仅fetch边界替换，未注入候选或审核凭据。原桌面组合81项及上下文／整专辑／身份／轨目／概念／署名／批次数据回归通过。最终构建、类型、发行清单通过，最终截图已检查。原生源码及生成ABI头与Git基准逐文件一致，复用0.207已验证编译结果，没有重新编译未改动的原生组件。

首个数据检查使用了错误的测试署名属性，修正为externalId，并修正测试审计表／撤销入口。桌面入口错误地读取Electron运行时版本、对话框名称不符及后台窗口截图超时依次修正；设置测试窗口可见和关闭背景节流后9项通过。原桌面组合首次断言仍匹配旧提示，改为兼容新增“音频”文字后81项通过；保留各失败报告，未将其当作产品验证成功。最终发行资料没有参与新增网络真值／隐藏轨实际发行正确性认证。

最新安装包仍0.201.0，Windows x64未签名；本轮未打包、实际安装升级卸载或新增硬件。用户原音乐和曲库未修改。完整整库批量、多来源／更多字段、指纹、实体合并／关系角色、完整写回／恢复、规模性能及发布继续，仅ASIO实机验证暂停。
