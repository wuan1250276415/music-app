# ADR-103：内嵌封面读取完整性与播放详情队列

- 状态：源码、类型与编译检查通过；实际图片和界面待 MVP
- 版本：0.97.0
- 日期：2026-10-02
- 关联：用户封面／播放详情反馈、FR04／FR10／FR11、WP04／WP05／WP10；延续 ADR-098／101

## 核对与修改

播放栏封面入口、独立歌曲资料、可点击检索的歌手／专辑／风格、完整封面、滚动歌词、顺序／列表循环／单曲循环、随机模式、队列跳转／重排／移出和可视化已在源码中存在。此批继续处理读取与展示缺口，不将所有既有功能重复记为新实现。

封面 worker 原来吞掉音乐标签解析异常，保留已解析图片后继续尝试目录图片。若异常发生在内嵌图片产生之前，就可能将“尚未完整读取”当成“没有内嵌封面”，显示占位或保存低优先级候选。源码可以确认这条失败路径存在，尚未通过用户的实际歌曲复现。

现在仍先尝试已取得的内嵌正面封面及其他内嵌图片；即使后续标签损坏，已经得到并可转换的内嵌图片仍可显示。若没有取得可显示的内嵌图片，且标签读取未完成，则返回可重试错误，不新选目录图片。标签读取完整、内嵌图片缺失／被安全解码拒绝／被用户请求排除时，继续歌曲同名图片和目录常规图片回退。旧图片仍可作为明确标记的 stale／offline 缓存显示，不宣称是新读取结果。

同一原始图片摘要在一次 worker 请求中只尝试转换一次，重复标签不再耗尽 16 次转换预算。原有前 64 个图片标签、16 MiB 单图、32 MiB 标签读取、尺寸／像素、受监督 worker 和转换器错误分类保持；未提供全部图片格式支持，实际文件可能触及这些限制。

选择指纹更新为 `embedded-first-complete-tags-v4`，在线旧引用重新探测，离线资产保留；无需增加图片缓存 schema，像素转换算法保持 `wic-webp-srgb-jpeg-v3`。

播放栏封面点击明确打开歌词面板，避免上次查看队列后再次点击仍停在队列。独立播放列表快捷按钮继续直接打开队列。队列加入 256 像素封面缩略图，仅可见队列面板挂载图片请求，共用原图片队列、缓存、当前文件观察与离屏租约释放；播放器与详情封面保留前台通道。播放详情也接入本批文件管理入口。
