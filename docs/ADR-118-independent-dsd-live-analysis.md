# ADR-118：原始 DSD 的独立实时分析副本

日期：2026-10-03。状态：源码、Main／Renderer 类型与构建、全部生产原生组件及既有金样编译、41 个 CommonJS 语法和发行／分发清单静态检查通过；运行与数值验收集中到 MVP，ASIO 实机验证继续搁置。

承接 [ADR-117](ADR-117-dsd-application-routing-and-lifecycle.md)，对应架构 FR03／FR11、WP02／WP07。Native／DoP 的输出路径只消费原始位流，不将 FFT、解码、JSON、文件读或进程通信放入 ASIO 回调。

## 进程与文件所有权

新增 `dsd-analysis-worker.exe`，由 Main 在原始 DSD 正在播放且可视化启用时启动。该程序以禁用设备 I/O 的 miniaudio 构建方式提供文件辅助类型，只使用既有受控 FFmpeg 解码库和原始 DSD reader，不加载 ASIO 驱动或打开输出设备。进程使用独立只读文件句柄，重新读取真实 DSF／未压缩 DFF 头部，再与已经批准的播放来源、文件绑定、存储布局、有效位数、声道标记及范围逐项核对。它不借用播放文件指针，不消费原始输出环。

分析开关、暂停、切歌、跳转重建、曲尾结束、播放错误和停止会退休旧副本。Main 不重用失败会话的副本，关闭可视化后重新开启可明确重试。旧进程未确认退出时不启动新副本，后续实际退出确认才能解除该限制。释放播放供标签写回等流程使用时，同时等待分析进程退出；无法确认关闭只读句柄时返回失败。分析失败仅发布可视化状态，不停止原始音乐、不更改输出计划、不自动回退 PCM。子进程观察父进程死亡后退出。

## 有界原始窗口与转换策略

共享独立分析协议为版本 1。首条消息包含 Main 构建 ID、nonce、会话、代际、曲目、父进程、路径、批准的来源与位数范围。准备回执必须使用当前 Host 构建 ID 并回传相同来源与范围。每个窗口带唯一 requestId 和连续十进制 sequence，Main 严格核对原请求、来源、代际和数值结构。主播放 IPC 保持 1.22，数据库 schema46 不变。

原始位率限于 DSD64／128／256，源声道 1–16。reader 产生 MSB first、交错字节，不改变位流播放。副本直接使用 FFmpeg `DSD_MSBF` 解码为每八位一个 PCM 样本，再使用同声道布局的 SWR 转为 176400 Hz float，软件增益为 0 dB，不做 ReplayGain 或声道混合。这里不使用现有整曲 DSD seek：整曲转换需要从源起点顺序解码，不能用于每个实时窗口。

固定分析 profile 为 `raw-window-dsd96-swr128-kaiser9-c0.5-preroll8192-v1`，SWR filter_size=128、cutoff=0.5、Kaiser beta=9。每次窗口重置解码／转换实例，在目标前后各读取最多 8192 原始字节帧的上下文；上下文可跨 CUE 轨边界，但不会跨真实文件边界，输出的完整 2048 PCM 分析帧必须全部落在当前批准轨范围内。源尾不足一个完整 PCM 采样单元的位不用于分析；不补零凑 FFT，也不把转换内部滤波延拓称为真实源样本。此 profile 与整曲转换 profile 分开，有限预热与延迟对齐尚未数值认证。

峰值／RMS、2048 点 Hann FFT、64 对数频带和 64 组波形 min/max 使用分析类的纯窗口函数。非有限值清零、过大浮点值限幅并计数，仅在分析副本处理。回调的原有 PCM ring／worker 行为不变。

## 时钟、新鲜度与预算

Main 使用原始播放位置位数作为锚点，在最多 500 ms 内按单调时间外推。使用整数比率 bitRate/176400 计算源绝对 PCM 窗口；完整窗口必须在轨内，nominal PCM frame 与原始位数映射写入分析证据。它是播放锚点估算，既不是声卡采样捕获，也不是 DAC 实际声输出测量；滤波群延迟补偿仍为 pending。显示时钟和歌词继续使用原始播放时钟。

Main 同时只允许一个窗口请求，无积压队列；结果之后至少间隔 50 ms，准备期限 8 秒，单窗口期限 2 秒，退出观察 2.5 秒、文件释放等待上限 3 秒。结果的显示新鲜度从原请求发出时计算，超过 500 ms 的窗口丢弃；锚点过期时显示等待新时钟。输入单帧最多 64 KiB，输出单帧最多 16 KiB，标准输出每秒 256 KiB、诊断总计 16 KiB。原始 reader 单次 4096 字节帧，转换输出上限 32768 PCM 帧 × 16 声道，FFT 固定大小；codec 配置单解码线程，既有 FFmpeg 单次分配限制 32 MiB。后台进程仍可能消耗磁盘与 CPU，是否增加播放欠载必须到 MVP 实测，不能由隔离设计推断通过。

## 界面与后续验收

播放详情中的频谱／实时波形可请求 DSD 分析副本；明确展示副本说明、预热／等待时钟／失败状态。返回帧使用 `independent-dsd-pcm-copy` 和单独 `dsdCopy` 证据；PCM 仍使用 `callback-pcm-before-device`。Renderer 不接触路径、文件句柄或解码数据，只绘制有界数组。频谱不能作为设备输出、DSD 数值一致性或 bit-perfect 证明。

MVP 集中验收：DSF LSB／MSB 和未压缩 DFF、三档位率与多声道的窗口信号；与整曲转换比较有限预热的稳定区域、滤波延迟、增益和频带；CUE 起止非整 PCM 边界、短轨不足 2048 帧、文件尾部分位；长曲随机位置；暂停／继续／跳转／切歌／关闭可视化／隐藏窗口后无陈旧结果；缺失 DLL／程序、损坏文件、进程超时、输出洪泛、父进程退出和旧进程退出未知；标签写回前副本文件释放；播放开启分析前后的 CPU、磁盘、欠载和延迟。ASIO 实机验证仍按用户要求搁置，不因本批源码完成而改变。

原始 CUE 双轨直通／无缝、其余架构工作包与 G1–G5／AC01–AC19 不由本 ADR 宣告完成。封面优先嵌入图片与播放详情入口沿用 ADR-114，真实缺失封面复现与界面验收仍需 MVP。
