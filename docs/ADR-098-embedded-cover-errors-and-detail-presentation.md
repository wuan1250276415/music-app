# ADR-098：内嵌封面失败处理与播放详情展示

- 状态：源码实现、类型与编译检查通过；真实文件和桌面交互待 MVP
- 源码版本：0.93.0
- 日期：2026-10-02
- 关联：用户封面／播放详情反馈；FR04、FR10、FR11；WP04、WP05、WP10

## 问题与已有基础

用户要求优先显示歌曲元数据中的专辑封面，并通过播放栏封面进入歌曲资料、可检索的歌手／专辑／风格、滚动歌词、播放模式与播放列表。

0.85 的独立歌曲读取、受控封面资源／租约、内嵌优先顺序、详情入口、实体检索、同步歌词与队列已经在源码中实现。这次继续完善这些路径，没有把已有功能重复声明为新实现，也没有通过用户的实际歌曲复现“封面没有显示”。最新已验证安装包仍是 0.29.0；开发源码不会自动更新用户已安装的程序。

源码核对发现，图片转换的所有失败都会被当成候选不可用，进而尝试其他内嵌图片或目录封面。转换组件启动、管道、回执或编码失败因此可能被吞掉，表现为普通占位图或低优先级封面。共享 `ArtworkCache` 并不保存空结果／失败；但已经显示“未找到”的可见组件要获得新的请求上下文才会重读。这两个问题必须区分。

## 决策与实现

1. 保持来源顺序：内嵌正面图片、其他内嵌图片、歌曲同名本地图片、目录常规封面。扫描仍跳过图片，封面按需单独读取，避免扫描期间扩大图片内存占用。CUE 仍通过对应音频文件的元数据取封面。
2. 遵循原生转换器已有退出约定：82 表示图片解码／格式／颜色或尺寸预算拒绝，可以回退到下一候选；启动失败、管道错误、异常退出、编码失败和无效回执作为读取失败向上传递。本地图片的文件异常仍允许继续寻找其他本地候选，但图片转换移到该文件异常捕获范围外。82 内部尚未进一步区分每一种 WIC 失败，不能宣称完整的故障分类。
3. `artworkFingerprint` 加入 `embedded-first-errors-v2` 选择策略标识。在线请求会重新检查旧策略保存的引用，让旧选择重新遵循新的失败分类；离线时仍可显示已保存图片。旧实现本身已有本地图片引用的有效期，并非永久缓存。无需 schema 迁移，也不清空全部图片资产。像素转换算法仍为 `wic-webp-srgb-jpeg-v3`。
4. 可见封面请求键包含条目 ID，并使用 JSON 编码上下文。相同源文件的不同 CUE 条目不再直接共用 Renderer 的授权身份；库服务仍按文件身份合并读取。原有当前候选重注册、排除预算与文档租约保护保留。
5. 详情封面使用 `object-fit: contain`，完整显示长方形图片；小缩略图仍保留裁切。封面下显示来源／缓存／错误状态及独立“重新读取封面”按钮；该按钮强制重新探测原文件，不触发歌词读取。顶部保留同时重读封面与歌词，歌词刷新不等待封面成功。切歌后的旧刷新结果不能发布当前歌曲提示。
6. 抽出 `SongInformation`。歌手、专辑、风格、音质、时长直接展示；详细署名、发行资料、录音信息和文件信息放在“更多歌曲资料”。所有原有实体 ID／角色链接保留，没有实体时按标签名称检索。选择链接后退出详情，并将焦点移到曲库检索框。
7. CUE、解码、播放时钟、尾部、处理与输出计划放在“播放与音频信息”中。实时可视化与整曲波形保留；主面板继续展示跟随滚动／点击跳转歌词、歌词来源设置、随机、顺序／列表循环／单曲循环及队列跳转／重排／移出。
8. 播放栏新增播放列表快捷按钮，可直接打开详情中的队列面板。进入详情时关闭普通浮动面板与窄屏导航，但保留正在进行的元数据变更及其审核状态。既有关闭／Escape／回到封面按钮焦点的行为保留。

## 验证与研发计划

类型检查、Main 构建、Renderer 构建（100 模块）、全部原生组件编译、发行／分发清单静态检查及 41 个 CommonJS 文件语法检查通过。原生 gold 程序仅编译，没有执行。现有 catalog 桌面验收脚本增加展开更多资料的步骤，以适配可折叠信息；没有新增单元测试，也没有运行该脚本。

MVP 应使用带内嵌图片的 FLAC、WAV／ID3、MP3、DSF 与 CUE 源文件，对照目录图片验证正面优先；覆盖原生转换器失联、82 拒绝、编码失败、旧引用重探测、离线缓存、图片回收与租约、快速切歌和手动重读。还需检查长方形图片、小窗口／缩放、实体检索和焦点、歌词滚动／seek、播放模式、队列快捷入口／编辑及应用实际渲染。

数据库 schema v39、音频 IPC 1.19、媒体协议 6、系统媒体协议 1 保持。没有运行音乐、图片解码、应用、数据库／迁移、Provider 网络、安装器或音频设备。本批不能证明用户实际文件的问题已解决，也不作为 G1–G5／AC01–AC19 验收。按既有计划继续完整架构研发，只有 ASIO 实机验证搁置。
