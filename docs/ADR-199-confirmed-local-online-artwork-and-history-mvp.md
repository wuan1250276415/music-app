# ADR-199：在线封面明确保存、本机选择与修改记录 MVP

日期：2026-10-12；源码0.193.0；schema74；媒体协议15；音频IPC1.23。完整V1未完成，仅ASIO实机验证暂停。

## 决定和用户行为

在已有选定图片临时预览之后增加明确保存。数据源仍默认关闭，来源保存设置仍默认只预览。允许本机保存后，用户选择“确认保存这张封面”，默认作为补缺：文件内嵌图片、同目录图片、已保存在线图片依次选择。用户可明确设为首选，随后切回补缺、清除当前选择或撤销最新修改。列表、播放栏和详情收到修改通知后刷新图片。

保存不修改音乐文件。详情显示来源、图片编号、使用顺序和最近30条修改记录；新程序进程和文件离线时，曲库内图片仍可显示。暂停网络或新图片保存不会阻止使用、调整、清除和撤销已保存图片。

CAA图片的授权状态保持unverified；本机用户选择记录不是CC0或其他开放许可认证，不开放图片导出或文件写回。来源设置允许保存明确选定的本机图片，逐图片记录仍保留来源和权利限制。CAA公共访问与版权须分别理解，参见[CAA说明](https://musicbrainz.org/doc/Cover_Art_Archive)及[MusicBrainz版权与DMCA说明](https://musicbrainz.org/doc/Copyright_and_DMCA_Compliance)。其他Provider与MusicBrainz资料留存规则保持。

## 数据与进程边界

Renderer只能提交命令UUID、曲目ID、基准修订及Main签发的内部预览地址，不能提交图片字节或外部图片地址。Main先核对命令回执，再从当前所属预览提取图像及来源。Library Service重新核对有效候选、曲目资料指纹、发行版和当前来源／网络状态，Repository核对留存设置与图片边界，原子保存图片、来源、选择、修改及命令回执。

schema74新增四张表：content-addressed JPEG资产、不可变来源、当前曲目选择、不可变修改记录。来源包含原下载图片SHA、规范JPEG SHA、发行版／图片ID／来源网页、获取与确认时间、尺寸和操作限制。修订冲突拒绝覆盖；同一命令回放先返回既有结果，不要求预览仍存在。撤销只针对当前最新修改且原选择一致，避免旧操作覆盖新编辑。

独立在线图片存储上限256MiB、8192资产、32768修改；单JPEG至多2MiB、1024×1024，检查SHA及JPEG尺寸。超过上限原子拒绝，不自动删除用户确认图片或历史。小列表复用规范图片并缩放；在线多尺寸资产与用户存储清理页面继续开发。现有本地缩略图缓存不能淘汰这些在线资产。

已有schema73曲库升级前生成不可变pre-v74快照，再事务建表、核对原记录／完整性／外键和版本。较老曲库保留原pre-v73快照路径，一次升级到当前74。当前备份纳入图像与来源／历史，并新增第九个online-artwork领域校验，包括实际内容SHA、来源归属、修订链、命令回执和撤销关系。历史68–73备份可识别原版本，完整应用仍需显式迁移，不能重新标注为74。备份内容认证通过不代表目录切换／完整恢复流程已验收。
