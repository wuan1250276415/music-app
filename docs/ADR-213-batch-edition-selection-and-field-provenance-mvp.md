# ADR-213：批量逐首发行版选择及字段来源 MVP

状态：0.206.0 源码集中 MVP 通过；完整 V1 未完成。2026-10-14。

同一录音出现在多张发行版时，录音查询候选的首个专辑不能替代用户的版本判断。批量对话框复用生产发行分页面板，逐首显示日期、地区、介质、版本说明、状态和条码；选择派生候选仍由私有批量预览会话保留，不由展示对象授予身份。换版清空本行字段及范围确认，其他行保持。

批量内的专辑上下文只作资料比较。闭合请求新增可选布尔 readOnly；未提供时保留原请求形状，错误类型、未知字段和分页游标拒绝。Service 仍核对候选、条目及发行快照，readOnly=true 时不调用整专辑／发行字段审核签发，结果中的 albumReview 与 fieldsReview 均为 null。界面保留曲目表、数量／位置／当前录音警示，隐藏编辑入口；批量文本采用仍必须重选字段并确认。

持久批次继续保存私有已接受候选中的发行 ID 和字段来源，使用既有 schema75，不引入新的迁移。读取计划时复用闭合字段来源校验；已有明确字段 URL 优先，其次专辑字段使用所选发行版 URL，其他字段采用录音来源。录音查询链接独立保留；字段链接调用现有受控来源打开入口。旧计划读取、创建回执、离线执行与补偿保持。

集中验证：既有身份27、轨目14、概念19、署名14、直接查询14、ISRC16；批量19项新增闭合只读请求及选版来源／关闭会话／创建回执；实际 Main／preload／Service／Electron75项，新增发行分页／选版后本行字段清空与同行保持、只读比较与未匹配提示、两个编辑审核为空、保存后字段来源按钮及离线重启来源保持。实际窗口截图经检查。网络是明确 fetch 夹具，无候选／审核令牌注入；数据层文件输入有显式夹具。构建、类型、原生与发行清单检查通过。

用户原 FLAC 只读观察保存在验证附件：31,414,008 字节、0个PICTURE块，包含歌名、歌手、专辑和ISRC；摘要与既有记录一致。该文件无法贡献内嵌封面，不据此更改原文件，也不声称已下载现实封面。此前播放详情、内嵌图片优先读取及本地／在线图片审核证据仍独立保留。

最新试用安装包仍0.201.0。本轮不构成真实音乐识别真值、100首真实文件整批性能、完整字段写回、实体合并、完整恢复、安装升级卸载或硬件验收。完整架构开发继续，仅 ASIO 实机验证暂停。
