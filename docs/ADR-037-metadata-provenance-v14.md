# ADR-037：字段来源与单值字段锁

状态：0.32.0 源码实现和编译通过，2026-09-30；schema v14 迁移、运行与回归待 MVP 集中验证。对应 WP03/WP08，不表示元数据工作包或完整领域契约已验收。

## 范围和入口

歌曲标签／覆盖值管理名称、歌手原文、专辑原文；艺人管理名称、排序名称、区分说明；录音管理名称、版本说明、参考时长；发行版管理名称、日期、国家／地区、发行公司、目录编号、条码、版本；专辑概念管理名称和类型。署名列表、角色、连接词、风格集合和图片不属于本次单值字段锁范围。

入口为曲目“整理关联 → 查看来源与字段锁”、播放详情“来源与字段锁”、在线匹配面板同名按钮，以及艺人资料管理中所选身份的同名按钮。单曲入口可切换查看它当前关联的全部对象，独立艺人也可以查看。歌曲层的歌手／专辑原文与人工绑定后的规范署名／发行实体分别管理，锁定原文字段不会锁定整个关系图。

## 数据与写入规则

- `metadata_observation` 保存实体、字段、规范化值、来源、来源引用、授权快照 ID、来源记录时间和去重指纹；记录不可改写或直接删除。已确认的在线值仅保存名称、歌手原文和专辑名称，不持久化原始 API 响应、候选分数、评级或评论。
- `provider_rights` 保存不可改写的授权策略快照。当前本地来源只声明本地使用；MusicBrainz 核心文本记录 CC0 快照。来源记录不等于自动允许所有 Provider 内容导出或写回。
- `field_decision` 保存选中来源、所选值、锁定状态与字段修订；`metadata_field_revision` 在撤销删除选择行后仍保留修订计数，防止修订倒退。`metadata_policy_state` 独立记录实体的来源／锁定修订，不把这些字段加入旧曲库身份投影。
- 多态来源、修订和选择记录通过闭合集合／实体存在／字段白名单触发器校验。选择来源必须属于同一实体和字段；仍有来源的实体不得直接删除，沿用保留和归档方式。
- 保存和撤销在 Library Service 的事务中执行，通过命令 ID、请求指纹与持久回执处理重复提交；检查所见来源修订、字段值和关联成员，过期预览拒绝。单次最多影响 5000 个文件。

扫描明确区分文件标签、CUE 信息、文件名推断和缺失值。规范化实体的新候选标为本地派生值，不能直接当成某个在线 Provider 的数据。旧库缺少来源证据时显示“现有曲库值（来源未记录）”，迁移不猜测或批量回填；重扫会补读没有解析来源信息的旧文件标签。旧的已确认录音不会在重扫时误标为新扫描候选。

歌曲字段锁使用现有曲库覆盖层冻结当前展示原文，原始文件标签仍可更新并记录观察值。解除明确文件来源的锁后恢复最新扫描值；解除人工、在线或来源未知的锁时保留现有确认值。录音未确认候选的名称／参考时长更新也检查字段锁；已确认录音继续由资料状态保护。其余规范实体本就不会因重扫覆盖现有标量值。

人工资料编辑可以主动修改锁定值，并更新来源为人工编辑、保留锁定状态；锁不是禁止用户编辑的权限。发行拆分和身份确认复制字段时保留已知来源及锁，明确输入的新字段记录人工来源；缺少来源的复制值继续标为未知。

在线匹配在界面禁用锁定字段，后端再次校验，旧候选不能绕过后来新增的锁。候选使用请求开始时的基础修订，避免网络等待期间的修改被错误当成新预览。专辑字段记录所选具体发行版来源链接，名称／歌手记录录音来源链接；来源时间来自收到候选的时间。

在线覆盖和艺人／录音／发行资料修订保存来源快照。撤销检查之后是否发生来源或锁变化，拒绝覆盖后来的选择；恢复选择使用递增修订。旧审计没有来源快照时，只允许实体尚未产生来源／锁选择的情况下直接撤销；不是无条件承诺所有旧审计继续可撤销。

## 来源策略依据

MusicBrainz 官方将核心数据列为 CC0，补充数据使用其他许可；录音名称、署名和发行名称属于列出的核心字段。因此本次授权快照只应用于已经确认的这些核心文本字段，不泛化到封面、评论、评级、标签关系或搜索索引。[数据许可](https://musicbrainz.org/doc/About/Data_License) · [核心／补充数据范围](https://musicbrainz.org/doc/MusicBrainz_Database)。核对日期为 2026-09-30，快照日期不是 MusicBrainz 公布的许可版本号。API 访问条款、后续 Provider 与保留期限仍需 broker 统一管理。

## 验证与后续

本轮类型检查、主进程／Renderer 和原生宿主编译通过；没有运行单元、schema v14 迁移、桌面、音频或安装包验证。历史测试夹具已更新为可构造 pre-v14 审计，当前 schema 断言调整为 14，但未执行。旧安装包仍为 0.29.0。ASIO 实机验证按用户要求暂停。

MVP 必须检查：v13 一致备份／升级／失败回滚、全部实体与字段归属拒绝、字段修订不倒退、在锁期间重扫与解锁、确认值保留、人工修改锁定值、在线旧候选与并发锁冲突、来源 URL 与授权白名单、资料撤销保护、旧审计保守恢复、重复命令／服务重启回执、关联成员变化和不可用文件、各入口及键盘操作。

下一步仍需来源观察历史和显式选择、完整多值集合来源／锁、Provider broker 的访问／缓存／TTL／撤销策略、批量审核、标签在线 ID 导入与全局来源 ID 检索，以及后续写回消费权限规则。每个观察值限制为安全整数、字符串或空值，JSON 长度不超过 16384 字符；大库源记录保留／归档与性能也需集中验收。
