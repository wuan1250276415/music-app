# ADR-090：封面预加载保护与独立当前歌曲详情

日期：2026-10-02；源码 0.85.0；schema v38、音频 IPC 1.19、媒体协议 6 不变。

## 用户要求与现状

歌曲封面优先使用文件自带元数据；点击播放栏封面进入播放详情，展示可点击检索的歌手／专辑／风格、大封面、同步滚动歌词、播放模式和播放列表。此前批次已接入这些入口及监督图片解析，封面顺序为内嵌正面、其他内嵌、同名本地图片、目录常规封面。

源码核对发现：可见图片已有租约，候选预加载图片仍未等待租约；在缓存回收与加载交错时，预加载可能把资源暂时不可读当成图片不支持，排除内嵌封面。当前歌曲信息还只来自列表、队列或上次选择的快照；进度拖动的预览位置未绑定到原歌曲。这些是代码路径上的缺口，不是已通过用户文件复现的结论。

## 决策与实现

1. `media-artwork.ts` 在候选预加载前使用独立 consumer 保护当前资源，等待 retain 回执后才设置图片地址。租约失败向上报告，不把来源加入图片排除名单；正常结束、失败与超时均安排同一 consumer 的清理，超时后迟到的 retain 完成也安排 release。清理是异步尽力执行，服务故障的完整恢复仍属于 FR13，不能宣称已证明无泄漏。
2. 预加载解码失败先重新请求／注册同一来源一次，重复失败后才排除 token 并按既有顺序寻找下一个候选。保留八个来源与六十秒单次读取预算；该期限不保证下游进程已结束。可见图片继续使用已有独立租约和有限恢复机制。
3. `ArtworkResources.lease` 在等待库服务期间发生文档重置时，清理旧租约并返回明确失败，避免把已失效文档的租约确认当作成功。
4. 新增只读 `MusicApi.item`／`library:item`，复用库服务 `getItem`，不新增数据库或原生协议。Main 限定受信任窗口与非空、最多 128 字符的条目 ID。`useCurrentItem` 按歌曲 ID 和曲库修订独立加载资料；列表与队列提供即时预览，成功回执优先，切歌／卸载／修订变化后的旧回执丢弃。加载失败与已移除歌曲在详情中明确显示，支持手动重读；收藏／评分保存后刷新独立资料。
5. 新增 `PlayerProgress`，将未提交的位置绑定到歌曲 ID、队列 entry、已观察的时钟 generation 和可播放状态。切换这些上下文时清除草稿，保留原输入手势身份直至松开，忽略旧手势随后产生的变化；取消指针不提交。有效提交继续传入预期歌曲 ID，由既有音频控制接口核对。这里不是完整播放会话授权方案，也不宣称同 ID 的所有宿主重建都可由 Renderer 独立识别。
6. 详情继续使用既有实体 ID 检索；没有实体时按标签名称检索。歌词支持跟随当前行、手动浏览后恢复跟随、点击同步行跳转；歌词／播放列表标签页、顺序／列表循环／单曲循环、随机、队列跳转／重排／移出继续保留。歌词跳转明确传入当前歌曲 ID，不依赖详情资料是否加载完毕。侧栏歌词、播放栏及详情共享封面链路。
