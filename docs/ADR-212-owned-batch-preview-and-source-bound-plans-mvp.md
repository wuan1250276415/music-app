# ADR-212：批量预览会话与来源绑定计划

状态：0.205.0源码MVP；最终结果与当前源码摘要见本版本checkpoint。schema75、媒体协议16、音频IPC1.23保持。Windows优先，仅ASIO实机验证暂停。

## 批量查询和审核

批量审核可按默认依据查询所选歌曲，也可只查询一首。默认优先唯一已确认录音；多个标识时明确选择。每首可主动选用其当前有效ISRC，选择候选后再勾选字段。重新查询一首只清除该首旧候选和字段，其他歌曲的明确选择保留；分数与ISRC均不表示身份已确认。

界面复用录音选择、编码选择和匹配依据，并在资料变化时只清除受影响的草稿。所有字段与候选默认不采用，仍需最终范围确认。已保存计划显示审核时使用标题／歌手、已确认录音或ISRC的依据，支持既有执行、暂停、取消、独立字段撤销和重启记录。

## 拥有期限的内存预览

普通Provider候选仍限制400条。批量查询由服务签发预览会话，绑定1–100个不同曲目；最多同时4份，最长10分钟。批量候选另以私有快照保存，所有会话合计最多16MiB序列化快照预算；不因普通缓存压力淘汰当前审核中的歌曲。预算不足明确拒绝本次保留，并完整保留已有预览；不会把展示对象变成来源授权。

保留时核对当前来源及元数据指纹，向客户端返回独立副本。发行分页和完整署名的派生候选继承原会话，统一核对并原子保留。未在范围内的曲目拒绝，单次请求取消仅释放对应候选；关闭、缓存清除、暂停联网、到期和服务关闭释放会话。到期候选主动清理。会话与候选只在内存保留，尚未确认的网络预览不写数据库。

## 持久计划与执行保护

创建计划时从服务端候选登记提取查询类型和当时来源指纹，保存核心录音标识或本地ISRC；不保存搜索评分或由调用者提供的候选值。使用既有candidate_json，schema75不改变，历史无新增绑定的计划保持原解析与回执。

执行不依赖预览会话，不再联网。除原修订、字段锁和权限外，新计划还核对来源指纹。录音引用改变后再恢复，或编码／来源变动时，仅该首进入冲突并保留当前值；其他首可执行和撤销。创建回执仍优先读取，预览关闭或离线重启不重复创建计划。原有整专辑文本批次保留其独立专辑上下文绑定。

## 集中MVP证据与边界

新增生产Provider/Broker/缓存与SQLite集中17项通过：40首共800个批量候选，并另外施加600个普通候选压力；最早普通候选被淘汰时批量选择仍可解析。包含展示对象隔离、范围／关闭、逐首替换与取消、派生候选、录音引用变动、持久依据／回执、离线冲突与独立执行／补偿、ISRC变动、预算失败原子性、4份上限、到期、schema75备份检查及重开。文件与网络输入为明确夹具，不作为真实扫描或匹配真值证明。

实际Electron/Main/preload/Service组合最终71项通过，覆盖两首逐曲录音／编码选择、保留另一首字段、窄范围拒绝、计划保存、来源恢复后离线执行冲突／同行成功、补偿、主动只清除变更草稿和重启记录。在线为fetch夹具，不注入候选或授权凭据；源码重启同样使用该边界。字段勾选与确认布局受旧全局样式影响，现用批量窗口专属规则修正，初始和最终截图保留。最终发行检查同时纠正一个未定义的主题颜色引用，改用现有主题色；初次拒绝日志保留。最终样式复验单独记录，不与之前的组合命令混淆。
