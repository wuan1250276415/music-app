# ADR-123 实际工件只读核对与持久恢复报告

日期：2026-10-04  
状态：0.117.0 源码实现；类型／编译／静态发行核对通过，实际文件与界面验收留至 MVP。

## 目标

按架构 FR12／WP09 推进可恢复标签写回。暂存取消、进程失败或服务重启后，单个数据库阶段不能证明文件系统状态。本轮接通实际原文件、已知备份和已知临时文件的只读核对、取消与持久报告，为后续恢复动作提供证据。完整写回、认证替换、解除恢复占用及工件保留策略仍待实现，本轮不标记 FR12／AC12 完成。

## 原生核对

新增 `tag-file-inspector.exe`，与暂存监督组件一起编译、随未来安装包分发。它只打开已存在文件，不创建、覆盖、替换、重命名或删除歌曲及工件。受信 Library 进程从冻结执行描述导出三个固定工件路径，Renderer 只提供命令 ID、任务 ID 和修订，不能指定路径。

- 先确认父进程与固定执行文件；单进程 Windows Job，不允许子进程，进程／Job 128 MiB、8 小时墙钟和 6 小时用户 CPU 上限。父进程退出、输入 EOF／额外输入或超时会终结核对进程；正常完成等待实际进程 `close`，不会仅因收到完成消息就确认退出。
- 三个已有工件使用 `GENERIC_READ`、共享模式 0、`OPEN_EXISTING` 和 `OPEN_REPARSE_POINT` 打开，保持所有成功句柄直到全部核对结束。共享模式 0 对读／写／删除打开的限制仅持续到句柄关闭；本轮结果不是未来文件替换所持有的锁。[Microsoft CreateFileW 文档](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew)
- 获取卷标识、128 位文件 ID、创建／修改／变更时间和字节数；拒绝重解析点、目录叶节点和多硬链接。最终句柄路径须位于批准根目录，根目录身份在读取后复核。[Microsoft FILE_ID_INFO 文档](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_id_info)
- 区分 `present`、`missing`、`busy`、`unreadable`；不能读取的文件不当作缺失。逐个 4 MiB 分块计算完整 SHA256；标准 FLAC 块链另计算元数据前缀和编码音频载荷 SHA256。单文件上限 64 GiB，FLAC 前缀 32 MiB／1024 块。非标准或损坏 FLAC 可报告完整文件摘要，但不产生 FLAC 音频证据，不做解码认证。
- 固定请求上限 128 KiB、回执帧上限 64 KiB、128 KiB/s 输出、16 KiB 诊断、131072 顺序消息；严格核对任务 nonce、递增序号、工件角色、物理身份和摘要结构。5 分钟无进度请求 EOF 取消，仍等实际退出；未知退出保持不确定状态，不依据观察超时重新启动进程。

冻结的授权音乐目录、原目录观察和当前授权设置在核对前后复核。原生物理身份是本次句柄快照，不能把一次只读核对推导为之后的原子写入授权；认证写入仍需同句柄根／源身份和独占写锁。已有外部属性修改或目录竞争等负例需要 MVP 实测。

## 数据库、日志与任务

schema49 新增恢复核对历史，绑定原任务／执行／基准修订与命令。限定 8192 条／256 MiB，最终报告最多 32 KiB；执行所属任务受触发器约束，身份及最终回执不可修改／删除。运行核对在重启时转为 `interrupted`，旧结果不能自动解除占用。

原命令回读先于当前修订／会话检查；同命令相同内容返回原持久回执，不新建第二个核对。停止请求先保存命令回执，再发送取消，终态等待进程退出。单任务运行且和暂存互斥；暂存或核对退出未知时拒绝当前会话新启动。新流程同样等待读取组件真正停止；35 秒未完成等待则保留恢复占用。

实际文件核对完成后，读取不可变阶段日志完整 SHA 链；校验冻结计划、每阶段命令、租约 ID／修订、备份／临时工件 ID，并逐条核对数据库阶段回执与文件系统摘要。文件系统先持久化而数据库尚未确认的阶段明确标为 `fs-ahead`。损坏／缺口／未知日志或不一致数据库回执标为 `journal-unconfirmed`，不能据此判断安全恢复。

只有已持久化 `validated` 源完整摘要时才分类为原文件一致／备份暂存一致／原文件明确缺失且备份一致。源摘要尚未建立时报告 `source-baseline-unavailable`，不声称当前音频与旧来源一致。原文件被占用、不可读取或未确认 FLAC 时不分类为可从备份恢复；没有替换受害者证据，不确认替换已完成。

报告是读取期间的快照，原生句柄在退出后关闭。保存报告不修改原任务的恢复租约，不替换文件，不执行扫描／库提交、不自动清理或重试。后续解除占用或保留当前文件并重扫、从备份恢复、认证替换必须重新核对，拥有独立持久命令及文件身份约束。
