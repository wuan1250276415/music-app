# ADR-219：后台音频识别与持久阶段 MVP

状态：0.212.0 源码集中 MVP 通过；完整 V1 未完成。2026-10-15。

对应 FR06／WP08 以及任务中心、进度恢复和资料来源边界。识别工作移到 Library 服务，Renderer 只提交任务控制和读取公开进度，因此关闭任务窗口后处理仍继续。一次处理当前任务页，最多100首，四个排队任务，一个实际执行任务；没有据此宣称整库无人值守跨页或百万首性能通过。

schema77新增 metadata_recognition_run、metadata_recognition_item、metadata_recognition_command。任务保留修订、当前页代次、状态及分类错误；每项保留阶段、尝试次数和错误码。命令有闭合读者、修订比较及不可改写回执；同一命令不能更换意图。领取延用工作清单固定范围、当前来源观察及十分钟父页期限。手工领取与排队／执行中的后台领取不能争用同一任务，已提交命令仍优先核对回执。

调度先核对来源开关和系统凭据，再领取实际任务页；计算当前歌曲/CUE片段指纹后查询关联。凭据不足时不开始读取、外发或领取。逐首持久 decoding、lookup、ready、empty、failed 等阶段，异常只保存分类码，避免写入远端正文或凭据。单曲异常保留其他已完成结果；来源关闭、鉴权或容量失败停止本页。已完成有效关联在暂停后继续可复用，失效结果重新获取；每次尝试单独累计。

暂停首先标记 stopping，并中止实际关联查询或等待原生读取收尾，排空后才显示 paused。取消释放所属未审核页，保留独立审核计划和补偿记录。后台关联预览与MusicBrainz预览归属同一私有页，过期、来源变化、页关闭或计划保存会撤销预览。后台处理中阻止交互资料选择和计划保存；暂停或完成后才允许逐首审核，候选及字段默认不采用。审核时按行读取已有结果，不重新计算音频或自动联网读取录音资料。

原始指纹和关联响应仅在短期内存保存，数据库不持久化这些正文。重启后保留阶段和尝试次数，但将临时结果标为丢失，释放原页，任务需明确继续；不会自行发送外部请求。公开进度事件仅传递状态、数量和分类码，不携带私有令牌。界面直接合并这些小结果，状态转换才安排整页刷新，五秒轮询作为恢复手段。

集中桌面验证暴露了真实界面竞态：服务已完成识别，用户点击取消时界面仍保留旧修订，请求被拒且停在待核对状态。操作现在先读取同一任务页代次的当前修订，再提交原意图；若页代次变更则要求刷新，不把旧操作转用于另一页。服务仍保留最终修订比较，不自动重新提交未确认写入。原失败报告 completed:false 保留；修复后的实际退出／重启／五首继续／取消完整流程通过。

维护先阻止新调度，取消查询并等待实际原生工作排空，释放所属页后才能捕获数据库。恢复暂停运行时不自动恢复或调度任务，冻结与关闭不修改只读归档；真正重新启用时也不隐式恢复查询。备份、恢复兼容性、历史导出及版本读者同步schema77；旧归档仍可识别，但应用前必须显式迁移。只读领域检查从十域增为十一域，包含后台识别阶段、数量及命令来源。构造schema76升级前生成-v77快照。

核心23项使用实际监督扫描的WAV/CUE、现有原生指纹程序、生产Broker/Provider/调度/SQLite，只有凭据与网络为测试边界。涵盖未启用和无凭据预检、真实原生读取、暂停排空、鉴权暂失时保留有效部分结果、私有范围拒绝、继续跳过已完成、无自动采用、schema77独立备份与只读十一域检查、实际重开、无关联、实际读取取消后以r+打开源文件证明锁释放、修改自有测试源后的错误记录及恢复扫描重试、异常关联分类及明确重试、父页过期、四任务队列、维护排空与不自动恢复、真实queued归档的只读冻结字节不变、76→77快照以及源文件/SQLite完整性。

实际Electron11项使用隔离Windows假凭据和真实Main/preload/Library/Renderer，只有fetch被夹具替换。包括默认来源关闭、无凭据、实际凭据保存与不泄露、离开任务窗口仍处理且本地搜索可用、实际暂停与部分结果/明细、六首续办、按行读取既有结果和伪造归属拒绝、逐首明确录音/字段后原子保存一首及五首待审、离线执行撤销和原文件保持、实际隔离主进程及子树强制退出后不自动联网、重启明确继续剩余五首并取消且原计划补偿保持。假凭据按自有范围清理，截图已检查。

回归通过：整库清单18／桌面8，独立历史schema72定义摘要仍匹配0.185的634对象记录，72→77迁移、原始记录/重复歌单保持、真实快照及DDL故障回滚4组；原生指纹18和官方工具对照、真实FLAC只读副本3、批量指纹15、单曲桌面9／批量桌面10、批量审核26及完整桌面组合81。最终构建、类型、发行生成和清单检查通过。媒体16／音频IPC1.23／指纹协议1不变，原生源码及二进制与0.211检查点一致，本轮没有重编原生或新增硬件证明。
