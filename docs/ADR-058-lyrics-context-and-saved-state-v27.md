# ADR-058：用户歌词历史范围快照与跨范围状态管理（schema v27）

日期：2026-10-01。状态：0.53.0 源码实现，运行与迁移待 MVP。对应架构 §17.1、FR10、WP03/WP10。延续 ADR-056/057，保留 FR01–FR14 与 WP01–WP11 完整范围；ASIO 实机验证仍暂停。

## 保存时的范围上下文

schema v27 新增不可变 `lyrics_document_context`，每个新导入版本在原文、状态、范围修订和回执的同一事务中保存上下文 JSON 与 SHA-256。快照 v1 保存范围 ID 和用于计算范围身份的全部字段：PlayableItem ID、MediaFile ID、当时音频路径、file/cue 类型、源音频秒起止与 75 fps 整数帧起止；同时保存当时歌曲标题、歌手、专辑、格式、时长、采样率、位深、碟轨号及录音／发行／发行曲目身份和当时修订。

来源时间基、编码、语言、解析版本和原文字节仍由原歌词文档保存；快照不会改写词句或重新定义播放时钟。上限 64 KiB，提交前验证字段、数值、帧秒对应和范围摘要；读取时核对 JSON 字节摘要、结构及文档的 item/scope 关联。上下文禁止更新与删除，曲目删除也不删除用户原文或快照。原始音频路径只供用户展开查阅，不写入状态通知或常规日志。

v25/v26 文档没有保存当时的完整字段，迁移不从当前歌曲反向补造历史，也不解读 SHA-256 为旧起点。读取明确返回缺少快照，界面提示历史上下文未保存。新文档复制时原来源快照供查阅，新文档保存新的目标快照；复制引用不改变原文的历史范围。该快照记录的是当时库内范围与资料，不证明音乐文件内容未改变，不保存完整原始 CUE 文件、INDEX00/PREGAP 或目录改写历史，也不是完整元数据来源／锁状态备份。

当前曲目版本管理、跨范围原文查看与复制草稿共用历史上下文展示。读取旧文档不重新访问音乐文件，不把当前曲目名称作为导入时名称。预览仍显示后台实际核对的当前目标。

## 跨范围归档与恢复

原文目录可管理当前范围、旧 CUE 范围、离线媒体和已移除曲目的用户导入版本。打开单个文档后显示其原范围的当前修订，归档／恢复使用该版本的 document_id、历史 item_id、scope、baseRevision 和新的 UUID。Main 只接受固定字段及归档／恢复动作，Service／Repository 再做结构与关联检查；不接受导入、重新绑定、路径打开或外部来源操作。

提交在一个立即事务中复核原范围所属 item_id、文档所属范围、`local-private-v1` 授权和修订。旧范围操作不需要当前 PlayableItem 存在，也不根据当前曲目的新范围计算目标。归档只停用该范围来源；恢复只启用该原范围版本，不使旧范围歌词成为新歌曲来源。版本 ID、原始字节、解析内容、快照和复制关联均保持。

恢复复核原文 SHA-256、解析结构与已有上下文校验，继续执行每范围最多 16 个启用版本／4 MiB 解析内容上限。新导入的 64 版本／32 MiB 原文限制不变；归档内容不被自动删除。当前范围版本管理复用相同状态变更逻辑，避免两个入口采用不同恢复规则。

原范围修订、状态和不可变回执一并提交。精确相同 UUID 请求先读取历史回执，再看当前修订；后续归档／恢复不会令旧操作重新执行。同 UUID 内容变化拒绝。新接口使用既有归档／恢复规范请求格式，不重写历史回执。通知包含历史 itemId 以刷新相关视图，提交后的通知失败不会将已保存结果改为拒绝。

## 修订查阅与界面确认

单个文档修订按范围内单调 revision 降序键集分页，每页 20 条；新增 document/revision 索引。游标绑定文档、范围、观察到的范围修订及末条修订，另一文档的游标或期间变化会拒绝并要求重新读取。列表不依赖系统时间排序，保存日期只供展示。可查看导入／归档／恢复动作、时间、修订与操作 ID；这些审计跨旧范围和关联条目移除后仍可查阅。

界面在原文视图中显示状态按钮、明确的原范围说明、重新读取和修订入口。外部变更标记需要重新读取；提交使用乐观修订核对，防止覆盖另一个窗口或入口的变化。未知传输结果保留原 UUID 与原请求，锁住新操作与关闭入口，提供“核对上次操作结果”；已返回保存成功后的读取失败只提示刷新，不再次提交写操作。分页与读取仍按页面请求代次隔离。刷新、搜索和状态筛选更新目录，归档原文仍可复制；恢复旧范围也不自动绑定到当前歌曲。

未新增持久待确认意图收件箱：进程内未知请求可重试，已提交回执持久保留；崩溃后的未确认请求自动恢复仍属 WP01/WP11 后续工作。实际键盘／模态／小窗口与多窗口并发测试待 MVP。

## 迁移与验证

schema v27 新建上下文表、不可变触发器和文档修订索引，不更新已有文档。v26 创建增加条件保护，升级前一致 `VACUUM INTO` 备份，然后在事务中创建对象并提交 user_version。最新 schema 断言和逆迁移夹具更新至 v27，音频 IPC 1.8 不变。

本轮类型检查、主进程、Renderer（59 模块）、音频宿主与凭据组件编译通过；发行／分发清单一致性、维护脚本语法静态检查通过。未运行单元、数据库迁移／事务、实际文档读写、界面、音频或安装验证；没有新安装包，最新已验证安装包仍为 0.29.0。

MVP 矩阵：新文件和 CUE 导入生成快照；快照字段／帧秒／64 KiB 上限及摘要损坏拒绝；旧文档保持无快照；编辑资料、改 CUE 范围、移除曲目后查看保存信息；复制新目标保留原来源并保存新快照；当前／旧／移除／离线范围归档恢复；无当前播放项管理；伪造 item/scope/document/action 拒绝；跨窗口修订冲突；恢复损坏字节／解析／快照与容量拒绝；精确 UUID 重放、变造和丢回执核对；成功后刷新失败不再写入；修订分页绑定／期间变化／系统时间回退；菜单关闭及事件迟到；v26 备份、v27 事务失败回滚和历史回执兼容。
