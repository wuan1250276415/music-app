# ADR-047：数据源后续保存设置与来源修订入口

日期：2026-10-01。源码版本：0.42.0。schema：v22。IPC 协议仍为 v1.6。关联 WP01/WP03/WP08、FR06/FR14。

## 行为与边界

数据源设置新增“来源保存与撤销”。查询启停独立于后续保存选择：MusicBrainz 可以保持查询开启、只查看候选，也可以允许保存明确审核后的修改。清除候选只影响短期内存预览；逐字段撤销恢复曲库展示值；两者均不等于彻底删除来源内容，也不写回音乐文件。

新建及升级曲库沿用现有 MusicBrainz 核心文本授权快照，后续保存默认为 reviewed；在线查询的新库默认关闭规则不变。Cover Art Archive 与 AcoustID 仍未接入，固定为 preview-only，不能启用保存能力。本批次没有重新解释或扩展外部授权；已有核心文本按先前记录的授权快照使用。切换为 preview-only 是用户暂停新的在线保存，不是撤销既有来源许可。

设置保存使用基础 revision、命令 UUID、事务和不可变审计。重复已提交命令不重放变更，返回当前汇总；界面可显式核对丢失回执的操作。不同请求内容不能复用同一 UUID。修改设置不删除已经确认的来源、修订或审核计划。

## 提交与旧候选保护

单曲单值、在线艺人来源、完整主署名集合及审核批次创建／执行均在保存边界检查当前模式与核心授权快照。历史回执优先于新写入检查；已提交命令重试不再次采用在线内容。既有合法来源的选择、复制及撤销继续可用，取消与撤销不要求网络查询开启。

审核指纹包含保存模式及其修订，避免 reviewed → preview-only → reviewed 后旧批次重新有效。设置操作后清除旧候选和署名预览、取消相关查询并发布状态；即使事务已经提交而汇总读取失败，也使旧候选失效。旧 v21 批次因指纹组成改变而保守失效，待重新查询审核；已成功项和撤销入口仍保留。

界面阻止 preview-only 模式下新增单曲确认、署名确认、保存批次和继续采用剩余项；实际拒绝仍由 Service／事务层负责。查询暂停与保存暂停分别显示，不能用界面按钮是否可点作为持久化权限依据。

## 来源记录与撤销

按固定注册的数据源汇总歌曲单值修订、未全部撤销修订、在线署名修订及两类来源观察数量。歌曲单值修订使用 created_at／id 键集分页，每页 30 项，游标和数据源均验证；列表只返回当前标题及修订身份，不复制来源值。

选中修订进入既有逐字段撤销预览。预览检查当前值、有效显示、来源、锁、修订和署名保护，后续编辑冲突保留当前值；补偿结果与原应用回执分别记录。来源观察和审计仍保留。来源统计不是完整内容清单，也不能作为“已经彻底删除”的证明；署名及其他实体的完整来源清除尚未实现。

数据源设置、来源设置、字段预览逐层管理焦点与背景不可操作状态，关闭后返回上一层。分页结果带读取代次检查，过时响应不能覆盖刷新后的记录。

## schema 与检查

v22 新增 provider_retention、provider_retention_change、审计保护触发器，以及修订分页／来源统计索引；在线署名来源统计使用受 json_valid 保护的 JSON 表达式索引。v21 安装改为版本条件保护，升级已有 v21 不再重建其表。已有库升级前保存 pre-v22 一致备份，新增表和 user_version 在事务中提交。旧版本测试夹具补充 v22 逆迁移，仅维护夹具，没有执行迁移测试。

本批次类型检查、主进程／界面（50 模块）／音频宿主及凭据组件构建通过。发行／分发清单和脚本语法检查在交付时核对。未运行单元、SQL 迁移、桌面界面、网络、实际凭据、用户音乐播放或安装包验证；没有生成安装包。最新已验证安装包仍为 0.29.0，ASIO 实机验证继续暂停。

MVP 集中验证应覆盖：新库／v21 升级及备份、查询与保存两种开关组合、保存模式往返变化、设置提交后回执丢失和旧 UUID 核对、旧候选／署名／持久批次失效、暂停后已成功项查看与撤销、部分冲突保留当前值、既有合法来源选择／复制、待接入数据源拒绝保存、分页刷新与最小窗口键盘操作。

## 后续完整范围

需要期限或条款撤销清理的数据源暂不启用。完整策略仍需处理有效展示、来源观察、不可变审计、命令回执、批次候选、派生值及备份中的内容，并提供恢复与删除验证；本批次不把普通补偿撤销作为内容清除。其他 Provider、整专辑／完整署名批量、其他实体／集合的部分冲突撤销，以及 FR01–FR14／WP01–WP11 剩余功能继续开发。
