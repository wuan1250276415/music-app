# ADR-043：持久批量审核计划与逐项执行

状态：0.38.0 源码实现，2026-10-01。对应架构 §11.2–11.4、WP03/WP08。schema v19，音频协议 v1.6 不变。当前未通过迁移、网络、桌面运行和 MVP 验收。

## 选择、查询和审核

- 歌曲列表支持按本地条目 ID 勾选、选择已加载歌曲及清空选择；跨加载页保留选择，静态歌单重复条目按歌曲 ID 去重。每个审核计划最多 100 首物理／CUE 可播放条目，未加载的全库内容不会被隐式选中。
- “批量元数据审核／记录”入口提供逐首 MusicBrainz 候选、原值与候选值比较、逐字段复选及来源链接。候选、歌曲和字段均不自动接受；排序分数不解释为匹配正确率。查询沿用统一 broker，串行处理并支持取消当前查询与剩余查询。
- 返回预览前先捕获本地歌曲快照、元数据修订和审核指纹。指纹包含有效展示值、文件身份／可用状态、曲库关联与修订、字段来源／锁／集合状态。查询期间及查询后的重扫或编辑使旧审核引用失效；不在查询结束后用新修订替换用户未见过的基线。
- 批次当前接受歌名、单值歌手及专辑展示值；锁定字段和已确认结构化署名受 UI 与后端双重保护。完整多人署名继续使用 ADR-042 的显式成员／角色审核，未纳入本轮批次。专辑展示覆盖不等于确认整个发行版归属或曲序；整张专辑上下文匹配仍待实现。
- 公开联系信息与在线启停使用已有设置。搜索仅发送曲名和歌手，不发送文件路径或完整音频；关闭窗口时取消并失效本窗口产生的查询令牌。取消搜索保留已返回且尚未过期的其他曲目候选。

## 计划与权限

- schema v19 增加 `metadata_batch` 和 `metadata_batch_row`。保存计划和执行分开；用户先核对所选歌曲、候选、字段及发行版本，保存后仍需主动点击执行。计划标题、成员、审核引用、所选字段和候选值不可在执行期间改写。
- 原始 HTTP 响应、未采用字段、未采用候选、排序分数和完整在线署名不进入持久计划。仅保存已确认的核心文本字段、来源实体 ID／URL、抓取时间、审核期限和权限快照引用；本地原值用于审核和结果显示，其来源不因此转为在线 CC0 数据。
- 当前限定 `musicbrainz-core-cc0-2026-09-30` 白名单核心文本；确认时检查该快照允许显示和保存。确认期限与授权期限为不同条件：有持久权限仍须在审核期限内执行，重启不会延长确认期限。
- 新计划在一个写事务内验证所有引用、修订、字段、身份、锁和候选期限；任何成员无效则整份计划不保存。已有库升级前保存一致备份，v19 表和索引在独立事务中迁移。
- 该计划是用户已审核变更的日志，并非持久查询缓存。正式 Provider 注册／凭据、保留策略、动态权限撤销与受控删除仍待实现，不用本轮审计替代这些要求。

## 执行、暂停与恢复

- 每次执行命令只处理一个待执行项，保持 Library Service 可响应；Renderer 连续请求形成逐首执行，并显示成功、冲突、失败、过期和取消数量。单项不成功不会回滚已成功的其他歌曲。
- 单项业务变更在事务保存点内执行，失败回滚该项后保存结果。结果、批次修订和命令回执与业务变更在同一外层事务提交；事务提交失败时不发布假成功。单曲 API 复用相同业务实现，单曲调用仍包裹独立写事务。
- 提交前再次校验原审核指纹和期限；变化报告冲突并保留当前值，过期项要求重新查询和新计划。成功项不再作为待执行项处理。批次命令携带所见修订，其他窗口改变批次时拒绝过期请求。
- 暂停等当前一项提交后停止派发，并保存暂停状态；继续执行不联网。取消剩余项将待执行项标为取消，已成功项保留。关闭或进程退出后，计划和结果仍可从批次记录重新打开；不会因重启自动执行未完成项。
- 创建、执行、暂停、取消和撤销命令使用 UUID 与完整请求摘要保存回执。同 ID 重试返回当前批次状态但不再次执行原动作；同 ID 不同参数拒绝。创建回执读取先于网络启停和候选令牌检查，避免丢失响应后生成重复计划。
- 批次记录按创建时间及 ID 键集分页，每页 20 个；详细结果最多 100 项。全库批量作业、批次结果导出和更大规模后台调度尚未实施。

## 撤销与边界

- “撤销已成功项”逐首调用已有补偿撤销，同事务记录结果并支持命令重放。取消或完成的批次也可撤销已有成功项；失败或未执行项不参与撤销。
- 当前使用整条单值修订的严格 after 值、元数据修订和来源／锁检查；后续编辑造成冲突时保留现值并显示撤销冲突，其他成功项继续撤销。逐字段冲突后的部分撤销仍未实现，不能宣称满足架构 §11.3 的完整要求。
- 本轮未扩展在线评分、风格、关系角色、封面、歌词或指纹授权范围；ASIO 实机验证继续暂停。完整 FR01–FR14／WP01–WP11 目标保持进行中。
