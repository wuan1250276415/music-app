# ADR-034：录音、发行版与专辑概念外部引用（schema v12）

状态：0.29.0 实施。对应 WP03 领域模型与 WP05 管理入口，不代表完整工作包或发布门禁通过。

## 行为与身份

曲目“整理关联 → 管理外部引用”可分别编辑 Recording、Release、ReleaseGroup 的来源、来源 ID 和可选 HTTPS 链接；艺人引用继续使用艺人资料管理。每种对象最多 32 条引用，同种对象的同一来源 ID 只能归属一个本地实体。来源名称规范化为小写，其他来源 ID 保留大小写；MusicBrainz UUID 规范化为小写并生成对应实体链接。拒绝重复、控制字符、错误实体路径、带凭据或非 HTTPS 链接。

MusicBrainz 的 MBID 是 36 字符 UUID，录音、发行和发行组分别具有实体身份；引用格式依据[官方 MusicBrainz Identifier 文档](https://musicbrainz.org/doc/MusicBrainz_Identifier)。本地 UUID 不被外部 ID 替换，保存引用不推断两首音乐相同，不修改标签、曲目绑定、署名、收藏评分、重复歌单或队列。

引用属于所选本地实体。发行合并或拆分创建新实体时不自动转移或复制原引用；原实体及其引用保留，即使暂时没有当前文件。撤销整理回到原绑定后，仍可查看原引用。扫描相同标签保留引用；标签改变生成新候选不自动继承。数据库禁止直接删除具有引用或引用修订状态的实体。

## 修订与事务

`entity_reference_state` 提供独立修订号，`entity_reference_change` 保存前后快照及撤销状态，引用值复用 v10 `external_ref`。新修订不递增兼容曲目投影或发行核心修订。

预览指纹包含实体资料、全部当前成员（含隐藏／离线）、发行和专辑概念关系、解析后的署名及来源修订、引用与独立修订号；空发行的资料和署名也在指纹内。重扫、重新绑定、发行整理、资料或身份变化后拒绝旧预览。每次最多覆盖 5000 个文件或发行，扩大范围前需大库性能证据。

保存先检查全部 ID 归属，再在单写入事务替换引用、更新独立修订、保存审计与 UUID 命令回执。相同规范化请求跨重启重放原回执；命令 ID 被用于其他请求则拒绝。任一步失败完整回滚。撤销检查后置实体指纹，再恢复旧引用并递增修订；旧 ID 已被其他实体声明时拒绝恢复，保留两者现状。

打开链接只接受当前实体快照、已保存的来源和 ID，由 Main 从数据库读取 URL，检查 HTTPS 和凭据后调用系统浏览器。Renderer 不能提交任意待打开 URL；未保存的编辑不作为链接来源。

## 迁移与验证

已有 v11 库先 `VACUUM INTO` 一致备份为 `.pre-v12-*.bak`，事务创建修订／审计表与身份存在、删除保护触发器，然后写 schema 12。核心投影形状保持不变，无须重建旧审计指纹；DDL 失败回滚至 v11，保留备份。更旧版本依序迁移。

单元测试覆盖三种实体的独立命名空间、归属冲突、格式和链接校验、规范化持久回执、重扫／重启保留、空发行、合并不转移 ID、旧预览拒绝、撤销时归属冲突、后期注入故障的完整回滚、删除保护及 v11 备份／旧审计撤销／DDL 回滚。

桌面回归 `npm run test:references` 使用三个真实标签与内嵌封面的 MP3，检查三种引用、链接参数、冲突提示、历史撤销、实际标签重读、音乐播放、详情专辑检索、用户状态与重复歌单及重启恢复。链接系统接口使用替身拦截，未实际访问外部来源。源码和解包版结果记录在 README；隔离测试库不代替真实用户库升级恢复。

## 剩余范围

本次引用为手工声明，尚未联网核验。标签中的在线 ID 自动导入、外部 ID 全局检索、Provider broker、批量匹配、字段来源／锁定、录音完整资料、CUE 任意编辑身份对账与呈现时钟历史仍需实现。十万库、真实用户库恢复、长时稳定性及签名发行仍未验收；ASIO 实机验证继续按用户要求暂停。
