# ADR-167 恢复后的正常应用挂载与实际读取确认

状态：源码实现，运行验收待 MVP。日期：2026-10-10。版本：0.161.0。

## 决定

ADR-166 已经释放曲库和全部主程序资源，但保留播放、历史记录及主程序外层交互占用。此时不能直接开放交互：原准备视图没有构建正常 App，普通请求也仍然被维护门禁拒绝。

本批在私有主流程中追加 application-intent 和 application-ready，让同一已经独立核对的新文档挂载正常 App，确认核心界面确实获得主程序实际读取结果。application-ready 明确表示 applicationMounted/userGateHeld，不是恢复终态或重新启动许可。

## 原文档及持久挑战

Main 再次核对原事务、main-resources-released、同一实际普通曲库服务、全部主程序资源释放、保留的播放与历史占用、固定本地 URL/webContents/代次及新文档准备证明。application-intent 绑定相同完成 UUID、新挑战、原新文档 UUID/token/代次/应用版本、主程序释放与原 Renderer 准备摘要、九项队列状态和受保护待保存资料摘要。

队列比较显式规范九项字段及条目键顺序，忽略 QueueView 新增的 items，仅用于语义状态比较；六项实际返回数据的摘要仍包含完整 QueueView。因此 JSON 原字段顺序不能导致队列状态误判，新增视图资料也不能替代队列证明。

持久意图并读回后，Main 才建立当前文档的读取观察和发送 catalogRestoreApplication。准备视图在回复原文档准备挑战之前已经安装后续事件监听，独立确认相同文档身份、版本、待保存资料和队列，然后用正常 App 替换准备视图。整个过程不再次导航，不重用原旧文档。

## 受控显示读取

普通 Main 请求门禁继续 held。只在当前应用加载操作中，为该实际新主 frame 允许 17 个固定显示入口：播放状态、队列、曲库统计/目录/歌单/浏览、当前曲目、封面及显示租约、歌词、三个已缓存的音频偏好视图、检索状态、分类显示设置、外部文件收件状态。

不开放播放、seek、队列编辑、设置保存、导入、扫描、元数据修改、凭据、在线请求、设备/驱动查询或标签执行。主动封面刷新继续拒绝。封面读取可能维护显示缓存，租约属于显示资源，不宣称这些读取完全不写缓存；原文件标签不因此修改，候选导入来源授权策略保持。

每个入口继续执行原参数验证、真实发送者主 frame 检查和原业务方法；新增通道不能绕过固定 allowlist。动作、读取结果投影/预算/观察和完成校验均在 Main 的恢复读取登记中。操作前后核对同一 Library 实例、维护所有者、新文档和取消信号，迟到结果不能移交其他文档。读取登记提供下一阶段实际等待能力，尚未作为最终交互释放证明使用。

Main 对六种核心读取分别观察成功结果摘要：playback、queue、stats、roots、playlists、browse。浏览投影包含规范查询、实际快照和总数，分页内容及一致性仍由普通浏览协议和 useSnapshotPages 核对；不把多页聚合数组误当成单页回执。stale 浏览回执不能作为准备结果。每项保留最多八个最近观察，核心单次资料上限 3 MiB。

## 正常 App 实际准备

正常 App 的原初始化效果继续读取实际播放状态、QueueView、统计/目录/歌单及分页。新增恢复准备回调仅在这些核心初始化全部成功、当前浏览有 ready 快照且没有错误时触发，数据来自已经提交到 React 的正常 App 状态，不能依靠默认空值或只查询一个隐藏检查接口代替。

恢复挂载容器继续由 CatalogBackupBoundary 的 inert 和受保护 storage 冻结管理。Renderer 核对挂载容器/正常播放栏/同一文档 UUID、inert、应用版本、规范队列和待保存资料；计算六项实际数据摘要，再等待一次事件轮次并确认文档仍连接、原 pending 值未变化，才发送成功回执。核心读取失败发送明确失败回执，保留维护视图和原资料。正常模式沿用原 App 初始化，没有强制要求恢复回调。

Main 只接受原当前文档的相同挑战及请求摘要，要求规范队列/pending 摘要一致，六项摘要都在该当前新文档的实际 Main 成功读取观察中。精确重复回执幂等，不同内容不能覆盖原回执。Main 独立核对实际文档位置后持久 application-ready，保留同一成功回执的后续实际断言。

## 中断、证据与余项

未知导航/刷新、窗口或曲库退出、休眠、取消、60 秒未获完整确认及持久失败都保留原记录和交互占用；读取取消后不允许继续进入显示入口，已经在途的工作保留登记直至实际结束。成功挂载仍保留取消监听，供最终完成前的原操作中断使用。

正常应用确认没有证明播放/历史占用已释放，也没有证明在途读取已清空、最终 completed 已持久、系统入口已开放或重启已安全。当前启动门禁仍拒绝所有已移动但未完成的整库事务。后续继续接通最终释放、独立交互屏障、completed 证书、完成启动准入、未决事务处理及原文导出复审界面。

最长已有链 42/48 条，帧/累计/保留预算和 schema68/音频IPC1.22/媒体10不变。全部架构功能与验收项保持。

本批只进行类型、Main/Renderer 构建、生产原生及既有金样编译、CommonJS 来源语法及发行清单静态核对。没有运行应用、SQL/迁移、恢复、worker、媒体、硬件或测试。实际新文档挂载、控件状态、资料摘要、缺失回执、读取交错、图片与歌词、性能和异常恢复在 MVP 集中验收；ASIO 实机仍搁置，真实缺图仍待复现，无新安装包。
