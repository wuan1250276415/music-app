# ADR-206：跨发行版本的专辑概念身份审核 MVP

日期：2026-10-13；源码0.199.0。schema74、媒体协议15、音频IPC1.23不变；最新已验证试用安装包仍0.198.0。完整架构范围继续，仅ASIO实机验证暂停。

## 用户流程

从整专辑曲目审核进入“审核音乐身份”。已验证的在线发行上下文提供ReleaseGroup标识、当前本地发行也已关联一个专辑概念时，新增独立“专辑概念”卡片。卡片显示本地／来源标题、标识和规范来源链接、涉及的所有本地发行版与版本资料、可播放条目及发行版数量。录音、具体发行版、专辑概念分别确认。

确认方式默认不采用。追加标识或只替换MusicBrainz引用均复用已有引用机制，保留其他来源。本轮不改变本地专辑概念标题、类型、成员、发行版归属、歌曲主键、文本、歌单或音乐文件。

选择专辑概念后，还需单独勾选“已核对专辑概念下列出的全部本地发行版”。仅确认录音／发行影响范围不能提交该目标。当前发行曲目对应未完成或来源曲目列表含未审核内容时，概念目标也阻止确认；录音可独立处理。

来源没有概念标识时不构造新值。当前发行没有本地概念时显示说明，用户先使用既有曲库“专辑概念”关联功能选择多个发行版，再重新读取审核；此轮没有实现在线审核直接创建或自动合并本地概念。

## 保存、审计与兼容

规范来源URL使用MusicBrainz的release-group路径；Main的受控来源打开入口允许该规范实体页面，仍拒绝任意URL。

概念目标绑定完整实体资料、引用修订、全体发行版、各版本署名及所有PlayableItem成员快照。其他发行版后来移出概念，即使当前来源发行自身未变，也使旧审核失效。外部标识已有其他本地概念归属时阻止确认，不自动迁移或合并。

录音、发行及概念目标共用一个事务：全部验证后保存引用、每实体审计及聚合回执。概念审计在末段失败时，先前录音／发行写入及回执一起回滚。最多1000条映射、1002个目标、5000个影响条目；预览仍为4份及总16MiB序列化预算。返回的展示对象与私有目标快照分离，修改展示位置／引用／来源标识不能改变保存的授权来源或审计位置。

来源设置的身份记录／计数直接包含概念修订。可单独撤销概念引用；保留录音确认、发行归属和其余引用。后续概念资料、成员或引用改变时，旧撤销保留当前状态并报告冲突。重启及媒体离线继续读取审计与提交回执。

新增可选confirmedReleaseGroupScope字段。旧请求缺少该字段时保持原有规范JSON元组，不默默补false，以免旧命令回执摘要改变。缺少该字段的旧请求继续适用于录音／发行，不能确认概念。兼容检查采用明确的旧请求／回执元组夹具与当前生产数据库、当前版本重启；未声称全部历史计划或旧安装版升级路径已验收。

## 集中 MVP 验证

执行`npm run test:metadata-identities-mvp`。原生构建提前完成；最终命令构建Main及Renderer，再执行生产SQLite检查和实际桌面组合链。网络仅替换fetch边界，没有注入候选、预览或批准凭据。

首次扩展仓库测试仍使用旧“4条历史”总数，新增概念场景实际9条，断言失败；调整为本场景明确总数后通过。首次桌面扩展过早检查撤销弹窗文字，读取期间失败；改为等待实际确认控件载入再检查。失败记录保留，不计入通过证据。最终执行证据为v0.199-mvp-command.log／exit及对应两份JSON。

## 剩余范围

完整FR06仍需ReleaseTrack标识完整绑定、缺少概念时在线直接创建／合并、整专辑真值集和召回、隐藏／数据轨、ISRC／指纹、多来源、更多字段和完整多人角色、全库批量、完整来源生命周期／写回／恢复与规模性能。此次是明确审核的既有本地概念外部引用接受，不是远端成员正确性自动认证。

未修改用户原曲库／音乐；没有本轮真实网络概念确认／现实封面保存、发布安装升级或新增硬件验证。完整V1未交付。
