# ADR-176：内嵌编排的精确采样范围

日期：2026-10-10。范围：FR02／FR07／FR08／FR09／FR10／FR11 的源码接通，延续 ADR-175；不是播放、驱动或 MVP 验收。

## 原始范围与曲库

[RFC 9639 §8.7](https://www.rfc-editor.org/rfc/rfc9639.html#section-8.7) 的非 CD CUESHEET 可以包含无法精确表示为 75 帧的采样边界。不能用四舍五入、微秒或浮点秒代替这些原始位置。

解析标记升为 `aural-flac-cuesheet-2`。整个文档可精确换算为 75 帧时保留既有路径；否则全部可播放音轨、子索引和隐藏前导采用原始采样整数，时间基准为文件采样率。原有 `playable_span` 保存 ticks／rate，无 schema 变更；非 75 帧条目的 `start_cue_frame`／`end_cue_frame` 为 NULL，秒字段只供显示，不能当作音频边界。投影明确返回 `cue.timeBaseDen` 和 `{sampleRate,start,end}`，列表仍不携带整块二进制。

升级后旧解析标记触发一次重新探测，旧版内嵌文档仍参加扫描保护与外部 CUE 移除后的回退。按文件／轨号／隐藏属性保留当前曲目身份；资料审核与录音成员指纹纳入新的精确 span，旧 75 帧曲目保留原指纹格式。原文件艺人／专辑／风格／碟号、封面来源、原始二进制与 SHA 沿用 ADR-175。

## 播放与原生范围

新增共享 `source-sample-range.ts`。Main 核对有界整数范围、文件采样率、显示秒与原范围、两个音轨的源文件及精确相邻关系；相邻计划保留各轨整数起止，不混用 75 帧与采样时间基准。

音频 IPC 升为 1.23，宿主声明 `source-sample-span-v1`；有采样范围时 Main 要求此能力。请求的 `sampleRange` 使用规范十进制字符串保存采样整数，显式 rate，明确是否存在下一段。WASAPI／ASIO 共用原生 `source-sample-span.hpp`，拒绝字段缺失、非规范整数、越界、非相邻下一段或与旧范围冲突。实际解码率必须与声明率一致，原生按原整数定位，完整源长度、首尾及恢复位置约束继续检查。

Main 在正式播放计划与准备证明里独立比较原采样起止和两段整数边界，再沿用现有开始确认、实际时钟、处理、曲尾与释放流程。ASIO 的直接帧书签继续保留文件绑定与配置核对。本批不改变 DSD 原始位时间基准；仅 ASIO 实机验证仍暂停。

## 歌词与波形

媒体协议升为 12，歌词上下文增加可选 `cueIndex01Seconds`，保留旧七字段／75 帧路径，严格检查新 INDEX01 在源范围内及与旧帧的一致性。标题同名歌词相对于 INDEX01 换算，整文件歌词仍按源时钟裁剪；非 75 帧不会被解释成 75 帧偏移。

整曲波形请求升为 2，算法／指纹升为 `minmax-f32-v4-sample-span-ma-0.11.25-ff-8.1.3-dsdpcm-v1`；旧缓存记录保留，但不能冒充新算法结果。独立波形进程核对实际解码率并按原始采样范围顺序定位与分析；Main 对新结果及缓存复用都比较 rate／start／end，保留原文件摘要、原请求身份与当前曲目指纹核对。

播放详情用明确的每秒采样数和采样位置显示非 75 帧 INDEX／起点／子索引；标准 CD 与外部文本仍显示分秒帧。原文解释按钮只适用于外部文本 CUE。

## 验证与保留范围

Main／Renderer 类型及最终构建、生产原生与既有金样仅编译整体 exit0、4 个发行 CommonJS 脚本语法、发行生成文件和最终分发清单核对通过（193 模块／主块 463.89kB，gzip 142.75kB）。晚期 Main／资料审核补充后重建并刷新清单；工作区根的一次类型命令因缺少 package.json 退出 1，正确项目目录最终命令退出 0。未运行 SQL、迁移、应用、媒体进程、音乐、驱动或测试。MVP 需要覆盖非对齐起止／多轨 INDEX00／隐藏前导、旧标记重探测及引用保留、采样率改变／过期源、实际首尾与双轨边界、WASAPI 共享／独占和转换、ASIO 软件与故障、暂停／seek／设备切换、歌词标题和整文件时基、波形定位及缓存、实际 UI。

非音频轨、无 INDEX01 的位置集合及未知完整采样数仍未提供分轨播放；保持诊断与当前原资料保护行为。文本 CUESHEET 注释逐轨名称、不可变内嵌原文历史／导出、完整间隙编排与去加重、跨文件无缝仍需实现；实际原缺图未复现确认。未决恢复继续／回滚与新进程所有权、当前 WAL、标签格式与文件系统认证、更多在线来源、插件、多窗口和 macOS／Linux 继续。全部 FR01–FR14／WP01–WP11／G1–G5／AC01–AC19 的原始范围保留，没有因本批源码接通完成任何运行验收。
