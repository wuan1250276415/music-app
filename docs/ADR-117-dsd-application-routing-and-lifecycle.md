# ADR-117：DSD 应用路由、位数书签与宿主退出闸门

日期：2026-10-03。状态：源码、类型与编译检查通过；运行与数值验证集中到 MVP，ASIO 实机验证继续搁置。

承接 [ADR-115](ADR-115-asio-dsd-private-session-and-bit-tick-bookmarks.md) 和 [ADR-116](ADR-116-dsd-presets-and-dop-device-profiles.md)，对应架构 FR03／FR09／WP02／WP07。只保存档案不足以完成应用播放，Main 必须在当前曲目、文件与输出配置一致时批准宿主计划，并在实际进程退出后重建或继续队列。

## 输出选择与范围冻结

ASIO 后端下的 DSF／未压缩 DFF 按 DSD 预设选择 Native、DoP、转 PCM 或停止。inherit 沿用既有 ASIO DSD 策略；WASAPI 仍使用自己的转换策略。没有静默回退到 PCM、自动混音、软件音量或隐式选用档案。PCM 文件仍走既有 PCM 路由。

Main 请求携带保存的驱动、明确的输出声道顺序、缓冲以及选用 DoP 档案的完整授权对象。DSD 源声道数必须等于映射长度，实际位率由宿主同一只读句柄读取；扫描缓存只作为可核对的已知速率提示，缺少速率也能准备。初始化后的驱动版本和源实际速率必须再次匹配档案。

音频 IPC1.22 扩展原始源范围：保留精确 startTick／endTick／initialTick，另外允许微秒或 CUE75 的绝对源范围和相对恢复微秒。宿主读取真实位率后做整数换算，Main 使用独立共享换算再次核对冻结计划；CUE75 采用原始位率的整数比例，不套用解码 PCM 帧。范围、有效总位数、只读文件绑定、原始布局、处理阶段、缓冲与输出必须全部一致，才能发送 planToken 批准启动。

Native／DoP 独立跟踪器严格校验准备、活动状态、位置与计数、快照、尾部和重建回执。事件代际和原命令身份与当前阶段一致，时钟与位数计数不得回退。原始状态单独发布为 `asioDsd`，不伪造 PCM decodedSource／处理链或 PCM 输出参数。

## 暂停、跳转、释放与队列

暂停／跳转／驱动变化使用宿主原始位数书签，保存实际文件绑定、位率、源范围、ASIO／后端修订与有效的设备档案身份。书签中的 frame 是兼容协调器的原始位计数，dsd 判别字段禁止把它送入 PCM 帧重建。驱动自动重建保留暂停状态并限制每分钟次数。

旧会话释放后，Main 取消其他进行中操作，等待操作系统确认宿主退出且退出码为零，再通过同一队列协调器重新读取当前曲目并批准新计划。原始宿主允许有界输入线程退休时间；未退出、非零退出、队列变化、休眠、操作取消或新档案冲突均阻止自动重建。暂停满 60 秒和系统休眠继续保留精确原始书签，恢复需要用户动作。

正常完成必须先进入尾部等待，再收到最终有效原始位数发布回执和完成尾部；Driver／来源释放标记不能代替操作系统退出证据。Main 在旧宿主正常退出后才发布 ended 让队列前进。进程退出通知可先于最后的管道数据，给予有界 250 ms 完成事件到达时间；管道结束却没有有效释放事件则失败。

原始 CUE 本批走普通逐轨队列转换；禁用 PCM 两段预排。每轨按原始 CUE75 范围准备，不声明跨轨无缝或连续同驱动会话。

## 设置变化与软件增益

正在使用的 DSD 预设或选用档案变化先释放输出，再持久保存并重新规划；inactive 档案编辑、普通 PCM 播放和 WASAPI 不因 DSD 档案修改重启。明确 stop 或归档当前 DoP 档案后不自动继续播放。

原始 DSD 拒绝软件音量、静音与 ReplayGain。Main 保存数字处理前检查当前原始会话，播放入口也再次检查；用户须先明确选择转 PCM 或停止。原始 DSD→PCM、Native↔DoP、驱动或档案修改使用新的配置和新计划，保留当前曲目、位置与暂停状态；不同时间基不复用 PCM 帧。无关档案导致全局修订增加不会使仍相同的选用授权失效。

详情显示实际原始来源、速率／声道、绑定范围、映射、承载单位、延迟、时钟依据、尾部与发布计数。播放栏显示驱动并使用硬件音量提示。原始 DSD 不启用 PCM 回调分析，界面明确独立 PCM 分析副本尚待接入；现有离线整曲分析与封面／歌词功能保持。
