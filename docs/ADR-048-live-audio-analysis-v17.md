# ADR-048：PCM 分析旁路、实时可视化与全屏播放

日期：2026-10-01。源码版本：0.43.0。音频 IPC：1.7。schema：v22 不变。关联 WP02/WP10、FR11、AC15。

## 功能与采样位置

播放详情新增可视化开关、64 频带频谱、各声道 peak/RMS、当前窗口波形与全屏播放按钮。数据来自正在播放的独立音频宿主，不生成装饰性频谱。全屏保留播放栏、歌词、队列和资料操作；关闭详情或检索跳转时退出本组件拥有的 DOM 全屏。

AnalysisTap 复制 PCM 环形缓冲消费后、WASAPI 后续适配前的有效解码帧，不包含欠载补零和结束补零。整数 s16/s32 或 float32 原输出字节保持不变；只有分析线程转换副本。共享模式后续重采样、格式／声道转换和设备实际输出不在采样点内；不能把可视化作为数字捕获、硬件模式或位完美认证。当前不支持 DSD 分析，因为 DSD 输出／转换主链仍未实现。

“实时波形”表示当前 2048 帧窗口的 min/max 摘要，不是整曲波形。整曲后台多分辨率摘要、缓存键、取消／续跑、DSD 分析及开放可视化插件契约继续开发。

## 实时路径与生命周期

固定 SPSC 分析队列为 32 个槽，每槽最多 512 帧、16 声道、4 字节／样本，总原始槽位容量 1 MiB。内存在启动输出前分配；回调只读取标量原子、检查容量、复制有效帧和发布游标，不分配、不加锁、不 FFT、不写文件或 IPC。单次复制上限 8192 帧；容量不足或超限丢弃整个分析块，递增分析丢帧计数。分析读游标不参与播放 PCM 游标与解码调度。

槽位先写内容后 release 发布 write 游标，消费者 acquire 读取；完成读取后 release 发布 read 游标。控制线程不重置 SPSC 游标。编译期要求回调涉及的 uint64_t/bool 原子在目标上始终无锁；同步规则参考 [C++ 原子次序](https://eel.is/c++draft/atomics.order)。这约束复制等待，不代替实际回调耗时验证。

独立 Analysis 线程处理格式转换、FFT 和统计，尝试降低线程优先级，参考 [Windows 调度优先级](https://learn.microsoft.com/en-us/windows/win32/procthread/scheduling-priorities)。分析异常关闭自身，不终止播放。线程优先级调用是否成功、CPU 和回调 deadline 仍待实测。关闭可视化时消费者丢弃已有块；seek、暂停、保存开关变化以原子 epoch 使旧窗口失效。数据不连续或 CUE 段变化时重新积累窗口，不跨丢块／跨曲做 FFT。

分析结果保存在一个受互斥量保护的最新摘要槽，控制线程 try_lock 获取，不能获得时跳过。音频回调不访问该锁。摘要在约 40 ms 间隔计算／发送，上限约 25 Hz，不积累结果队列；控制循环处理命令的检查间隔改为 40 ms，既有播放位置／缓冲诊断仍约 250 ms 发布。

## 统计定义

峰值和 RMS 按独立声道、最近一次发布后的有效帧统计；首个摘要需积累完整窗口。数值以 dBFS 表示，显示范围 -96 到 +24。非有限浮点副本用零参与分析，超过 ±16 的副本限制在该范围并计为异常样本；不改写播放样本。波形汇总全部声道每段 min/max，图形限制 ±1，过载仍由峰值读数体现。

频谱使用 2048 点 radix-2 FFT、Hann 窗和窗增益归一化。各声道分别 FFT 后合并能量，避免反相声道先混为 mono 而抵消；每个对数频带取所含频点最大幅度。从 min(20 Hz, Nyquist) 到 Nyquist 分为 64 带，无可用频点的带显示下限，不把邻带频点冒充该带能量。频率分辨率仍受 sampleRate/2048 限制，尤其高采样率的低频带不能据此精确测量；此视图不是测量仪器。

## IPC 与界面背压

IPC 1.7 握手新增 analysis-tap-v1 能力；playback.play 可传 analysisEnabled，analysis.configure 接收严格布尔 enabled，沿用当前会话／generation／命令回执，不修改播放 generation。playback.analysis 是带 sequence/generation 的可选摘要事件，含采样点、2048 帧窗口、采样率／声道、曲线、统计和分析计数，不传 PCM。

Main 校验版本、采样点、固定数组长度、数值范围、计数、CUE 段和曲目位置；分析事件只能使用当前 generation，过时或超前摘要丢弃，不能推进播放 generation。坏的分析 payload 丢弃，分析配置超时不触发播放 snapshot 对账或停止音频。既有协议封包／会话／序号错误仍按音频协议拒绝。切歌、暂停、seek、CUE 边界或关闭分析清除旧摘要；超过 500 ms 的摘要不返回，位置与播放锚点偏离超过 1 秒也不采用。

新增窄 IPC analysis:enabled / analysis:snapshot，限当前受信任窗口。Main 只保存最新摘要，不把 25 Hz 分析广播成全页面状态更新。组件以最多一个在途请求、通常 40 ms 间隔读取；慢响应只降低更新频率，不积压 Renderer 事件。Canvas 绘制仅由新摘要或尺寸变化触发，画布尺寸没有变化时不重复重建。系统减少动画设置把界面读取降为 250 ms，无补间动画。

关闭详情、暂停、页面隐藏、窗口隐藏／最小化及页面重载关闭分析请求；恢复播放／窗口后按当前界面选择恢复。Main 再依据窗口可见状态限制分析，避免单靠 Renderer 定时器。分析不是播放状态的拥有者，操作失败只显示可视化错误或等待状态。

## 验证与剩余门槛

按用户节奏仅类型、主进程／界面（52 模块）／原生组件构建及静态发行清单检查。没有执行新分析代码、单元、桌面、音频输出、负载、网络、SQL 迁移或安装包测试；本轮没有生成安装包。类型和编译不能证明频谱正确、无欠载或无陈旧样本。最新已验证安装包仍为 0.29.0；ASIO 实机验证继续暂停。

MVP 集中验证：已知正弦幅度／频点、Hann 增益、静音、正反相双声道、s16/s32/f32、NaN／过载副本及播放字节不变；窗口分辨率和空频带；满分析队列／故意慢消费者／超大块时只有分析丢帧；暂停／恢复、快速 seek／切歌、同文件 CUE 边界、未知分析命令回执及超时不停止音频；最小化／隐藏／重载／减少动画、全屏与焦点恢复；多声道和高采样率 CPU／内存、回调 deadline 与播放欠载开关对照。

AC15、G1 及 FR11 全部验收尚未通过。后续继续整曲波形与分析任务、格式／DSD、完整歌词和 FR01–FR14／WP01–WP11 其余范围。
