# ADR-196：RF64封面定位与WAV／DSF格式MVP

日期：2026-10-12。源码及内部试用包0.190.0。完整V1未完成。

## 缺口和实现

WAV及DSF已有直接ID3图片读取，但缺少实际格式矩阵证据。RF64在图片定位分支未识别，通用RIFF解析器也不能可靠处理ds64替代长度，可能遗漏音频之后的封面或阻止无图片回退。

按[EBU Tech3306](https://tech.ebu.ch/docs/tech/tech3306v1_1.pdf)读取第一个ds64块：32位哨兵由64位容器／首个data／额外块表长度替代；额外表按同名未使用条目顺序消耗，支持重复JUNK块。实际文件／容器边界及JavaScript安全整数范围核对，不使用32位位运算截断偏移。ds64最多1024表项，原32MiB累计读取／20秒／1024块／4个WAV标签／64图片／16转换预算保留。直接定位只读取头和标签，不读取音频载荷。

直接读取现在报告容器和完成状态；只有完整RF64 ID3遍历才可跳过不支持ds64的通用RIFF图片解析，确认没有可用图片后进入旁置阶段。不支持版本或压缩／加密／未知APIC格式标志令RF64读取未完成，保留既有通用解析尝试和可重试错误，不把未完成当作没有封面。已找到可用内嵌图片继续沿用既有优先级；未引入外部图片URL获取。

在线来源指纹版本更新，使此前遗漏RF64封面的在线参考重新读取；离线已保存图片不清空。字段／协议／schema未改变；RF64标量标签和全部解码／seek仍需独立完整矩阵，不能将本次图片验证扩大为格式认证。

## 运行证据
