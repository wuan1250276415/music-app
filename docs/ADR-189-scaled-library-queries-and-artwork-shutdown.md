# ADR-189：规模检索、分页读取与封面资源退出

日期：2026-10-11。源码0.183.0；schema72、音频IPC1.23、媒体14保持。本轮是内部MVP的规模验证与实际失败修复，完整架构范围不变，ASIO实机暂停。

## 实际发现与实现

一万条合成目录记录通过真实 `LibraryDatabase.upsertFile` 建立文件、曲目、目录关联、来源及检索索引。首次入库约196秒，基准请求格式错误随后修正，不能将该次脚本记为通过。发现新条目也执行全文虚拟表按未索引item_id删除，随库扩大造成无用扫描；仅在事务内确认为新playable_item且没有旧派生记录时跳过删除。已有条目及旧索引重建仍执行原删除路径，保持重扫和原文替换语义。复用已经读取的排序资料，避免再次读取完整目录投影。中间一万条入库约155秒，后续CPU分析发现重复SQL编译。

对目录、元数据标量／集合与检索模块中的私有同步run/get/all语句，使用每连接256项LRU、单SQL64KiB上限缓存；不缓存查询结果，不共享迭代器或可变返回／绑定选项。迁移完成、构造失败和关闭时清除缓存；其他连接使用独立缓存。规模入库与完整旧库索引重建耗时仍须单独验证。

实际首屏查询曾达到约16秒：SQLite在缺少统计资料时，版本数关联子查询选择active/visible索引，重复扫库。固定使用发行曲目关联索引统计版本数；按已召回item_id查询时使用曲目主键索引，避免少量精确／错拼结果也扫描整个目录。非静态歌单先排序并分页ID，再读取本页曲目、来源、CUE与版本数量；未过滤的全部／最近添加计数直接使用有效曲目索引。歌单继续保留重复entry、顺序与位置语义；筛选、版本折叠、排名、精确总数及浏览快照保护保持。

此前正常退出仍可能向已退出Library发送封面租约请求。ArtworkResources现在在before-quit同步关闭新资源入口，停止重置任务，等待在途读取／租约与清理工作，清除Library租约后释放缓存；有效的晚到release无需再次访问服务，新retain被拒绝。该关闭Promise纳入原1.5秒有界退出收尾，窗口关闭及导航不再重复启动清理。超时不构成所有资源已排空的证据。Main的原frame校验和租约字段校验保持。

## 一万条规模证据

这是合成目录／生产SQL与索引基准，不是实际扫描一万个音频文件。固定语料定义、SHA、实际环境、首调用及热索引p50/p95/p99、次数、数据库规模见[JSON报告](validation/v0.183-library-10k.json)和[运行日志](validation/v0.183-library-10k.log)。报告为Windows x64、i9-12900H、约32GiB内存、Node24.19.0／SQLite3.53.3，每种请求12次；当时另有十万条入库工作，结果不能外推参考机器或无竞争环境。

| 请求 | 核心p95，约ms | 结果范围 |
|---|---:|---|
| 首屏／末尾分页 | 261／272 | 总数10000，各仅100首详情 |
| 精确标题／繁简标题 | 1／1 | 1／2项 |
| 全拼／首字母 | 6／5 | 22项 |
| 重音／英文错拼 | 2／1 | 各1项 |
| 风格限定错拼 | 2 | 1项 |
| 风格＋中文词 | 88 | 1249项 |
| 单字命中几乎全库 | 516 | 9991项，单列大候选 |

全部28项原真值、稳定首／末页快照、实际详情读取批次[100,100]、多艺人有序署名、双碟20轨排序及数据库重开通过。没有测量Electron端到端350ms或OS冷缓存启动；单字大候选耗时保留，不隐藏为普通搜索达标。

十万条生成工作已经启动，但截至此检查点仍在运行，没有十万完成／性能验收声明。该长任务加载的是分页进一步优化前的中间代码；其一致SQLite备份用于随后按最终源码重新测量，不能直接替代本检查点最终分页与详情批次证据。接续须先核对同一实际进程／会话的状态，不因日志暂时没有输出重新启动生成。

## 正确性、退出与迁移验证

最终分页源码下，MP3/WAV播放详情、FLAC/CUE及搜索三组隔离MVP脚本均退出0。详情脚本新增正常关闭后拒绝任何封面租约IPC失败诊断的断言，本次通过；不能据此证明崩溃、强退、维护中退出或全部在途超时场景。

现有目录／关联13项回归全部通过，覆盖多成员署名、同名不同发行、多碟、版本折叠、收藏及歌单重复条目、确认／撤销／重扫、数据库重开，以及受控v5／v6小库升级、备份与冲突回滚。初次失败中，旧测试夹具未撤去schema69–72的CUE字段／触发器，且在线候选缺来源链接和时间、迁移后仍硬编码68；已修正夹具与候选，不放宽生产来源／迁移校验。这些由当前库降构的受控旧schema样本不代替真实历史库、CUE历史及所有版本的完整兼容认证。

最终日志：[目录回归](validation/v0.183-catalog.log)、[MP3/WAV](validation/v0.183-core-detail.log)、[FLAC/CUE](validation/v0.183-flac-cue.log)、[检索](validation/v0.183-search.log)。主程序／界面最终构建与生产原生构建退出0；既有原生金样仅编译，本轮未重新执行全部金样。最终来源摘要见[摘要清单](validation/v0.183-source-fingerprints.json)。
