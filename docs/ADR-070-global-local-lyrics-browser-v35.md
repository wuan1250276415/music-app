# ADR-070：全库本地歌词原文目录与来源查阅

日期：2026-10-02。源码 0.65.0；schema v35；内部媒体协议 v5、音频 IPC 1.8 不变。

承接 ADR-069。架构 §17.1 的来源原文与用户显示设置分离、§23 的用户歌词保留要求不能只依赖曲目仍存在。0.64 的单曲历史读取需要当前条目，本批补全全库／已移除条目原文查阅、显式跨条目复制，以及用户导入版本到本地原文来源的查阅入口。

## 保留与查询

沿用不可变原始字节、解析文档、规范编码、来源摘要／ID、首次曲目范围快照和 local-private-v1 授权，不依赖音乐文件或原歌词文件仍可访问。历史表没有到当前 playable_item 的删除级联；关联曲目不存在时原文可独立读取。音乐文件离线但条目仍在时显示“音乐文件不可用”，与“关联曲目已移除”分别呈现。

全库入口由“用户歌词 → 查阅本地 LRC/TXT 原文历史”进入，单曲版本管理也可打开本地原文目录。检索保存的来源文件名、解析语言和首次曲目快照的歌曲／歌手／专辑；不声称是歌词正文全文检索，也不声称原曲目信息随当前元数据改动。可筛选全部／已移除／同条目全部范围、同步／纯文本和各来源最近保存版本。

查询使用参数绑定，LIKE 中的反斜线、百分号和下划线按字面转义。每页 20 项，创建时间／版本 ID 键集游标绑定规范查询摘要、关联条目、类型和最近保存筛选，禁止换筛选沿用旧游标。数据库当前最多 32768 个观察版本，列表不返回原文 BLOB；摘要字段和日期有界校验，完整原文在选中时读取。schema v35 增加全局创建时间／ID 索引，备份后事务升级；没有执行迁移 SQL，不宣称当前检索具备十万曲库基准。

当前范围／旧范围／已移除关联和文件可用状态来自当次曲库查询；原文不可变不等于这些显示状态冻结。目录订阅变化、查询序列隔离迟到结果；读取过程中变化时禁止复制，要求刷新。最近保存指针仍表示成功观察内容，不表示源文件当前状态。该目录没有自动更换主／辅助歌词，也没有把原文历史纳入可删除图片缓存。

## 原文校验与跨条目复制

独立读取路径复用既有原始字节长度／摘要、版本身份、快照摘要／范围／文件 ID、解析来源／路径／字段、严格编码与从原文重新解析核对。校验在历史数据内进行，不为读取历史重新打开失效的源路径。只允许 local-private-v1 本地原文复用，未来在线来源不能借此绕过许可。

用户明确选择一个保存版本和目标歌曲后，草稿保留原始字节、编码、语言和来源版本 ID，必须重新选择目标时间基、解析预览并确认。目标曲目仍由既有存在检查、范围／文档修订 CAS 和持久回执保护。复制提交重新完整验证保存来源，并核对草稿字节完全相同；允许复制来自另一条目或已移除条目的本地原文，而不是要求源条目存在。旧 CUE 时间不会自动绑定到目标范围。

新用户版本继续按目标范围和所选时间基重新解析。不可变复制关系与原文／状态／范围快照／回执同事务提交，原观察仍保留。用户原文目录增加本地复制来源标记和原文／范围查阅，读取时核对复制关系与导入回执记录一致。继续复制用户文档会沿既有用户文档来源链接查阅到原本地来源。归档／恢复仅影响用户版本状态，不修改原观察。

## 开发与验收边界

类型、Main／Renderer（65 模块）／原生编译、发行与分发清单及维护脚本语法静态核对通过。未运行数据库、迁移、单元、真实文件、目录／模态／焦点、播放或安装包测试；最新已验证安装包仍为 0.29.0，源码 0.30–0.65 待 MVP 集中验证。迁移 fixture 仅增加 v35 索引回退与目标断言，未执行 SQL。

MVP 要覆盖已移除条目回读、离线与移除区分、CUE 旧范围到新范围／其他歌曲复制、字节篡改、来源摘要／解析失配、换筛选游标、检索通配符、事件／切歌迟到隔离、来源查阅和未知提交结果重试，并验证 v34→v35 备份及迁移。

本批未实现嵌入标签完整原始字节观察、历史导出／受控恢复、自动离线采用、用户歌词数据管理、授权在线歌词、微秒区间／字级同步、统一取消和呈现时钟。512 MiB 历史原文字节上限不是 DB/WAL／备份磁盘限额。FR01–FR14、WP01–WP11 与 G1–G5／AC01–AC19 完整目标保持，ASIO 实机验证继续暂停。
