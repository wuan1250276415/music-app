# ADR-144 独立 ID3 内嵌图片读取与播放详情检索

日期：2026-10-06  
状态：0.138.0 源码实现；编译与静态核对，实际媒体与界面验收留至 MVP。

## 本轮需求与证据

用户要求优先显示歌曲自带封面，点击播放栏封面进入歌曲详情，并提供歌曲资料检索、封面、滚动歌词、播放模式和列表。

已有源码包含上述详情入口和交互。本轮检查确认两个具体问题：除标准 FLAC 原生 PICTURE 外，图片发现仍依赖通用标签解析；详情资料点击会保留之前的 MusicFilters，因而从队列打开的歌曲可能被旧评分、格式、艺人或统计条件排除。尚未运行用户缺图文件，不能确认原缺图案例的唯一原因或宣称实机修复。

## 封面读取

在原只读、授权句柄与一次性受监督媒体任务中新增 `id3-artwork.ts`。仅解析内嵌 APIC 图片，跳过其他帧的内容，不解析文字、音频数据或播放时长。

- 按文件签名定位文件开头的 ID3v2.3/v2.4、普通 RIFF/WAVE 的 `ID3 `/`id3 ` 块，以及 DSF 的元数据指针。WAV 根据块长度和奇数填充跳过音频；DSF 检查 28 字节头、总文件长度、fmt/data 块边界及指针不得落入音频块。
- 按版本读取普通或 synchsafe 帧长度，处理扩展头、v2.4 匹配尾部、group identity 和 data length indicator。v2.3 对标签体撤销 unsynchronisation，v2.4 只对标记帧撤销一次；支持相应单字节或 UTF-16 描述终止位置。
- 新通道只处理未压缩、未加密且格式旗标可识别的 APIC。图片 URL `-->` 不读取、不联网；未知版本、v2.2 PIC、RF64/Wave64、DFF、尾部单独 ID3、连续 ID3 标签和其他容器仍交由既有通用解析器，不新增格式认证声明。不校验 ID3 CRC，不以此证明整份音乐格式有效。
- 单次独立通道累计读取最多 32 MiB，20 秒，单标签最多 4096 帧和 64 图片，WAV 最多 1024 块和 4 个标签；所有返回图片合计最多 64。每图仍最多 16 MiB，并沿用内容嗅探、去重、16 次转换、解码尺寸和像素预算。标签体只读到受限自有 Buffer，unsynchronisation 原地处理，不修改文件。
- 正面顺序为原生 FLAC 正面、新 ID3 正面、通用解析器正面，再处理其他内嵌候选；所有内嵌候选先于目录图片。文字解析失败但已取得可显示图片时仍能返回。独立通道或通用解析器读取未完成、且无可显示内嵌图时，保留可重试错误，不将读取失败解释成无图并进入目录。
- 指纹更新为内嵌 v7、目录 v6，使在线旧目录选择也重新核对；离线或读失败的已保存图片恢复、来源限制、句柄观察、缩略图转换及资源租约继续沿用原路径。没有修改元数据或数据库结构。

依据：[ID3v2.3 §3/§4.15/§5](https://id3.org/id3v2.3.0)、[ID3v2.4 标签结构 §3/§4/§6](https://id3.org/id3v2.4.0-structure)、[ID3v2.4 APIC §4.14](https://id3.org/id3v2.4.0-frames)、[Sony DSF 格式规范](https://dsd-guide.com/sites/default/files/white-papers/DSFFileFormatSpec_E.pdf)、[Microsoft RIFF 块布局](https://learn.microsoft.com/en-us/windows/win32/xaudio2/resource-interchange-file-format--riff-)。

## 播放详情与检索

播放栏封面仍默认打开“歌词＋列表”，也可切换为独立歌词或队列。当前歌曲资料独立于曲库页面读取，切歌后旧歌曲结果不能覆盖新歌曲。

点击歌曲资料中的歌手、专辑、专辑概念、风格或其他署名后，优先以已有实体身份检索，并清除旧文字查询与组合筛选。风格点击保留这次明确选择的风格及下级范围；普通排序及版本折叠偏好保留。关闭详情并把焦点移到检索框，不修改正在播放的队列。

详情封面改为完整等比显示，非正方形图片不会被裁切；列表与播放栏仍按原缩略图布局显示。换歌重置“更多歌曲资料”的展开状态。原有歌词时间跟随、手动浏览暂停跟随、点击歌词定位、双语显示、顺序／随机／单曲或列表循环、队列搜索／定位／重排／移除和可视化继续保留。

## 验证及后续

版本、生成的发行身份、新模块源码摘要和解包校验清单同步更新。schema66、音频 IPC1.22、媒体协议10均保持。本轮类型、构建及静态核对结果写入实施状态；不执行应用、测试、媒体转换、SQL／迁移、硬件、驱动或安装器，不生成新安装包。

MVP 集中验收：

1. MP3/WAV/DSF 中正面与其他图片、损坏文字帧、不同描述编码、多图、重复图和目录竞争。
2. v2.3 标签体与 v2.4 帧 unsynchronisation、扩展头、尾部、group identity、长度指示；帧／指针／块越界、截断、URL、超限、压缩／加密与通用回退。
3. 在线旧目录缓存再探测、离线保存图片、转换失败、重试、文件替换和切歌旧结果隔离。
4. 原评分／编码／艺人／统计条件下从队列进入详情，资料点击应打开干净实体范围，切歌与检索焦点正确。
5. 宽窄窗口完整封面、详情入口、滚动歌词／双语／定位、模式切换、重复队列项与队列编辑。

真实缺图与详情交互尚未验收；完整架构工作继续，仅 ASIO 实机验证保持搁置。
