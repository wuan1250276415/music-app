# ADR-055：内嵌封面优先与播放详情完善

状态：0.50.0 源码实现；2026-10-01。schema v24、音频协议 v1.8 不变。按用户反馈优先完善封面与播放详情，ASIO 实机验证继续搁置。

## 封面读取与显示

固定依赖的 `selectCover` 实现使用图片 `name`，并用数组的 `in` 判断名称，不能可靠地按 `type` 的正面封面标识选择。现在由 Aural 显式识别 `Cover (front)` 等标识，保持原始顺序并将所有内嵌正面封面排在其他内嵌图片之前。没有图片时不调用空数组 reduce。图片的字节签名、大小和 Chromium 可显示性检查保持不变；不将未验证的图片当作已显示封面。

候选优先级为：内嵌正面封面、其他内嵌图片、与音频同名的本地图片、同目录 cover/folder/front。同名图片支持 JPG/JPEG/PNG/WebP/GIF/BMP；目录名匹配保留大小写兼容。CUE 虚拟轨继续读取其引用的音频文件，不把 CUE 文本当作媒体文件。损坏候选使用 token 排除后继续查找，一次仍最多尝试 8 个候选、总等待 45 秒。

候选现在携带来源类型和简短说明，曲目列表、底部播放栏与详情共用读取路径。详情在封面下显示“歌曲内嵌正面封面”“歌曲内嵌图片”或本地图片文件名；读取中、缺少图片、读取失败和图片无法显示分别提供提示。顶部“重新读取封面与歌词”继续刷新三个位置。

Service 的缓存键包含文件 ID、音频路径／大小／修改时间／变更时间以及目录属性摘要；读取前后检查属性没有变化。摘要是属性指纹，不是媒体内容哈希或文件锁。不同拒绝 token 集合拥有独立缓存项，共享并发回退请求，避免列表、播放栏和详情重复解析同一回退步骤，不替换未排除图片时的首选项。主动重读清除该文件所有候选项，重扫仍清空 Service 缓存。

两个进程的图片缓存继续限制 32 项、约 64 MiB 字符串载荷；成功项增加 30 秒有效期，失败或缺图不缓存。到期在下一次请求时重读，不自动轮询已挂载的图片。音频属性变化可在 Service 下一次请求时形成新键；原位修改本地图片可能需要等待有效期或主动重读。Renderer 的键加入路径与可用状态，避免同 ID 的文件移动／离线状态沿用旧图。未声称已有文件监听或完整读取取消。

## 播放详情

底部播放栏的封面按钮打开详情；已有歌手／专辑／风格及其他署名链接使用身份和角色进入曲库检索。详情显示大封面、曲目信息、歌词、模式和播放列表，播放栏保留播放、暂停、上下曲与进度控制。关闭按钮或 Esc 返回封面按钮，背景曲库在详情打开时不可交互。

歌词继续按当前播放时间定位和滚动，手动浏览暂停跟随，支持恢复跟随与点击同步行跳转；纯文本不伪造时间。来源、主／辅助歌词、偏移和字号沿用已实现的设置。展开设置的高度限制为歌词区域的 40%，设置内部可滚动，保留歌词显示空间。

播放列表继续支持点击播放、上移／下移和非当前项移出；当前项增加播放标记，列表显示歌手与专辑，长文本可通过提示查看。顺序／列表循环／单曲循环与随机开关使用既有队列业务和持久化接口。歌词与队列滚动限制在自身区域。

## 验证边界

本轮类型检查、主进程／界面（55 模块）／原生及凭据组件编译、发行／分发清单静态检查和 DSD gold 运行脚本语法检查通过。受控 FFmpeg 构建产物与既定 recipe 匹配，DSD 软件 gold 程序仅编译，未执行。运行验证集中到 MVP，不运行新单元、桌面、实际用户歌曲、音频、数据库迁移或安装包验证。最新已验证安装包仍为 0.29.0；本次源码不证明用户当前安装包或具体歌曲已经显示正常。

MVP 验证项：背面在前／多个正面／无内嵌图片／损坏候选／错误 MIME；内嵌与同名／目录图片并存时的优先级；文件修改／原位图片修改／重扫／主动重读／离线恢复／快速切歌；列表、播放栏和详情的一致性；详情所有身份检索入口、歌词滚动与展开设置、队列模式和编辑、最小窗口及键盘交互。FR01–FR14 与 WP01–WP11 范围继续保留。
