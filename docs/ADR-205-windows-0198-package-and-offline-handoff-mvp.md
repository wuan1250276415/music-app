## 首次失败及校正

首次尝试给发布程序传入夹具预加载开关，程序未执行该预加载，实际取得了网络结果，因此断言失败。`v0.198-package-fixture-preload-first.*`保留为失败证据，不计入通过范围，没有封面／资料保存。测试工具现在在创建曲库和启动进程前拒绝“发布可执行文件＋在线夹具”组合；发布在线验证只使用已配置的有效公开联系信息与真实网络，夹具阶段使用原先已验证的源码包装入口。
