# ADR-211：ISRC 来源读取、候选查询与审核

状态：0.204.0源码；集中MVP结果由本版checkpoint归档。Windows优先，仅ASIO实机验证暂停。schema75、音频IPC1.23保持；媒体读取协议升至16。

## 来源及数据模型

扫描从受监督的music-metadata读取文件ISRC标签，原始字符串集合保存在既有item_catalog_source JSON中，不把它们写入Recording外部身份。大小、成员和文字预算沿用媒体契约；新增闭合字段使媒体读取协议从15升为16，旧协议回执不能冒充新协议。

CUE使用cue_track保存的当前虚拟音轨编码，包括外部CUE和已读取的内嵌编排；未提供编码的音轨不继承整张镜像的ISRC。尚待审核的CUE解释暂不用于编码查询。库内旧文件需要重新扫描才能补齐此前未采集的文件标签；已保存的CUE音轨编码可直接读取。

规范化只接受12位ASCII编码或标准分段连字符形式，保留原始观察值；规范结果去重。前后空格和大小写可规范化，不把全角、任意分隔符、控制字符或“ISRC”前缀强行转成有效编码。无效项显示数量提示，不导致同文件其他正常元数据丢失。

非空编码原始观察摘要纳入既有条目修订。真实扫描改变编码，再改回原值，也不会恢复旧候选权威；没有编码的旧条目沿用原修订输入，不进行全库结构迁移。读取上下文还绑定当前文件观察、CUE范围、录音引用及本地修订，派生发行和署名候选继承私有约束。

## 查询与审核

用户在元数据面板明确选择有效来源中的ISRC并请求查询。编码缺失或不属于当前歌曲来源的调用者输入拒绝；不接受同时指定MBID和ISRC。正常查询优先已确认MBID；没有有效歌名但有编码时先返回待选择状态，不自动把编码当作确定身份。

使用既有受控网络broker请求ISRC资源，校验响应编码、每个录音标识、标题、署名及发行列表。支持最多100个录音，每个录音保留一个按上下文排序的发行候选，其他发行版通过既有分页浏览；不按20条普通文本搜索上限静默丢弃其他录音。重复录音、错误编码、超预算或失败明确拒绝；空结果保持空结果，不静默改做标题搜索。

ISRC只是证据。候选显示编码、来源关联录音数量、文字和时长差异，不编造搜索置信度。用户可分别审核录音身份、具体发行版和文本字段；仅保存文本不会建立录音引用或改音乐文件。已有录音引用时明确显示本次是编码辅助查询，其他录音候选显示冲突提示，原引用保持。

协议依据核对于2026-10-14：[MusicBrainz API](https://musicbrainz.org/doc/MusicBrainz_API#isrc)；JSON字段根据[官方ISRC序列化代码](https://github.com/metabrainz/musicbrainz-server/blob/master/lib/MusicBrainz/Server/WebService/Serializer/JSON/2/ISRC.pm)及[官方查询测试](https://github.com/metabrainz/musicbrainz-server/blob/master/t/lib/t/MusicBrainz/Server/Controller/WS/2/JSON/LookupISRC.pm)核对。没有复制官方实现代码，使用现有客户端约束解析接口。

## 集中验证和边界

新增数据MVP16项通过，包含实际监督媒体进程扫描FLAC Vorbis、MP3 ID3v2.4 TSRC、CUE到生产SQLite；验证原始观察／无效项提示／音轨隔离、真实文件编码重扫与恢复修订、非唯一候选、不自动建立身份、错误／重复／超预算／空结果、100个录音完整保留、派生发行／署名失效、查询期间源变动、schema75备份检查及重开、外键／完整性和原始夹具保持。

实际Electron/Main/preload/Service链最终63项通过，增加文件导入、两编码明确选择、两录音显示、来源外编码拒绝、空结果不回退、明确标题保存、音乐内容不改、真实编码编辑／恢复、已有身份保留及冲突提示、媒体离线重启查询。查询网络是明确fetch夹具，源码重启也沿用该边界；不注入候选或授权凭据，不代表现实ISRC真值集验收。

首次桌面检查暴露测试等待异步扫描的方式可能在实际终态前返回；已根据当前Playwright实现改为显式await应用读取，并修正启动索引／扫描等待。扫描等待失败保留；后续成功提示定位器曾误把包含撤销按钮的整段文字作为完全匹配，改为实际成功区域并核对保存值。重启对账曾使在途快照发生变化，正确拒绝已保留；最终等待实际对账并仅对明确资料变化拒绝使用新请求，最多两次重试，其他错误不重试。最终数量、退出码、当前源码摘要及界面截图见checkpoint。保存后审核面板读取实际曲库条目刷新标题；选择状态以当前条目ID核对，保留用户后来选择。标题刷新首次断言没有先取消其他预选字段，实际歌手也已保存；最终明确只选歌名，核对歌手／专辑保留以及实际面板标题更新。核心详情／FLAC-CUE回归在面板刷新修正前通过；最终字段保存／面板刷新由63项桌面流程复验。
