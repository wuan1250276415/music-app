# ADR-049：整曲波形后台任务、内容缓存与跳转

日期：2026-10-01。源码版本：0.44.0。schema：v23。音频 IPC 保持 1.7。关联 WP03/WP10/WP11、FR11/FR13、AC15。

## 用户行为

播放详情新增按需生成整曲波形。支持任务阶段／进度、取消、重新核对文件、放大／缩小／移动可视范围、点击波形和键盘进度条跳转，以及最近 20 个任务状态。普通文件分析完整可播放范围，CUE 按当前虚拟轨的整数范围分析，不把同一镜像文件的其他曲目混入图形。

第一次请求会读取完整文件计算 SHA-256，再分析曲目范围；复用缓存时也重新核对内容，不用 size/mtime 推测内容未变。大文件核对可能耗时，界面区分“核对文件内容”和“生成波形”。关闭详情或切换曲目取消本组件拥有的未完成任务；重启后旧未完成任务显示“已中断”，重新发起使用新 UUID，不自动把未知结果改为成功。

播放模式和实时频谱仍由既有播放链负责。整曲波形是独立、只读后台分析，不写标签、不创建音乐副本、不启动音频设备，也不向界面发送 PCM。当前适配 FLAC/WAV/MP3；其他格式、DSD、多语言歌词和完整任务中心继续开发，不将 FR11/FR13 标为全部完成。

## 媒体进程与文件一致性

新增第一方 waveform-worker.exe，复用仓库锁定的 miniaudio 0.11.25 和 nlohmann/json。Library Service 只接受当前曲库条目 ID，在内部解析范围及所属目录；执行前核对原范围指纹、可用状态、realpath 包含关系和普通文件属性。Renderer 不能传路径或原生程序地址。

Windows 组件使用 CreateFileW 的 GENERIC_READ + FILE_SHARE_READ，持有只读句柄，在最终句柄路径上再次验证所属目录。读共享、写入／删除共享冲突及属性访问边界依据 [CreateFileW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew)。该措施不声称隔离内核、特权进程或证明所有远程文件系统行为；本地盘、UNC、共享冲突、目录重解析点及长路径仍需实测。组件为盘符／UNC 使用扩展路径，避免依赖 MAX_PATH；路径只经私有标准输入传递，不进入进程参数或错误输出。

使用 Windows CNG SHA-256 流式读取，参考 [BCryptCreateHash](https://learn.microsoft.com/en-us/windows/win32/api/bcrypt/nf-bcrypt-bcryptcreatehash) 与 [BCryptFinishHash](https://learn.microsoft.com/en-us/windows/win32/api/bcrypt/nf-bcrypt-bcryptfinishhash)。哈希对象缓冲区由 RAII 对象拥有，先销毁哈希句柄后释放内存。读取完毕后对同一句柄复位，使用公开 miniaudio VFS 接口提供 read/seek/tell/info；解码器不再次按路径打开文件，因此不会因为父目录重解析点变化而换读另一个文件。

结果发送后继续持有句柄，等待服务校验当前条目／范围并提交 SQLite 缓存和完成记录，收到 commit 确认才退出。完成记录是已保存分析摘要，不是音频输出验证。提交后确认管道丢失不盲目重写音乐或重新分析；同任务 ID 返回已保存结果。进程退出后外部文件仍可变化，下次请求会重新核对 SHA-256。

组件尝试使用 PROCESS_MODE_BACKGROUND_BEGIN 与较低线程优先级，参考 [SetPriorityClass](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-setpriorityclass)。后台模式也涉及资源调度，不能仅调整 CPU 就声称磁盘负载无影响；调用结果、CPU/I/O、播放缓冲和回调 deadline 需在 MVP 对照验证。组件监视 Library Service 的进程句柄，父进程退出则停止自身；不是完整跨平台 Job Object 实现。

## 分辨率与数值

算法标识 minmax-f32-v1-ma-0.11.25。解码使用源采样率、全部声道的独立 float32 副本，以最多 4096 帧块处理；不读整曲 PCM 到内存。最多 8192 个基准时间桶，短曲采用不超过样本帧数的二次幂桶数。基准桶聚合全部声道 min/max，再合并为最多 128/512/2048/8192 桶层级，去掉重复分辨率。层级嵌套，不跨范围边界合并。

min/max 向外量化到 1e-4，保留摘要包络；非有限样本按零、超过 ±16 的副本限制到该范围并计数。整轨 peak/RMS 按全部有效样本统计，dBFS 显示限制 -96 到 +24；图形限制 ±1，峰值读数可显示过载。解码不足预定范围、范围越界或未知长度均失败，不把不完整结果保存为完整波形。CUE 时间使用既有 75 fps → PCM 帧转换，保存实际起止 PCM 帧与时长。

缓存键包含算法版本、完整文件内容 SHA-256、采样率／声道及起止 PCM 帧。条目路径／文件身份／范围指纹只负责引用和任务冲突检查，不作为内容修订的替代。图形选择适合当前宽度和缩放范围的层级；实时频谱与整曲波形显示不同采样窗口。

## 有界任务、协议与恢复

每个 Library Service 最多一个运行分析进程、两个等待任务。创建任务使用 UUID 身份；重复 UUID 返回原记录，不创建第二个进程，不同曲目复用被拒绝。进度约 500 ms 更新，阶段内进度不回退；界面最多一个在途状态查询，不广播大摘要或每次进度到整个页面。

原生私有管道使用 UInt32LE 长度 + UTF-8 JSON。请求上限 128 KiB、单响应 512 KiB、读取缓冲 1 MiB、最多 5000 个消息、错误输出最多 4 KiB、任务默认最长 30 分钟。格式、哈希、固定算法、分辨率、数值范围、整数帧和时长关系均验证。普通错误不向界面回显文件路径。

运行任务先标记 cancelling，再请求进程停止；只有 close 事件确认退出后才标 cancelled 并启动下个任务。尚未启动的任务可直接取消。超时或观察迟缓不作为已退出证明，不以此并行重启另一个媒体进程。后台 SQLite 失败不主动崩溃曲库服务，也不能伪造持久完成；重启后未终结记录改为 interrupted。当前重新发起从头核对／分析，没有块级断点续算或全库自动排程。

缓存载荷采用 LRU，逻辑载荷预算 32 MiB、最多 1024 条，未超预算时不读出全部淘汰候选。删除缓存时级联清除引用、历史任务保留但结果引用置空。这个预算不等于 SQLite 文件／迁移备份的物理大小上限。缓存可重新生成，内容不属于用户资料编辑历史；任务身份不可改写。近期列表只读状态，不为列出任务加载全部波形。

曲库变更事件保守清空当前图形并取消未完成请求，重新核对后可复用内容未变的缓存。实时外部文件监听尚未接入，未重扫／未重新核对时不能证明外部文件仍与最后一次图形一致；这属于 FR13 剩余范围。

## 跳转、schema 与分发

整曲波形、歌词和播放进度条通过兼容的可选 expectedItemId 提交跳转。Main 检查当前曲目，排队 seek 保存创建时的曲目身份，执行时再次核对；跨曲排队请求拒绝，不把旧波形位置套到新曲。Native seek 仍沿用现有 generation 与 CUE 协议；这不替代完整呈现时钟和快速 CUE 边界门禁。跳转上限受当前播放时长及当前波形时长约束。

schema v23 新增 waveform_cache/reference/job、LRU／近期任务索引和任务身份保护。v22 安装增加版本条件保护；已有库升级前保存 pre-v23 一致备份，在事务中提交新增表与版本。旧测试夹具的逆迁移／版本断言维护到 v23，仅维护夹具，没有运行 SQL 迁移测试。

原生构建加入 waveform-worker.exe；打包资源、安装目录哈希核验和报告清单包含该组件。没有新增 npm 或第三方原生依赖；许可仍使用已有锁定组件及应用 GPLv3。这里只接入打包配置，没有生成或验证新安装包。

## 验证与剩余门槛

本批次类型检查、主进程／界面（53 模块）／音频与凭据组件及波形组件构建通过；交付前核对发行／分发清单和脚本语法。没有执行新分析程序、单元、实际波形／跳转、SQL 迁移、桌面、负载、网络、凭据或安装包验证。最新已验证安装包仍为 0.29.0，ASIO 实机验证继续暂停。

MVP 集中验证：静音／脉冲／正弦／反相多声道与分辨率包络、短于 128 帧、长曲、FLAC/WAV/MP3、源范围／跨文件 CUE 负例；文件内容变化且 size/mtime 相同、Unicode/长路径/UNC、重解析点及现有写句柄冲突；结果提交确认丢失、结果截断／非法值、取消启动／计算／保存阶段、父进程退出、组件丢失、30 分钟超时、队列满；v22 备份迁移、LRU 淘汰／外键、重启中断／重复 UUID；缩放／移动／键盘／切歌陈旧请求拒绝；播放时 CPU/I/O、缓存冷热开关、回调 deadline 和欠载对照。

AC15 尚无运行证据。继续其他格式／DSD、后台分析断点与完整任务中心、歌词偏移／双语／逐字、文件监听，以及 FR01–FR14／WP01–WP11 全部剩余范围。
