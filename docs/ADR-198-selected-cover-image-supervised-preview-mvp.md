# ADR-198：选定在线封面图片的受监督临时预览

日期：2026-10-12。源码 0.192.0；最新内部试用安装包仍为 0.190.0。本次推进 FR06／WP08，完整 FR01–14／WP01–11／G1–5／AC01–19 范围继续，仅 ASIO 实机验证暂停。

## 问题和结果

0.191 的候选审核只能显示选定发行版的 CAA 来源文字。现在可以主动预览其中一张图片：服务核对当前曲目、候选、资料指纹、发行版及图片条目，通过受控网络取得图片，再交给独立受监督媒体进程转换，最终由 Main 提供应用内部的临时图片地址。

这是从来源索引到实际图片展示的进展。**确认保存到曲库、在线封面引用／历史／撤销、离线保留、备份恢复、导出及文件标签写回仍待开发。** 临时预览不会修改当前本地封面，也不会把在线图片标为 embedded／sidecar。

架构将文字数据和图片操作分别建模。此次返回 `status: unverified`、主动临时显示、仅会话内存、`persist: false`、`export: false`；这描述实现开放的操作，不构成逐图片许可验证。社区审核状态仍只表示来源整理状态。

## 完整请求和清理路径

1. 用户选择有效 MusicBrainz 候选的发行版，查询 CAA 索引，再点击具体条目的“预览图片”。界面不自动下载所有图片，不提交远程 URL 或任意文件路径。
2. Library Service 使用已有来源设置与查询取消表，核对曲目 ID、候选 token、审核指纹及当前数据源状态。所选图片 ID 必须属于重新读取的有效索引。
3. 查询索引后、下载后、转换后均重新检查候选对象、曲目资料、取消信号、来源开关及到期时间。预览期限取有效候选／索引／图片回执的最早期限。
4. 图像字节暂存于本次新建的私有目录，只创建 `image.bin`；记录文件身份与观察值。媒体进程以只读文件句柄解析，输出不带本地来源类别的 JPEG、原图 SHA、宽高。
5. Main 在服务等待前捕获窗口／曲库代次，注册结果时再次核对。只向界面返回随机化的 `aural-artwork://preview/{id}.jpg`，界面安全策略保持原样，不添加 `data:` 或远程图片来源。
6. 关闭、替换、迟到或身份不符的界面回执会释放图片；Main 另有到期定时器、16 张／32MiB 上限。文档重置、曲库变化、来源设置变化、网络暂停、维护和退出清除临时图片并淘汰旧代次。
7. 临时图片响应使用 `Cache-Control: no-store`，防止浏览器把已释放的地址留作图片缓存；已有本地封面地址及租约流程保留。

暂存清理只删除本次持有且身份未变化的单个文件，然后删除空目录；检查绝对父目录、随机目录名、实际路径、符号链接和文件 dev／ino／观察值。原生媒体进程退出未确认时保留暂存，避免在仍有进程读取时删除。完整异常退出暂存恢复与清理策略仍需后续故障矩阵验证。

## 网络、图像和进程边界

选定图片使用 CAA 的具体图片 1200 缩略图接口，从 CAA 入口开始请求；官方接口定义见 [CAA API](https://musicbrainz.org/doc/Cover_Art_Archive/API)。不使用索引内未经校验的任意图像地址。

- 沿用 CAA 至少 1100ms 调度间隔、18 秒单次尝试、45 秒单操作总期限、最多 3 次尝试及 16 项排队。服务整个预览另限 80 秒，Main 请求上限 90 秒。
- 手动跳转最多 3 跳，只接受 HTTPS、同一发行及所选图片的 Archive 缩略图路径。拒绝其他图片／发行、原图路径、假域名、查询参数、凭据、额外端口及循环；跨主机仅保留公开 Accept／User-Agent。
- 二进制能力响应最多 16MiB，校验 MIME 与图片头，下载中超限也拒绝。图片不进入原 JSON 查询缓存；文字索引短期缓存仍保留。
- 通过现有 Windows Job 监督的媒体适配器转换，原生转换器仍受该 Job 生命周期约束。沿用媒体进程取消、超时和退出确认机制。
- JPEG 最长边 1024、最多 2MiB；协议回执继续限制尺寸、字段、消息大小和读前／读后文件观察，原图 SHA 必须与下载一致。

新增来源中立的 `image` 请求，因此媒体协议从 14 升至 **15**，并更新严格分发检查；schema73、音频 IPC1.23 不变。兼容构建标识仍继承 0.187，实际编译文件以本轮 SHA 核对。没有新增持久在线图片数据库结构或改变已有封面缓存引用。

各分段证据不能合并成“真实歌曲匹配→在线图片确认应用”的端到端验收。临时预览的保存按钮尚未开放，试用安装包仍为 0.190.0；实际安装流程历史证据仍为 0.29.0。本轮未重跑十万正式性能、OS 冷启动、八小时运行或 ASIO／Native DSD／DoP 实机。

保留首轮失败：原生检查尚要求媒体14，更新为媒体15及新增转换／no-store 检查后重建通过；下载测试误将文字索引缓存也要求为零，以及使用无效维护 owner，修正测试后通过；隔离界面模拟到期值正好位于跨进程十分钟边界，改为明确处于有效期限内后 17 项通过。生产期限没有放宽。最终报告绑定当前源码／编译文件指纹，失败记录单独保留。
