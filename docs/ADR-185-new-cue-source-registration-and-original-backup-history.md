# ADR-185：新 CUE 来源登记与原备份历史

- 日期：2026-10-11
- 状态：0.179.0 源码接入，运行验收待 MVP
- 对应：FR02、FR04、FR07、FR13、WP03、WP04、WP06、WP11；承接 ADR-183、ADR-184

## 行为

已核对的外部 CUE 备份可以登记到当前曲库已有的音乐根目录。用户明确选择根目录并输入 CUE 相对路径；建立新的目标来源 UUID，保留原备份的身份和字节。原备份根目录身份不构成当前目录授权。登记不创建磁盘文件、不自动选择原文或启动扫描；之后仍须复审、明确选择并扫描音乐引用。

根目录身份和当前路径重新核对。目标路径必须规范化且位于该根目录内，拒绝路径越界、Windows 无效字符、设备保留名称、尾部空格或点。已有来源冲突返回拒绝结果和明确打开原来源的入口，不自动合并。

## 没有磁盘观察的来源

schema72 增加独立 registered_at 和不可变登记命令回执。新来源的 latestVersion、磁盘摘要、编码、解析器、间隙政策和观察时间保持空值，登记时间不代替磁盘观察时间。历史列表使用真实观察时间或独立登记时间分页。选择、复审和导入的 latest 比较支持空值；旧请求和原回执保持原内容。

目标来源、当前派生解释、原备份资产、历史代次及原命令结果同一事务提交。登记与已有来源导入共用原备份资产和命令预算。原 UUID 可查询原结果；界面未知结果重试沿用原 UUID。跨重启的完整未决操作恢复尚未验收。

## 原备份历史与导出

导入版本关联的原备份按每页20项列出，路径展示最多1024字符并标明省略。列表只读取记录资料；打开或导出时独立核对完整备份 SHA、严格 UTF-8、规范字节、原文、原解析结果及 v42/v43 版本摘要。

查阅返回有界预览，完整内容仅保存在 Library/Main 私有流程中，并绑定当前原窗口文档。重新导出保存原备份的完整字节与原身份，不使用当前目标来源改写旧备份。原生保存入口保持不覆盖已有文件及完整摘要核对。原版本时间不称为原备份文件的保存时间。

## 选择前释放播放

新来源尚无旧 CUE 编排，引用的普通完整音乐文件仍可能正在播放。选择前的私有范围查询包含现有文档和当前引用音乐文件；若命中当前、预备或保留播放资源，则停止并等待音频及 DSD 分析资源实际释放。最终接受仍在事务中重新核对当前引用与复审摘要，预查询不是应用许可。

## 验证与边界

最终 Main/Renderer 类型检查与构建、生产原生组件及既有金样仅编译、4个发行脚本语法检查、发行生成文件及分发清单核对均通过。没有执行应用、SQL、迁移、解析器、worker、真实音乐、文件导出、驱动或运行测试。新备份捕获使用 schema72；旧68–71资料保留实际版本，旧整库恢复仍需独立候选升级。

文件字节身份、目录别名与授权生命周期、复杂 CUE、内嵌及批次导入、完整恢复和故障演练仍需实现或验收。全部 FR01–FR14、WP01–WP11、G1–G5、AC01–AC19 继续；仅 ASIO 实机验证暂停。真实歌曲缺图尚未复现确认修复，最新运行验证安装包仍为0.29.0。
