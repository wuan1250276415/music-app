# ADR-147 播放历史一致快照与有界流式导出

日期：2026-10-09；源码版本：0.141.0；schema68及音频IPC1.22保持。状态：源码实现，运行验收待MVP。

## 范围与交付语义

FR07／WP06补播放历史资料导出：导出当前搜索和可选单曲范围内全部已保存记录，按稳定历史id倒序。导出既有旧version1和新version2统计记录，包括播放时的标题／歌手／专辑、逻辑session／队列entry／item身份、曲长、累计设备回报与估算时长、最远回报位置、当次规则、计次状态、最近观察时间及其依据、保存更新时间。

不读取音频或标签，不访问数据源，不删除历史，不修改统计与当前规则，不重放播放，不导入回曲库。导出文件不是完整曲库备份，也不是原检查点JSON／SHA回执的字节存档。用户歌词、收藏／评分、队列、全部元数据、凭据、配置和迁移快照不包含在本文件中。

Main在选定保存位置后尝试刷新待保存播放历史，再观察记录状态，随后请求独立只读快照。pendingAtRequest带UTC观察时间、enabled、pending数量和error，描述建立快照请求前的观察，不保证与快照建立瞬间完全同时。无法核对或仍有待保存条目时，文件说明和完成信息明确仅导出已保存的数据；原pending文件不修改为导出完成、不删除或绕过失败核对。

## 一致性与隔离

新增固定入口history-export-worker，由Main以utilityProcess启动，128MiB V8 old-space预算。Renderer只提交经过规范化的操作UUID／格式／历史检索范围，不能提供输入、输出路径、SQL或进程入口。曲库文件路径由Main从既有userData／library／library.db推导；保存位置只能来自本机SaveDialog。

Worker仅以DatabaseSync readOnly打开既有普通曲库，禁止扩展加载，query_only=ON，缓存2MiB，锁等待1秒。schema必须为68、日志必须已经是WAL；不调用LibraryDatabase构造函数、不迁移、不改变日志模式、不执行业务写入。BEGIN后的首次读固定SQLite读视图，后续全部历史行和统计规则都使用同一连接／同一事务，读取完毕后ROLLBACK并close。

只读事务仍可能使用SQLite的WAL共享内存协调；不宣称“不触碰任何SQLite附属文件”。128MiB是JS堆预算，不是Windows Job级总提交内存或CPU隔离。同步查询在独立进程内执行，不占用单写入Library进程的事件循环；数据库及磁盘读负载、长时压力和音频欠载仍待MVP测量。

Worker读出的不可变库来源UUID必须与Main从当前Library连接取得的来源一致，文件头同时绑定规范检索范围和pending观察。库服务退出、系统休眠、主文档失效或退出会使任务停止；发布前再次核对可信主文档及曲库就绪状态。

共用ADR-139历史query plan，沿用播放时资料子串搜索及单曲过滤，参数化SQL、不另建不同搜索语义。导出不用当前页面cursor或仅当前50行，也不运行全库COUNT／SUM。以snapshot ceiling与严格下降id分批扫描；原数据的修改或新增不会进入已固定视图。

## 协议与预算

每批最多32条，每个结构化消息最多1MiB。每批只有Main完成对应写入后才ACK；Worker一次只保留一个待确认帧，15秒无写入确认失败，不预生成所有记录。帧严格绑定操作UUID、sequence与类型，重复／错序／越界拒绝。

存档身份JSON最大32KiB，SELECT先用CASE防止把超限身份完整带入JS；原行session／entry／item／created_at必须与冻结身份一致，0／1计次字段及完整版本结构严格核对。新规则必须与同一快照内对应不可变规则修订完全相同，已计次的行必须仍有该次规则的达标依据。坏记录拒绝整次导出，不静默跳过。

Main再次核对结构、固定范围、下降身份和消息顺序，独立累积次数与BigInt时长。Worker完成总计必须与Main接收的记录一致。总时长以十进制字符串写入summary，不用SQLite SUM或JS Number对长期合计作不精确近似。

整次导出最大100万条／512MiB；准备与读取10分钟预算，另观察快照期间WAL较开始大小的增长，每秒一次、增长超过128MiB中断。超预算明确要求缩小范围，没有“成功导出前N条”的降级行为。只读进程收到停止／失败后先请求取消及kill，Main每秒继续尝试kill；**实际exit事件**才解除进程owner。最终成功要求完整done、正确总计和actual exit code0，不能用done或取消请求代替实际退出证明。

原生文件系统I/O可能在取消后仍需等待，发布阶段不接受用户取消；不声称所有磁盘操作都能在墙钟预算内被强行终止。发布阶段若应用关闭而不能完成，不记录为成功。

## 文件结构

| 格式 | 结构与用途 |
| --- | --- |
| JSONL | UTF-8无BOM；首行header，后续每行type=play，末行type=summary；保留原文字、原身份、version2完整规则snapshot |
| CSV | UTF-8 BOM／CRLF，固定21列，header／play／summary三类行；展示常见资料与微秒整数，规则JSON和导出说明另列，适合表格查看 |

CSV所有单元格带引号，原引号双写；首个非空白字符为=／+／-／@的文本加单引号前缀。它会改变这些文本的CSV呈现，需要保留原文字和结构时选JSONL；不把CSV重新保存后的文件宣称为原导出。CSV并非完整无损恢复格式。

文件头含format=aural-playback-history、version1、encoding、schema、snapshotAt、origin、规范scope、ceiling及pendingAtRequest。旧规则标识fixed-v1：设备回报达到曲长一半或240秒（较短者），短于30秒时95%且到达对应位置，未知曲长240秒；新行保留其version2完整rule与revision。available状态不导出，不用历史资料推断当前文件仍可播放。

末尾summary带complete=true、记录数／次数／精确合计及SHA-256。摘要覆盖summary前的**全部UTF-8字节**，CSV包括BOM、列名、header和全部play行；不包括summary本身，不是整个文件的SHA，也不是数字签名或来源认证。完整性必须结合末行、摘要和总计判断；缺失末行、摘要不符或表格软件修改后的文件不能视为原完整导出。目前未提供应用内文件导入或验证工具。

## 发布与退出

在所选真实目录创建wx／0600的私有UUID临时文件，逐批写入，不一次缓存整个文件。先等待只读进程实际正常退出，再写summary，sync并close；复核选定目标的原文件观察后发布。

原有目标必须为普通文件，替换使用同目录rename；这是观察后替换，不是文件系统CAS。新目标优先link实现不覆盖发布；不支持hard link的文件系统退到COPYFILE_EXCL并同步。后者可能在复制中断后留下部分目标，不能承诺原子可见或所有目录项断电耐久，完成标记和摘要用于识别未完整复制的文件。

仅清理本次确实创建的私有临时文件；清理失败不把已经发布成功的文件改称失败。失败发布不会任意删除目标，因为目标可能已由其他操作创建／更改。崩溃私有临时文件治理仍待实现。

应用退出把导出退出等待加入原1.5秒有界退出流程；退出超时不等于导出成功，可能保留临时文件。Main只保留当前／最近一次请求及结果，同进程同UUID重试会复用原操作，不再弹窗；该完成记录证明原发布，不能证明文件后来仍存在。跨进程重启没有持久导出回执或自动重试，需检查原保存位置后显式重新导出。

## 界面与验收

“播放历史与统计→导出播放历史”提供格式、当前范围导出、进度、停止与刷新。进行中的范围固定显示，修改历史浏览条件不改写正在导出的范围；关闭面板后重新打开可读取Main任务状态。选择位置与发布阶段不提供停止按钮，处理中段可以停止。进度通知最多约10次／秒，状态查询仍返回最新累计值。

类型／构建／发行静态核对结果写入implementation-status；schema68无新迁移。本批不运行应用、SQL、Worker、文件对话框、真实文件导出、测试、媒体、驱动或安装器。

MVP集中验收：空历史、混合版本、已移除曲目、搜索转义／单曲／多页全范围；并发检查点与规则变化的一致快照；来源不符、坏JSON／身份／规则／计次／长字段；序号及ACK异常、进程退出先后与取消／休眠／服务退出；待保存失败及不同时间观察说明；BigInt总计、字节摘要、CSV公式文字／引号／中文和编辑后失效；同名目标变化／链接／普通文件覆盖／无hardlink复制；字节／条数／时间／WAL预算、磁盘满／断开、遗留私有文件、窄窗口／焦点／重开任务、读负载与音频欠载。

历史清理与保留期、规则历史治理、完整备份恢复、跨文件无缝、多窗口、跨平台、Provider／插件生命周期、写回认证及完整架构其他未完成项继续；FR07／相关AC未验收，ASIO实机仍搁置。
