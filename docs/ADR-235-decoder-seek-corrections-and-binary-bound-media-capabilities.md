# ADR-235：解码器跳转修正与实际构建绑定的格式能力清单

日期：2026-10-17。状态：短素材软件解码／精确跳转MVP和当前共享静音桌面链路通过；完整FR01、AC04及设备精度未完成。

## 发现的问题

第一轮直接调用生产AuralPcmDecoder的独立软件工具，12组WAV／FLAC／ALAC整数输出通过，但10组有损文件全部出现跳转错误：MP3向前定位后的样本错位、AAC从时间戳零刷新后与顺序输出不同、Vorbis及Opus部分定位失败。以明确非静音的整数序列生成输入，每个目标窗口对照完整顺序解码，避免仅检查命令返回或时间条位置。

## 修正

MP3的底层原始游标含编码延迟，不能作为可听样本的逻辑游标比较。第一方适配器独立记录已返回的逻辑帧，向前丢弃到准确目标，向后重新初始化同一个只读句柄并丢弃前缀；未修改第三方头文件。流程保留取消和20秒时限。

AAC的priming／噪声合成状态不能仅由codec flush恢复。向前保留原状态，向后从已验证句柄重建原点。其余有损格式的起始预滚同样不把demux seek到时间戳零等同于重新打开；可靠索引仍保留，定位失败时重新初始化并有界重解码。索引预滚允许负时间戳的起始块，按实际源样本裁到目标，不把合法priming块直接误判为失败。

AAC/MP4存在解码器未裁去的最后一个部分帧。仅当首个有效源时间戳与流起点一致、流时长可精确换算为整数源帧时，以该权威时长作为最大输出边界，不进行额外起始裁剪，不重复删除已被解码器去除的内容。48kHz、3.25秒样本由原156672帧恢复为准确156000帧。裸ADTS没有可靠时长／padding依据时继续保留解码结果，不通过静音猜测裁剪。

AAC原点重解码及索引回退的长曲性能尚未验收，不能把短样本正确性解释为完整高效索引实现。源解析／解码／跳转在非实时线程执行，音频回调仍只消费既有有界数据。

## 可复现的格式证据

22份固定生成素材覆盖WAV、FLAC、MP3、AAC/MP4、AAC/ADTS、ALAC/MP4、Vorbis/Ogg和Opus/Ogg；输入为确定的双声道整数序列。生成器使用本机ffmpeg8.1.1编码，仅用于制作自有测试素材，二进制不分发；实际应用解码仍使用固定miniaudio0.11.25和本项目FFmpeg8.1.3库。编码参数与每份文件摘要保存，不在测试时随意重编码。

34组运行包含12组整数输出、12组无损浮点输出和10组有损浮点输出，每组35次前后／边界定位，共1190个窗口。无损输出直接比对独立生成的PCM字节；有损比对本解码器完整顺序输出。所有窗口实测最大误差为0，未扩大原2e-6浮点上限来使失败通过。输出时长、末样本与AAC/MP4边界同时检查。

得到33个唯一组合，Opus的两种输入采样率素材都编码为实际48kHz来源，合并为同一组合，不把44.1kHz编码输入误报为44.1kHz Opus解码能力。组合包含实际demux容器、codec-context档位、源位深与输出表示，不能按后缀推断。

## 当前构建与界面

音频宿主构建前后比较50项本地音频源文件摘要，保存输入和实际宿主／FFmpeg库摘要。完整测试报告通过后才生成MediaCapabilityManifest；原始证明去掉临时绝对路径后随清单一起分发，清单绑定宿主、四个实际媒体DLL、探针及证明摘要。

Main的只读接口核对当前应用版本、证明和组件摘要后返回覆盖表。实际播放来源增加可选的容器及编码档位资料并严格解析，旧兼容来源缺失资料时不声称匹配。播放详情显示准确组合是否有短素材软件解码／跳转验证，始终保留长曲、设备输出与无缝待验收的说明。没有修改原有hardwareVerified／bitPerfect认证事实。

打包流程在本次二进制构建后重新执行软件格式验证，再生成清单和分发记录；解包检查要求实际打包组件及原证明与清单相同。本阶段仅接通流程，未执行新安装包生成、安装／升级或签名验收。

## 集中验证

| 范围 | 结果 |
|---|---|
| 独立软件解码／定位 | 34组、1190窗口、33组合，全部通过 |
| 实际桌面链路 | 4场景，8种真实文件共享静音播放／暂停跳转 |
| 原生CUE／ring软件回归 | 2项通过 |
| DSD位序／packer等软件回归 | 13项通过，设备打开0、ASIO载入false |

桌面验证通过实际Main／Library／Renderer和重编原生宿主读取8份复制素材，选择WASAPI shared并先显式静音；源容器／档位与时钟回执可核对，2.75秒和0.05秒暂停跳转接续正常。打开“播放与音频信息”后可见软件覆盖；复制组件改动一个字节后，旧证明立即失效。全部当前素材摘要保持不变，未访问用户曲库或原音乐。

此链路使用本机Realtek默认端点，仅证明应用在该次运行中接受输出与逻辑位置回执，不能替代数字捕获、扬声器听测或DAC位完美验证。软件金样不打开设备。实际ASIO验证仍暂停。
