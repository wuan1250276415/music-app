# ADR-222：打包运行与实际0.201旧库升级 MVP

状态：0.215.0内部开发包集中MVP通过；完整V1未完成。2026-10-15。

对应WP01/03/08/10/11及AC11/14/15/17/19的部分证据。覆盖本轮实际打包程序，不把来源替身、软件金样或一次共享播放当作全部验收。

**0.215.0 Windows 打包运行与实际旧版升级 MVP**：已重新编译原生组件并生成未签名开发安装包。Main／Native 构建标识同步为0.215.0，schema79／媒体16／音频IPC1.23保持。包内全部编译文件、许可资料和25个EXE/DLL的哈希核对通过。

实际Aural.exe集中8项通过：正常目录导入6项WAV/CUE/FLAC、内嵌正面封面优先与目录回退、静音WASAPI共享流、播放详情的队列／模式／歌词跳转滚动与实时分析、后台整库识别暂停续办、逐字段审核计划离线执行撤销及重启保留。用实际0.201.0打包程序创建独立schema75曲库，再由0.215.0升级到79；收藏／评分／重复歌单条目标识保留，升级前快照、完整性和外键通过。四次正常退出未发现见证进程残留，隔离假凭据清理完成。

提供的《晴天》FLAC经只读检查没有原生PICTURE块；其副本显示目录封面。另用保留音频字节的FLAC金样加入前／后封面，验证正面内嵌图优先。用户原文件和原曲库未修改。在线链使用仅允许两个来源的回环TLS代理及每次生成密钥的子进程SPKI固定；ASAR未修改，但目录选择与TLS配置由测试设置，不能当作真实在线匹配真值。未安装系统根证书或设置全局代理。

界面定点重试8项与原完整桌面组合81项回归通过，复选框实际16×16并与文字对齐；新原生IPC/CUE/PCM4项、DSD软件13项、指纹18项和真实FLAC官方工具对照3项通过。本轮不重复旧版105项跨页全链路，历史证据保留其版本范围。安装包尚未实际安装／升级安装／卸载，未签名；硬件认证、十万真实库、8小时、300案例真值、多来源、完整写回恢复及发布门禁仍继续，仅ASIO实机验证暂停。详见[ADR-222](ADR-222-packaged-runtime-and-actual-201-upgrade-mvp.md)。

测试入口为`node tests/electron-packaged-mvp.smoke.cjs`，先执行`npm run package:win`。需设置AURAL_BUILD_OUTPUT、AURAL_LEGACY_EXE、AURAL_PLAYWRIGHT_MODULE、AURAL_PYTHON及AURAL_FINGERPRINT_REAL_MEDIA；测试固定使用D:/CodexTestData的独立目录。真实媒体路径对应已获准只读验证的文件，原始SHA需匹配测试断言。Python需cryptography；旧版解包程序必须真实存在。当前入口不是可直接在通用CI中运行的测试。

代理只转接api.acoustid.org和musicbrainz.org，其他CONNECT拒绝并记录；Chromium自身的redirector请求也被拒绝。生产Provider、凭据读取、原生指纹及网络实现均运行包内字节；测试不替换fetch、不更改ASAR。Main的证书回调观察在最终运行中为空，证书接受由启动时精确SPKI设置完成，不以空回调记录冒充验证。开关含义依据[Chromium官方源码](https://chromium.googlesource.com/chromium/src/+/main/services/network/public/cpp/network_switches.cc)，仅作用于隔离子进程和当次新密钥，不使用全局忽略证书错误开关。

进程见证绑定真实Main PID、准确exe和创建时间；只接受包内子程序及其系统conhost。CIM首次采样可能包含刚退出且路径为空的子进程，重新采样确认不存在才排除；仍存在但不能确认身份则失败。普通关闭失败才在原见证范围强制清理并判本次失败，PID复用不得误杀。最终四次均正常关闭，无强制清理。

前几次失败记录保留：错误地假定用户FLAC有内嵌图片、未滚动离屏图片、跨进程参数漏传、仅配置Main证书回调不足、旧版短命子进程取证，以及独立只读SQLite完整性检查缺少CUE索引函数。修正测试装配后完整8项重新执行通过；没有通过放宽产品断言跳过旧库数据或完整性检查。

新原生构建不复用0.214检查点的二进制摘要。原0.214源码包／检查点保持；0.201安装包和解包程序保留。0.215开发包未签名、未执行安装程序，不声明安装器升级卸载、完整发布、位完美或设备认证通过。继续完整FR01–14／WP01–11／G1–5／AC01–19，ASIO实机验证单独搁置。
