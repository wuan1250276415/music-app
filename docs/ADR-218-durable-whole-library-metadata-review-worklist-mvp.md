# ADR-218：持久整库元数据审核工作清单 MVP

状态：0.211.0源码集中MVP通过，完整V1未完成。2026-10-15。

对应FR06／WP08及任务中心、恢复要求。本轮扩展整库审核的范围与持久进度；识别与远程候选仍需在领取的页面中主动运行，字段和发行版逐首明确选择。没有将排序改成自动覆盖，也没有把有限工作清单描述为已经完成无人值守后台任务中心。

schema76新增metadata_workflow、metadata_workflow_item、metadata_workflow_command及索引／不可改写身份和回执触发器。任务创建在同一个IMMEDIATE事务中按可见active歌曲ID固定范围和稳定ordinal；每项持久原始item_id，移除不会导致分页位移或抹去异常。后来添加的歌曲不自动进入旧任务。最多32个未完成任务、每任务100万逻辑项；这些是防护上限，不是百万首性能认证。SQL选取每页最多100项，主表保存当前页私有令牌与10分钟期限，行区分pending／reviewing／planned／skipped／failed。

任务名称／范围和行身份不可改写；命令有闭合读者、UUID及修订CAS，原请求规范化后与持久回执核对。同一命令重放返回既有结果，不重新推进或逐出其他预览。UI结果未确认时保留原请求，只读回执核对区分已提交与未提交，不盲目新发。当前UI待核对请求本身仍属于界面会话，重启可从持久任务列表检查实际结果；跨窗口命令意图持久化和完整恢复故障矩阵未验收。

领取时当前已删除或隐藏的成员标记failed并记录原ordinal／item_id和原因，不让范围静默变小；其他有效项仍能审核。用户可查看明细、恢复来源后重试异常项。暂停释放本页未保存项但保留已保存计划；取消只跳过未完成项，不能通过重试隐式复活。明确勾选并确认后可跳过本页未保存的歌曲。未勾选的同行在计划保存后仍待审核，不会当作成功，也不会自动跳过。已经planned仅表示持久审核计划存在，执行／冲突／撤销状态继续由原计划独立管理；清单明细保留原计划ID。

整库页传入既有批量审核。页来源由Library核对，不接受调用者自选其他曲目；MusicBrainz私有预览期限被父工作页限制，AcoustID私有关联沿用该范围。暂停／取消／释放或完成保存会关闭所属MusicBrainz和AcoustID预览，取消实际在途查询，晚回应不能重新签发有效候选。重复回执不会产生新的UI状态变更事件。任务页关闭后同一候选不能再绕开任务作为独立新计划使用。页面重新读取和逐首选择沿用0.210的单曲／批量来源与文件观察校验。

MetadataBatch支持在已存在的SQLite事务中用savepoint运行命令。工作清单保存外层事务先核对页归属和全部选中item，再创建不可改写计划及其原回执，最后只把所选行标成planned并链接batch_id，释放同行未选项。任一末段失败一起回滚；不会出现计划已保存但清单仍可重复认领的半结果。既有非任务请求／回执形状保持；任务新请求才增加workflow来源。旧批次“重新审核”生成独立新计划，不携带已失效任务页来源，原工作清单进度保持。

普通服务重开将ready任务和未结束页标记为需确认继续，清理页令牌／期限并把未保存行恢复pending。恢复暂停连接不运行任务恢复或启动网络；正常释放准备阶段才进行恢复。只有用户继续后才能领取新页，不能重用此前候选或原始指纹。原始AcoustID指纹及远程关联正文仍不持久化，计划仅保留既有合法字段来源及公共领域标识映射。领取异常是持久失败；网络和识别失败当前仍在审核页显示，尚未变成持久后台执行阶段／分类重试策略。

升级75→76沿用已验证快照和结构／关键计数核对后事务DDL。数据库现版本门禁、备份元数据／预览／兼容性与历史导出schema读者同步到76，保留识别旧68–75归档的能力；整库应用仍要求当前结构，旧归档需显式迁移，不能在暂停恢复里静默改写。schema76只读结构／领域检查新增metadata-workflows，核对范围总数／连续序号、领取上限、令牌、计划成员链接与命令读者。此前online-artwork领域的schema75数量判断也统一为>=74，当前76为十域。旧二进制不能直接共享76数据库，不宣称完整降级或历史升级／恢复发布矩阵已验收。
