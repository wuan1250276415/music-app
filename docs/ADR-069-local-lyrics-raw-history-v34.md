# ADR-069：本地歌词文件原文历史与显式复制

日期：2026-10-02。源码 0.64.0；schema v34；内部媒体协议 v5；音频 IPC 1.8。

架构 §17.1 要求原文、编码、解析版本、语言、来源、范围及授权与显示设置分别保存。本批实现本地 LRC/TXT 的原始字节历史，继续使用受监督读取；歌曲内嵌歌词仍只有标签解析结果，不把标签解码文本称作完整标签原始字节。封面内嵌优先和播放详情继续保留，相关设计见 ADR-055/061/064/065/066/067。

## 读取与协议

sidecar 通过已授权目录内的同一只读句柄读取，沿用读取前后属性／路径核对、严格 UTF-8、UTF-16LE/BE、GB18030 解码与解析限额。有效且实际返回的 sidecar 文档携带原始 Base64、SHA-256、规范编码、来源路径、读取前属性和解析来源 ID；保留 BOM，原始字节不由解码文本重新编码产生。解析为空、损坏、超预算或未被选入返回集合的文件不保存。

媒体协议升级 v5，返回观察数组并逐一核对来源、规范 Base64、原始长度、摘要和每个 sidecar 的对应关系。最多 16 个来源，每份原文不超过 1 MiB，总原文不超过 16 MiB，解析文档集合不超过 1.5 MiB；歌词响应单独限制 26 MiB，其余任务限额不变。26 MiB 包含原文 Base64 放大和解析结果，不代表允许无限内存；Job 的 128 MiB V8 旧堆／384 MiB 单进程／512 MiB Job 和时间限制仍生效，大文件并发场景可能触发预算，真实峰值待 MVP。监督进程退出确认及不确定退出停止调度保持原机制。

Library Service 检查曲目仍存在及范围、可用状态、标题、文件属性版本仍一致后保存观察。存储失败追加可读提示，仍可返回当次已解析歌词和用户导入来源；原文历史事务提交与事件送达分开，不把通知失败报成保存失败。父进程的异步文件观察并未全部硬隔离，也不是完整 FileID／reparse／授权租约保证。

## schema v34 与容量

新增不可变 `lyrics_local_version`（原始 BLOB、摘要、解析 JSON、编码、来源、解析器版本、首次保存曲目范围快照、快照摘要、读取观察、local-private-v1 授权）、可更新的 `lyrics_local_latest` 和不可变 `lyrics_document_local_origin` 复制关系。升级前备份，事务创建表及约束；旧应用拒绝高于其 schema 范围的库。只修改历史 fixture 的降级脚本和目标版本断言，没有运行迁移 SQL。

版本 ID 由曲目范围、来源路径、原始摘要、编码、解析来源 ID 与固定解析器版本构成；重复内容复用既有版本。一次观察批次的新增和最近保存指针原子提交。每范围最多 64 个版本／32 MiB 原文，总计最多 32768 个版本／512 MiB 原文；满额时整个观察批次回滚，既有原文不作为封面缓存删除。该限额不覆盖解析 JSON、索引、SQLite 页面、WAL、备份及其他业务数据，完整磁盘管理仍待实现。

“最近保存”表示该范围／来源路径最近成功保存的内容版本；来源离线、缺失或读取失败时不清空它，不等于当前文件状态。恢复旧内容会重新指向旧版本，不生成每次读取的时间日志，首次曲目快照和创建时间保持不变。

## 查阅与导入

歌词管理增加“本地原文历史”，按当前条目全部历史范围有界分页，每页 20 项，游标绑定曲目与创建时间／ID。原文不可变，但分页期间最近保存标记可能变化；重读可刷新。历史读取验证原始字节／版本身份／快照摘要、解析字段和来源路径，并用固定解析器重新解析原文核对来源 ID。文本、哈希和原曲目范围可查看。

“复制为导入草稿”直接复用不可变原始字节，重新读取目标范围和文档修订，必须显式选择当前曲目时间或源音频时间，再预览和确认。Library 校验历史来源属于同一条目、授权与原始字节完全一致，提交时保留既有范围／修订 CAS 和持久回执；新文档与复制来源关系同事务保存。旧范围历史允许同条目复制，不能静默套用旧 CUE 时间。

本批没有自动离线采用历史歌词、全库／已移除条目的本地观察浏览、观察历史导出、自动清理或完整嵌入标签原始字节保存。用户导入歌词仍可通过既有原文目录浏览。完整来源复制关系的全库 UI 追溯、统一取消、授权在线歌词、字级同步和呈现时钟继续实施。

## 验证边界

按既定开发节奏，仅进行类型、Main／Renderer／原生编译、发行与分发清单及维护脚本语法静态检查。未运行单元、数据库／迁移、真实 LRC/TXT、进程／内存、播放、界面或安装包测试；MVP 集中验证时覆盖 BOM／严格编码、偏移与双语、CUE 旧范围复制、内容往返、重复观察、容量事务回滚、未知保存结果核对和 v33→v34 迁移。最新已验证安装包仍为 0.29.0，ASIO 实机验证继续暂停，FR01–FR14 与 G1–G5／AC01–AC19 完整范围不缩减。
