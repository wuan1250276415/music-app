# ADR-152 持久备份记录与当前文件核对

状态：源码已接入，MVP运行验收待完成。日期：2026-10-09。版本：0.146.0。

## 问题与决定

0.145已接通一致快照及备份保存，但Main内存状态不能证明重启前操作完成，也不能证明保存文件当前仍有效。使用独立于活动SQLite的私有操作登记，在原生文件选择、快照、打包和发布的边界保留证据。界面提供历史及明确只读核对；不自动续跑、发布、恢复或删除工件。

## 操作登记

`userData/backups/operations/<UUID>/`只包含连续`0000.json`至`0031.json`以及至多一个`manifest.json`。创建目录须独占，登记文件须`wx`，完整写入并`sync`后才接续下一动作。记录规范字段及UTF-8字节、操作身份、序号、前条SHA256、合法状态转换；原保存位置、私有临时位置、父目录身份及目标初始观察、快照来源、完整工件证明、发布结果不可改写。清单独立保存并由后续记录绑定摘要，避免每条重复最多2MiB的清单。

首次登记在打开选择框前；选择登记在冻结前；快照登记在生成进程前；完整工件证明在进程独立复核及实际exit0后；发布意图在目标变更前；完成结果及实际发布文件证明在保存后持久化。取消或失败尽力追加原状态，记录写入不确定时保留已有字节，禁止覆盖或推断成功。快照清单落盘但登记未完成的清单保留，不按文件名收编。

普通目录逐级lstat和realpath核对；记录须单链接普通文件，打开句柄与命名文件在读取前后观察一致；追加前重新核对完整原链和目录身份。256项操作、每项32记录、192KiB单记录、2MiB清单；目录计数以opendir有界读取。历史列表仅读取记录链，不读取全部大清单；每次列表读取预算64MiB，达到后说明结果部分读取。达到操作或检查点预算则拒绝新操作，暂未自动清理。未知文件、损坏链、缺口及部分写入保留并在界面报告。

文件sync不是目录项断电持久性或跨文件事务证明；SHA链是损坏检测，不是抵抗本机账户替换整链的签名。逐级观察不提供OS排他目录锁，这些限制留在MVP故障验证及后续平台强化范围。

## 重启与只读核对

界面通过可信Main frame的固定history/verify接口读取列表；verify只接收原UUID，路径和原清单由Main登记读取。操作记录中的completed表示当时完成保存的证据，历史显示“保存完成，当前文件待核对”，不会凭旧回执声明文件当前有效。进程重启不会重建旧维护占用，也不会执行旧意图。

核对重新验证完整登记和原清单，检查保存目录物理身份、目标普通单链接类型和大小；有完成回执时还要求原发布文件身份。固定独立进程执行完整容器逐文件及完成摘要校验，返回清单必须等于原快照，摘要与长度必须等于原工件证明，且实际正常退出。Main再次检查目标身份及校验后的文件观察，持久化核对回执后才显示checked。核对不停止当前曲库、不构造数据库仓储、不迁移或应用恢复，不读取音乐目录源文件。取消、界面重载、休眠、服务退出及应用退出继续终止原进程，实际exit决定所有权结束。

原操作没有发布完成回执但目标全量内容符合原证明时，显示“内容一致，原保存回执未确认”，不伪造publication类型、文件创建身份或已完成保存结果。已有完成回执且当前文件核对通过则显示“文件核对通过”。结果只代表当次读取，并附核对时间；目标变更、缺失或原目录替换拒绝通过。

发布流程额外捕获目标文件证明：rename/link路径要求实际文件句柄与命名目标同身份；link后原临时名移除未确认时不能给出单链接完成证明；复制路径保留第二独立进程证明。登记完成前再次核对目标观察；失败保留原文件和工件，不删除或自动重试覆盖。
