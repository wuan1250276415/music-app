# ADR-174 原生切换退出凭据审核与全局记录补记

状态：源码实现，运行验收待 MVP。日期：2026-10-10。版本：0.168.0。

## 问题与决定

原生目录切换有四项持久阶段及实际正常退出记录，全局恢复事务还需要单独追加完成记录。程序可能在两者之间退出：物理切换和原退出凭据存在，全局最后一项仍为 `move-intent`。启动页保留并阻止打开曲库，但此前没有可审核、可持久处理这一差异的入口。

新增明确审核后的 `move-reconciled`，把原先已取得的实际退出事实补入同一规范全局链。该动作不重复运行原移动命令，不模拟旧进程退出，不取得旧曲库维护租约，也不声明整库恢复完成。缺少原生退出凭据、缺口、未知文件、目录冲突或内容变化时拒绝这条路径。

## 原证明与实际内容

原目录日志的加载结果新增已严格验证的实际退出物理证明；历史规范字节没有改变。审核须满足以下条件：

- 全局原候选、关闭及实际退出记录可独立完整读取；最后一个移动尚无全局完成记录，事务未终止或完成。
- 原移动请求与全局意图完全一致；原生四项阶段、规范退出记录、请求/退出摘要和物理证明均存在。
- 任何可写激活意图都没有出现。激活意图本身就足以排除这条路径，不以缺失的激活成功回执推定没有发生写入。
- 原登记根身份仍一致，来源位置缺失，目标目录身份与原请求相同；固定曲库根的全部文件、大小、角色和 SHA256 与原移动清单相同。WAL/SHM及未知工件不作为旧 DELETE 清单的一部分接纳。
- 全局记录、原生记录、两个槽位再次读取，完整启动历史和当前目录检查再次执行；与原观察不同则审核失败。

读取使用原主frame/文档代次、当前服务不存在的检查、实际在途 Promise 和45分钟预算。逐文件读取可响应中断；既有规范记录读取仍须等原读取实际结束，不把导航、超时或取消当作证明已经退出。没有启动 Library、SQL、设备或后台旧任务。

## 用户审核和持久决定

核对页为具有未决移动及已登记退出记录的事务提供审核入口。实际审核可能发现条件不足并拒绝；只有完整审核成功才显示切换动作、文件数量/总大小、检查时间和诊断摘要，允许勾选后确认保存。页面明确指出曲库仍关闭，后续恢复步骤尚未完成。

4096字节明确确认仅包含原事务、原移动、新请求UUID、完整审核SHA和固定处理选择；不接受路径、原生证明、Main PID、恢复实例或任意移动动作。Main保留原审核所属文档与规范结果，对原UUID重试保留同一请求内容及实际工作；新请求、原请求内容变化、活动核对/报告/重启等不能混入。

确认后重新执行全部实际审核，比较所有原绑定字段。单独忽略新的检查时间，不忽略记录、目录、内容、请求/退出或完整启动历史摘要。存储层在追加前再次核对原退出、目录及完整目标内容。

不可变 `move-reconciled` 记录保存正常移动完成证明，以及完整原用户审核、其SHA、启动观察SHA、新请求UUID、本次Main实例UUID、实际Main PID/构建、接受时间和固定策略。当前写入只允许本进程和本构建。历史读取重新校验完整审核摘要、原父记录SHA、原事务/移动/动作/目录身份、原生请求和退出SHA、完整内容SHA与文件数量，拒绝重复补记请求UUID；同时重新读取原生退出链。历史读取不把旧PID视作当前活动进程。

该记录按照原规范 `wx`、同步及独立完整读回策略追加，不修改旧阶段或旧退出记录。断电/磁盘故障留下的部分记录继续保留并阻止启动，不删除失败工件或冒称保存成功。保存后的真实完整启动核对只更新观察；未决事务仍不会自动启动或继续移动。

## 协调与验证

只读重新核对、切换审核、报告保存、重新启动和补记工作互斥。新增工作类型区分，重新核对不能返回重启或写记录工作的 Promise 并把它伪装成一次只读观察。导航/休眠/退出清除旧审核并中断本次实际工作；应用退出等待原 Promise。普通曲库和播放业务入口仍封锁。

本批完成类型检查及 Main/Renderer 构建、生产原生和既有金样仅编译、CommonJS语法和发行静态核对；未运行应用、SQL/迁移、恢复、日志补记、媒体、驱动或测试。MVP集中验证实际 native-exit/global-intent 差异、旧请求重试、变更审核、记录缺口、目标改变、来源重占、缺失原生退出、激活意图后出现 WAL、磁盘满、保存中退出、真实重启读回和普通恢复完成链。

后续仍需实际未决移动的继续/回滚与新进程物理操作所有权、没有原退出凭据的独立核对、未持久完成的只读启动和可写准备恢复、当前可变 WAL 处理、原文复审及完整领域/迁移/配额等。全部 FR01–FR14/WP01–WP11/G1–G5/AC01–AC19保留，FR13/WP11/AC17未验收。仅ASIO实机暂停，真实缺图及播放详情待运行验证，无新安装包。
