# ADR-107：当前歌曲资料保留、封面重读隔离与窄窗口详情

- 状态：源码、类型与编译检查通过；实际文件及界面集中到 MVP
- 版本：0.101.0
- 日期：2026-10-03
- 关联：用户封面／播放详情反馈、FR04／FR10／FR11，WP04／WP05／WP10；延续 ADR-103／105

## 问题与实现

内嵌正面／其他图片优先、完整内嵌读取后目录图片回退，以及播放栏封面进入详情、歌手／专辑／风格检索、滚动歌词、播放模式与队列均已有源码。本批修复这些功能的刷新边界，不重复登记为全部新增功能。

当前歌曲独立查询的结果原来只在当前曲库修订匹配时可用。曲库修订后，若当前歌曲不在正在浏览的页和队列资料中，查询期间就会丢失展示值，封面组件也随之释放资源并重新加载。现在保留最后一次成功读取的同一曲目资料，优先使用当前页／队列提供的同一曲目预览，待独立查询返回后以其结果为准。失败保留同一曲目资料并显示现有错误；成功返回不存在则清空，切换曲目不会带入另一首资料。这只是刷新期间的展示保留，不改变播放前的文件／版本核对。

封面重读原来使用全局布尔状态，上一首慢请求会禁用下一首重读。现在按源文件去重，最多允许两个在途重读，旧请求完成只释放自身占位，不解除另一项的忙状态。新曲目可以在旧请求未完成时请求自己的封面；同源 CUE 仍共享一个占位。通知及错误同时核对曲目、文件和扫描观察身份，避免旧结果向新文件版本显示成功／失败通知。已有独立歌词刷新、监督任务、超时和资源租约路径保持；普通封面加载继续走原调度队列，重读并发限制不声称是全部媒体任务的全局限制。

详情图片重读按钮新增独立禁用状态，区分当前文件正在读取和两项并发占位已满；头部入口也使用相同限制。窄于 800 CSS 像素时详情改为可滚动单列，歌曲信息／封面上方、歌词或队列下方，两个内容面板各有独立滚动区；工具栏换行。正常宽度保留原左右布局。实际缩放、键盘与滚动交互仍需 MVP 验收。

## 验证与边界

Main／Renderer 类型检查及构建（106 模块）、原生组件编译、发行／分发清单与 41 个 CommonJS 源文件语法检查通过；Renderer 主块 375.74 kB／gzip 118.48 kB。未新增或执行测试，不运行应用、真实图片、播放、SQL／迁移、Provider、安装器或验收脚本。schema v43、音频 IPC 1.19、媒体协议 9、系统媒体协议 1 保持，无新安装包；最新已验证安装包仍为 0.29.0，源码更新不会自动更新已安装程序。

MVP 覆盖：列表外当前曲目在曲库刷新／失败／成功不存在时的封面与资料；快速切歌及旧封面重读延迟／失败；同源 CUE 去重、两个请求完成顺序和容量限制；刷新期间文件观察变化；内嵌与目录封面优先；窄窗口、界面缩放、歌词跟随与手动滚动、队列跳转和资料点击检索。实际用户歌曲的缺图原因仍未取得文件复现，不宣称已经实测修复。完整架构研发继续，只有 ASIO 实机验证搁置。
