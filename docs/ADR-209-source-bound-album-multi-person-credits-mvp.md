# ADR-209：来源约束的整专辑多人署名 MVP

状态：0.202.0 源码 MVP；Windows 优先，仅 ASIO 实机验证暂停。schema75、媒体协议15、音频IPC1.23保持。

## 结果与来源范围

整专辑曲目对应后，可进入多人署名审核。歌曲的每个文件版本、全局录音、发行版专辑艺人是独立目标，默认均不选择。歌曲使用该发行曲目的 artist-credit，录音仅使用 recording.artist-credit，专辑使用 release.artist-credit；缺少对应资料时不借用其他层次署名。来源录音与本地已确认标识不一致或归属于其他本地录音时阻止接受。

每个目标可明确保留本地成员、采用来源成员、调整角色、顺序及连接词。来源主署名不证明作曲、指挥等具体角色，角色由用户明确选择。来源姓名、规范姓名与已有本地艺人对应同时显示；来源艺人标识来自服务端保存的审核快照，调用者不能提交任意艺人ID或名称。

## 一致性与撤销

审核凭据绑定完整曲目对应、当前目标、成员、来源及策略，私有快照与返回展示对象隔离。凭据主动到期、取消或关闭曲库后释放；集合锁、歌曲展示字段锁、归属或来源变化使旧审核失效。最多四个凭据，总预算16MiB，每个目标最多64个成员，影响歌曲范围不超过5000条。

分别确认歌曲、录音、专辑的影响范围后，所有目标在一个SQLite事务保存：复用已有艺人或创建来源艺人，保存署名、来源观察、选择、前后快照及聚合命令回执。先验证全批，再允许本批前序写入产生的修订变化；同一来源艺人跨目标复用只导入一次。末段失败全部回滚。相同请求重试优先读取持久回执，离线重启不重复导入。

来源历史新增整专辑署名记录与独立撤销入口。撤销只恢复该目标署名集合及相应展示绑定，不回滚无关集合或整个实体修订；因此同批其他署名撤销及后来风格修改不会被覆盖。后来署名、角色、锁或艺人身份变化阻止旧撤销。导入的艺人、来源观察和审计历史保留，不写音乐文件。
