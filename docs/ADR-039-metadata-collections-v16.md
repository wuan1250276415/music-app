# ADR-039：多值集合来源、锁定与显式合并

状态：0.34.0 源码实现，2026-10-01；schema v16 迁移、桌面与运行验收留到 MVP。对应 WP03/WP08，延续 ADR-037/038。完整 FR01–FR14 仍在实施。

## 覆盖范围

当前覆盖曲目有序署名、录音有序署名、发行版专辑署名、曲目风格集合和发行风格集合。署名保留艺人引用、角色、顺序和连接词；同一人物不同角色是不同成员，不把名字按斜杠拆分。标签候选尚无显式连接词时沿用分类展示的顿号回退，每种角色的最后一位不添加连接词；保存的人工连接词保持原文。

各对象“来源与字段锁”页增加集合入口，可查看当前集合与历史观察、选取来源成员、调整顺序、预览和显式合并。重复的同一艺人身份／角色或同一风格由用户明确保留一个来源成员，后端拒绝重复，不进行静默身份猜测。自定义风格每行一个，名称内的斜杠保留；风格实体及已有 parent_id 不因关联更换而删除，层级编辑界面仍待开发。

集合可整体锁定、明确清空、恢复已确认的本地自动基线。主动资料修改和来源选择仍可修改已锁集合并保留锁；恢复自动或旧署名重置入口要求先解除锁。默认文件集合解锁可采用最新基线；既有人工署名或含用户分类的旧集合冻结时保留人工／未知来源，解锁不自动删除已整理内容。风格清空、署名空集合和标签缺失通过模式区分。

录音的集合选择独立于整个录音资料确认状态，不能因为选择署名而伪造所有标量资料“已确认”。已选择的录音角色接入详情和角色检索，并在人物归档前保留引用保护。专辑署名同样保持发行资料其他字段独立。

## 数据与来源

v16 增加 `metadata_collection_observation`、`metadata_collection_state` 和 `metadata_collection_change`。观察记录保存集合值、实体／字段、来源、来源引用、授权快照、首次记录时间与去重指纹；当前只登记本地标签／CUE／候选派生／人工／旧来源未知，不把人工整理当成在线 Provider 数据。来源引用保留当时的文件 ID、相对路径、根 ID 和 CUE 键，发行候选保留本地目录上下文；旧集合来源缺失时仍明确未知，复制观察保留原证据。

状态保存单调修订、锁、选择模式、所选集合、来源 ID 列表与最新自动观察指针。来源归属和支持的实体／字段由闭合集合及触发器检查；仍有来源的实体保留或归档。观察按值、来源和来源上下文去重，历史不是每一次扫描事件日志。自动指针处理 A→B→A，不用首次记录时间推断当前值。

当前观察统一引用本地使用的授权快照，不承诺公开导出或写回许可；读来源时检查展示／保存动作和有效期。未来在线多值观察、条款撤销清理和 TTL 必须通过 Provider broker 接入，不能借不可变表永久保存需删除的内容。

扫描先记录原始候选和风格观察，再保留人工选择与锁定集合。曲目冻结署名采用独立稳定副本，不能继续引用会被重扫改写的标签候选；已有人工署名保持原引用，避免重扫仅因再次复制而改变身份。相同内容的冻结副本复用，减少无意义修订。

曲目和录音候选由扫描补基线，专辑署名在新发行候选创建时补基线；旧物理文件缺少集合基线会实际补读。发行风格目前支持人工编辑、历史选择与复制，没有推断整张专辑风格的自动扫描基线，界面明确说明。手工发行身份也可能缺少扫描基线，不以当前确认值伪造标签来源。

## 关联、检索与撤销

曲目、录音和发行资料编辑登记人工集合来源，保留现有锁；复制确认实体时复制集合选择／锁和自动证据，为新实体创建归属正确的观察 ID。风格来源关联跟随复制后的来源 ID。发行风格参与曲目详情、风格分类计数、过滤和文本索引；当前详情用来源提示区分曲目与发行风格。明确清空曲目风格后，兼容显示和索引不能重新回退到旧原文标签。

元数据原有来源快照扩展集合状态，署名修订也保存集合状态。撤销恢复原署名引用／曲目绑定／风格成员与来源、选择模式和锁，状态修订继续增加，不倒退自动基线。旧审计若缺少集合快照，且实体后来已产生集合来源或选择，则保守拒绝直接覆盖。

命令在写事务中校验实体、字段、基础修订、成员及其当前身份指纹，持久回执支持相同命令重放。所选历史成员来自该对象字段的合法观察；保存时再次检查成员是否存在／归档、角色、连接词、重复身份和基准指纹。艺人身份在预览后发生变化时拒绝旧确认。单次最多影响 5000 个文件，署名最多 64 成员，风格编辑／选择最多 256 成员，单条观察 JSON 不超过 262144 字符。

历史每页 25 个观察，键集游标限定对象和字段；追加页遇来源／成员变化要求刷新。保存前必须显示预览，UI 不自动选择全部来源；合并次序由用户确认。完整逐字段冲突报告／部分补偿撤销仍待实现，当前按整个实体与关联状态保守拒绝冲突。

## 验证边界

类型检查、主进程／Renderer 构建、原生音频宿主编译和发行清单一致性检查通过。没有运行单元、SQL 迁移、桌面、真实音乐文件、音频、安装或真实用户库测试，按用户要求留到 MVP。旧测试辅助可重建 pre-v16 审计与 schema，最新 schema 断言同步为 16，但未执行。源码版为 0.34.0；最新已验证安装包仍是 0.29.0。ASIO 实机验证继续暂停。

MVP 集中验证需包括 v15 一致备份／升级／回滚、各集合锁／清空／自动恢复、角色顺序和连接词、重复身份拒绝、旧值来源未知、A→B→A、旧库补基线、扫描保护独立副本、人工资料与旧重置入口、身份变更传播与过期成员预览、合并后逐成员来源、发行复制、风格层级保留／继承／空集合检索、审计／补偿修订／重复命令／重启、旧审计保守拒绝、分页冲突以及键盘访问。观察历史内的名字保持记录时原文，当前分类继续解析人物身份；历史界面的身份更名说明还需 UI 验收。

后续仍需 Provider broker、多值在线确认、保留策略、风格层级编辑、标签在线 ID 导入、批量审核、部分冲突撤销和写回，以及其余 WP01–WP11 门槛。不能将本轮五个集合字段的编译接入解释为整个 Catalog 或 Metadata 工作包已验收。
