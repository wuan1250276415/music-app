# ADR-223：内置数据源版本契约与受限请求 MVP

状态：0.216.0源码集中MVP通过；完整V1未完成。2026-10-15。

对应架构§11、§18、§20.1及FR06／FR14、WP08。V1保持内置可信适配器，公开扩展SDK后续冻结。

**0.216.0 内置数据源契约与请求授权 MVP**：MusicBrainz、Cover Art Archive和AcoustID已通过API1.0宿主接入，声明接口版本、宿主兼容范围、平台／处理器、查询能力、网络域名及凭据槽。宿主维护独立允许范围，扩展声明不能自行增加权限；整批验证通过才登记，失败不遗留部分来源。

生产适配器只取得所属来源的请求句柄，跨来源、未声明接口和域名请求先拒绝；重定向同时满足宿主域名和既有精确条目规则。Broker复制并冻结策略，登记后的外部对象修改不能扩大地址、路径或保存权限；整数／有限预算严格校验。关闭扩展取消该源在途与排队请求、清理缓存、拒绝旧句柄及晚回应，其他数据源保持可用。凭据依旧由可信宿主固定槽回调读取，没有把系统凭据库或数据库交给适配器。

新增独立内置适配器示例和宿主授权文件。示例通过真实宿主／Broker返回带来源、获取时间、期限及权利的候选，只注入网络回应，不进入正式界面或自动应用资料。集中MVP21项通过，包含完整批次拒绝、权限扩张负例、真实在途／排队取消、策略变更防护、域名跳转、响应字节上限，以及66次同步提交与Broker实际1运行＋63排队的双层预算。原实际桌面元数据组合81项及音频识别9项通过。

类型、构建、发行／分发清单通过；schema79／媒体16／音频IPC1.23保持，备份数据源组件身份不变。原生字节逐项复核与0.215检查点相同，本轮没有重新编译原生、打包或新增硬件验证，最新试用包仍0.215.0。内置适配器为同进程可信代码，接口不是JavaScript或OS沙箱，也不代表公开插件SDK、签名安装或完整生命周期已经完成。完整FR01–14／WP01–11／G1–5／AC01–19继续，仅ASIO实机验证暂停。详见[ADR-223](ADR-223-versioned-builtin-provider-contract-and-scoped-transport-mvp.md)。

API1.0清单采用闭合读者，拒绝额外字段／文件写权限、非法域名、重复能力、不兼容主次版本和平台。宿主授权与适配器声明分开；正式来源授权仅由组合根中的固定目录维护。新网络范围必须同时改变宿主授权和实际适配器契约，不能通过Renderer或普通IPC传入。

ProviderExtensionHost先构建独立清单和策略副本，再调用Broker.registerBatch；Broker复核全部策略、重复与已有来源冲突后才改变运行表。策略包含独立正则副本、只读端点／权利／跳转头数组。回调函数仍属可信编译代码，副本并不隔离其闭包或环境权限。

受限ProviderTransport保留现有适配器调用形状，但只允许固定来源与登记接口，最多65个尚未完成的提交；Broker的maxQueued包含当前运行请求，最高64个真实在途／排队。私有取消控制器组合调用者取消信号；撤销先关闭入口，再取消所有所属请求及该源缓存，已有句柄不能再用。可信宿主管理仍持有全局Broker，单个适配器不持有全局登记／清空入口。

原有MusicBrainz独立构造路径仍可拥有自己的Broker，供独立领域测试；生产Service明确传入所属宿主句柄。AcoustID固定client-key回调、审核私有候选、字段确认和持久审核计划保持。资料API仅附加扩展描述，不增加接收用户代码／策略／域名／凭据对象的IPC；不把网络契约当作凭据库沙箱。

示例位于examples/provider-adapter，宿主授权文件独立维护，.invalid地址没有真实服务。可运行npm run test:provider-extension-mvp完成构建和集中回归；已有可用构建也可直接运行tests/provider-extension-mvp.smoke.cjs。新增正式来源仍需其领域适配、身份和权利审核、来源保存撤销、凭据、备份及访问条款核验，本例没有自动注册为第四个正式数据源。

MVP21项覆盖正反调用、示例候选来源／权利、不兼容及后续失败不留部分登记、声明／实际接口差异、额外凭据和域名／子域扩张、封闭字段、真实策略对象改写后原路由不变、越权跳转拒绝和显式授权CDN跳转剥离非公开头、在途和已排队请求撤销／晚回应拒绝／旧句柄关闭、同伴数据源可继续、原备份组件身份、主动取消及候选／响应预算。预算补查首次把maxQueued当作只含等待项而断言64，实际为1运行＋63等待；修正测试计数并验证66次同步提交中的宿主与Broker分别拒绝范围，失败报告保留，没有放宽生产预算。

实际Electron元数据81项通过新的生产Service宿主路径，包括MusicBrainz和Cover Art Archive；音频识别9项通过AcoustID／Windows隔离假凭据／当前原生／字段确认／离线补偿和重启。测试网络回应受控，不证明真实识别真值或新服务授权。原音乐不变，测试假密钥清理完成。原生没有改动，按0.215检查点逐项核对字节；没有重跑其全部软件／硬件矩阵。

公开扩展包安装／签名更新、安全模式／失败插件隔离、独立worker及完整契约SDK继续按架构后续边界推进。完整媒体／写回恢复、真实规模和长期运行、300案例真值及全部发布门禁仍未完成，ASIO实机仍搁置。
