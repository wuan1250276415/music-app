# ADR-045：封面解码回退与播放详情歌词

状态：0.40.0 源码实现；2026-10-01。类型检查、主进程／界面（47 模块）／原生宿主构建及发行、分发清单检查通过。schema v20、音频协议 v1.6 不变。按用户反馈优先完善 WP04/05/06/10。

## 封面显示

延续 ADR-036 的歌曲内嵌优先：先选择内嵌正面封面，再尝试其他内嵌图片，最后尝试同目录 cover/folder/front。CUE 使用所引用的音频文件。

旧路径只校验图片签名，签名正确但图片损坏时可能始终显示占位。本次界面先通过 Chromium 图片加载检查可显示性，成功后才进入 Renderer 图片缓存。不可显示的候选以 SHA-256 token 告知 Service，继续查找后续图片；不把原始图片回传为拒绝参数，也不将拒绝列表保存为文件的永久状态。既有 artwork 接口保留，新增 artworkCandidate 仅收曲目 ID 和至多 8 个固定长度 token，经主进程与 Service 两层校验，不接受调用方路径或网络地址。

一次显示请求最多尝试 8 张图片，总等待期限 45 秒，单次图片加载期限 5 秒。候选仍限制 16 MiB；浏览器加载后检查边长不超过 8192、像素总数不超过 32 Mi 像素。像素检查发生在加载之后，并不提供解码前内存限额。文件读入和标签解析的内存／取消边界继续待专门优化；界面期限到达只停止等待，不代表已取消 Service 中的读取。

Service 缓存仍保存读取结果，拒绝后的查找不污染共享文件缓存；Renderer 成功缓存继续限制 32 项／64 MiB 字符串估算。封面在曲目列表、底部播放栏和详情共享显示路径。读取中、占位和已读取图片提供不同提示；详情可以重新读取封面与歌词。刷新过程中切歌时，上一首的提示／异常不会覆盖新曲目。

## 播放详情

底部封面按钮打开详情，提供歌曲／专辑／艺人／风格及已有发行、录音资料，点击身份链接进入对应分类检索。歌词、顺序／列表循环／单曲循环、独立随机开关、当前队列跳转／重排／非当前项移出均使用已有业务接口和修订检查。此批次不改动音频输出或队列持久化规则。

详情展开后背景导航和曲库列表设为 inert；播放栏继续可操作，关闭按钮获得焦点。关闭或 Esc 返回播放栏封面按钮；其他编辑对话框出现时 Esc 不同时关闭底层详情。

歌词面板与详情使用同一展示组件。同步歌词跟随当前行滚动，只滚动自身容器；滚轮、触摸或滚动键暂停跟随，点击“回到当前歌词”恢复。点行可跳转，纯文本和未开始播放时禁用跳转；自动动画尊重减少动态效果设置。来源提示区分歌曲内嵌和本地文件。

## 内嵌歌词

沿用锁定的 music-metadata 依赖读取通用歌词；兼容原始 LYRICS／UNSYNCEDLYRICS／USLT／ULT／©lyr／WM/Lyrics 文本。原始 LRC 在通用归一化前解析，以保留多时间戳及后置 offset。同步时间为毫秒的标签转换成秒；MPEG 帧序号不同于毫秒，当前不推测换算。

普通音频优先可用的内嵌同步歌词，其次同名 LRC/TXT，再退回内嵌纯文本。CUE 优先与曲名同名的逐轨文件；否则只接受引用音频的同步歌词，按源文件的整数 75 fps 边界筛选并转换为曲目相对时间，不把整专辑纯文本展示为单轨歌词。同步行限于当前半开区间，不沿用上个轨道在区间外的歌词行。

单份歌词文本最多 1 MiB、最多 5000 行，最多收集 16 份可用内嵌文档。超限或空文档继续回退，不把截断文本展示为完整歌词。可读取的标签取决于现有解析器，不声称所有音乐格式、语言／描述选择、双语、逐字时间或授权在线歌词都已完成；独立偏移设置及保存仍待开发。
