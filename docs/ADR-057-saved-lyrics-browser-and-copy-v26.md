# ADR-057：保存的用户歌词目录与显式复制（schema v26）

日期：2026-10-01。状态：0.52.0 源码实现，运行与迁移待 MVP。对应架构 §17.1、FR10、WP03/WP10。ASIO 实机验证继续暂停，FR01–FR14 与 WP01–WP11 范围不变。

## 独立用户内容目录

延续 ADR-056 的不可变原文存储，顶部增加“用户歌词”，即使未播放歌曲也可查阅已保存的导入版本；曲目歌词管理页也可查看该曲目的全部范围。目录支持按版本名称／语言检索，筛选全部用户文档、关联条目已移除、当前曲目全部范围，以及启用／归档状态。

列表区分：与当前可播放条目范围一致、条目存在但属于旧范围、可播放条目已移除。音频文件离线与可播放条目移除不同；条目存在且范围一致、但媒体不可用时仍标记当前范围，并另提示音乐文件不可用。关联名称显示当前条目标题，不声称是导入时的原始歌曲名称。旧范围快照未完整保存的 v25 文档，不推测原文件起点或旧 CUE 编排。

每次返回 20 条摘要，按不可变保存日期与唯一文档 ID 键集分页；游标绑定检索条件及关联／状态／曲目筛选，不能把另一组查询的游标套用到本组。跨范围日期排序用于查阅，不取代 ADR-056 的范围内单调修订顺序。目录查询只读取摘要，原文按单份读取；每页至多核对 20 个关联条目并复用相同条目的读取结果。当前检索仅对名称与语言做字面包含匹配，不称为原文全文索引、拼音或错字检索。

目录只包含 `local-private-v1` 的用户导入文档。接口接受查询与文档 ID，不接受文件路径、网络地址或外部资源；原文读取不重新打开原音乐／歌词文件。打开文档时再次核对字节数、原文 SHA-256 和保存的解析结构，返回完整解码原文与原始字节供库内复制。归档文档也可查阅和复制，原始文档继续保留。

## 复制到当前曲目

在目录中查看原文后，可复制到当前选定曲目。来源若属于旧 CUE 范围或已移除条目，也走相同路径。复制打开一个新的导入草稿，保留原始字节与原编码，名称预填复制标识；不会修改原文的 item_id、scope 或解析结果，也不恢复旧范围到当前条目。

复制草稿不默认选择时间基。用户明确选择当前曲目时间或源音频时间，重新解析预览，再确认保存。预览显示后台实际核对的目标标题／歌手；CUE 显示源音频起止范围和裁剪后的行。整碟 raw LRC 的完整时间戳在原文中保留，选源时间后根据新范围重新裁剪，不能复制旧解析行来代替原文。对原曲目相对时间不猜测新偏移或自动平移；用户需要检查预览，必要时将解码文字复制到编辑框修改。

导入输入可携带 sourceDocumentId。Main 白名单提取并验证 ID；Service 在预览和提交时确认来源是已保存用户文档，核对来源原始字节摘要与本次输入一致。源原文不可变、不可删除，来源状态的归档／恢复不改变字节身份。保存的导入回执保留复制来源 ID 与原文摘要，目录显示来自保存原文的版本，并支持查看其复制来源。复制的目标文档仍有独立范围、版本 ID、容量限制和修订／回执，不绕过 ADR-056 的提交检查。

如果复制草稿改为文字编辑，内容按新的 UTF-8 用户输入保存，清除“原始字节相同”的复制引用；当前不声称提供编辑衍生关系图或变更字词追踪。相同目标范围、名称、内容和编码已存在时仍拒绝重复版本，旧文档可直接选择或恢复。

## 并发、界面与迁移

目录的搜索结果与原文读取用页面请求代次隔离，过滤变化、条目变化或关闭后不显示旧请求结果。刷新事件重新加载列表；分页不全量读入所有文档。目录为只读入口，旧范围／已移除条目文档的跨范围归档／恢复、物理删除及录音候选复用尚未增加。当前范围的归档／恢复仍由原曲目版本管理页处理。

从曲目版本管理页打开目录时，底层模态设为 inert／aria-hidden；复制时关闭目录并创建新的导入会话，避免已有草稿沿用旧 source 或默认时间基。读取失败保留诊断，没有把缺失条目伪装成当前范围。工具栏搜索允许伸缩，新增用户歌词入口保留在最小窗口宽度下；实际键盘、布局与高 DPI 验证仍待 MVP。

schema v26 只新增跨范围分页、归档过滤和每文档唯一导入回执索引，不改写已有文档。v25 安装步骤增加条件保护，升级前执行 pre-v26 一致备份，索引与版本号事务提交。v25 原有无复制引用的请求规范保持不变，历史 UUID 回执仍按同一规范请求核对；新增复制引用只用于新请求。已有最新版本断言和逆迁移夹具同步到 v26，未执行 SQL 验证。

## 验证与完整剩余工作

本轮类型、主进程／界面（58 模块）／原生与凭据组件构建、发行／分发清单和维护脚本语法检查通过。受控 FFmpeg recipe 缓存核对通过，DSD gold 仍只编译未运行。实际目录查询、原文读取与复制、迁移／事务、界面与音频验证集中到 MVP，没有新安装包。最新已验证安装包仍为 0.29.0；编译成功不代表用户歌词或数据库升级已验证。

MVP 矩阵：无播放曲目时打开目录、名称／语言／状态／已移除／同条目全部范围筛选；游标变造、条件改变、跨页同日期；旧 CUE 范围与删除条目后的原文保留／可查阅；离线文件不误标移除；原文字节与结构校验失败；完整整碟原文复制到新 CUE 范围、相对时间明确选择、重新预览和目标改变冲突；伪造来源 ID／不同原始内容拒绝；归档来源仍可复制；历史 UUID 与新复制 UUID 重试／变造保护；提交后来源引用查阅、编辑解除等字节引用；模态层级／快速筛选／迟到请求／最小窗口；v25 一致备份、v26 索引冲突回滚以及旧数据回执兼容。

FR10 仍需本地／内嵌原文观察历史、完整范围快照与历史上下文、跨范围状态管理、编辑衍生关系、来源优先级编辑、Recording 复用、完整导出／恢复、授权在线源、微秒行区间／逐字与音译、呈现时钟插值和对比度。扫描／文件生命周期、完整音频链、检索、写回与发布等其他工作包继续保留。
