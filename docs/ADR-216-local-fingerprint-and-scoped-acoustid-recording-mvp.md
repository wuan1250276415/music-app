# ADR-216：本地指纹与来源约束的AcoustID录音查询 MVP

状态：0.209.0源码集中MVP通过，完整V1未完成。2026-10-15。

采用官方[Chromaprint1.6.1](https://github.com/acoustid/chromaprint/releases/tag/v1.6.1)源码，资产SHA-256与GitHub公开digest核对，固定标签对象和提交。静态链接Kiss FFT和内部avresample，保留MIT／BSD3／LGPL2.1及完整对应源码／构建配方。归档唯一头文件符号链接严格限定名称和目标，物化为普通文件，不创建任意链接。独立fingerprint-worker由既有解码器读取，不使用播放音量、ReplayGain、输出后端或音频设备。原生协议1与音频IPC1.23／媒体16分别管理，SQL结构仍75。

原生进程核对父进程和最终文件路径，来源以FILE_SHARE_READ只读锁定，不允许替换。统计整份实际解码EOF帧数以取得真实时长，然后从同一锁定句柄的当前歌曲边界开始，只取最多120秒。外部CUE按75帧换算，内嵌精确样本范围按声明采样率核对；不以整张镜像或近似容器seek代替当前虚拟轨。正常Float32解码转s16输入Chromaprint；无效采样、空／过短、边界越界和不完整解码失败。父退出监视、原生5分钟墙钟／CPU限制、512MiB Job、nonce帧、完成ACK及实际exit0后接纳保护结果。自归属Job句柄活至进程退出，避免析构关闭时提前终止自身而损失真实退出码。

Library端一次计算、最多3个在途／等待请求，本地缓存最多4份／10分钟。必须有扫描文件观察，前后核对文件与曲目范围，已变化的物理文件即使尚未重扫也拒绝旧缓存。取消与标签写回／整库维护等待真实子进程退出，再释放读者；维护期间不发新任务。最大原生工作及排队时长通过独立较长的Main RPC超时覆盖，用户仍可随时取消。当前只是有界主动识别；统一任务中心、性能／长时／完整故障矩阵仍未验收。

按[AcoustID公开API](https://acoustid.org/webservice)使用固定https://api.acoustid.org/v2/lookup，只读POST正文包括client、fingerprint、当前虚拟曲目duration、meta=recordings及JSON格式。无GET查询密钥、文件路径、音频、贡献提交或跨来源跳转；统一Broker400ms间隔、有界正文／响应、超时／取消／429退避及内存缓存。公共服务非商业条件与商业服务方案在来源设置说明；没有硬编码官方示例密钥。密钥仅在Library内从Windows系统凭据库读取，存在未确定操作则拒绝查询，Buffer用后清除，不将secret返给Renderer。JavaScript／HTTP正文仍是请求期间的字符串，清除引用和短期生命周期不宣称能清零所有运行时复制。

查询解析严格校验AcoustID／Recording UUID、排序范围、重复、艺人文字及整体录音预算；合并跨指纹同一录音时保留最高排序的映射，不自动选录音。最多100个不同录音、四份私有10分钟预览。返回展示对象与私有选择隔离，选取时核对来源、曲库修订、期限和当前物理文件观察；任意未归属ID、跨歌曲／片段或状态变化不能获得选择权限。选中后只读取该MusicBrainz录音与发行候选，不静默转文本搜索，不自动更改音乐身份或发行归属。MusicBrainz候选与派生内容保留指纹依据和私有元数据指纹，期限不超过父识别；来源／密钥暂停、清除及维护取消在途并使预览失效。

按[AcoustID数据库许可](https://acoustid.org/database)，原指纹数据库的CC-BY-SA3.0与MusicBrainz-AcoustID公共领域映射分别处理。外部指纹／关联响应、排序和提供的显示文字不直接作为永久库值；确认后的字段从MusicBrainz另行读取和审核。持久文本计划只存公共标识映射、当前源指纹与本地算法依据，读取投影完整保留；不会写入原指纹正文或把音频指纹当作发行身份。普通旧查询／请求回执形状保持，备份75重开保留已审核映射和补偿。旧软件直接共享数据库降级读取尚未验收，更高应用版本备份的准入仍拒绝，不宣称完整跨版本发布已完成。

界面默认收起识别入口，需明确启用来源和保存用户应用密钥；按音频识别只处理当前歌曲。选择关联录音后回到MusicBrainz候选比较，初次不自动勾选或绑定身份，发行版及最终字段仍独立确认。识别排序不是概率；短片段提示依据有限。关闭／取消／期限／曲库变化保留后续资料安全，独立预览按所属令牌释放。此版本尚未提供整库后台识别或批量指纹自动策略。

集中MVP：实际受监督WAV／CUE扫描、生产原生指纹／来源／Broker／SQLite18项，包括真实片段0／10／40／70边界、不同轨指纹、独立物理裁剪及官方fpcalc1.6.1逐字一致、闭合读者、正文参数与密钥Buffer清理、私有范围、防伪／预算、明确MusicBrainz读取、来源变化、关闭／离线文本补偿／快照、晚回应取消、观测到真实原生PID后取消并等待其确切退出、物理文件变动拒绝缓存及维护完整性。原生DLL／缓冲来源为实际构建，不是假指纹；网络为明确fetch夹具。

另将用户曾明确提供的真实FLAC只读复制到隔离目录，经实际监督扫描与新原生程序完成3项对照：实际解码269.7466667秒，指纹取前120秒，与官方独立发行fpcalc指纹逐字相同，原文件及副本SHA-256保持b648dfa3538c5e2e5159f38cbf356cc6dfa6796f7058f48631adafaf8e63dbbb。不公开原始音频指纹，不执行真实AcoustID请求。这不证明现实录音关联质量。

实际Windows凭据／Main／preload／Service／Electron9项涵盖默认关闭不传输、真实密码表单与凭据保管、保存不启用／不返回secret、明确启用／当前CUE本地计算／两候选显示、真实内部读取并POST、伪造身份拒绝、明确录音读取／匹配依据且未绑定、只选择歌名保留艺人／专辑、实际逐字段撤销及媒体离线重启。密钥只是独立测试范围的假密钥，结束移除client-key及该范围的command-key；源WAV摘要不变，测试播放器静音。原桌面组合81项以及上下文／专辑／身份／轨目／概念／署名／批次数据回归通过。最后构建、类型、完整原生编译、六个vendored组件许可与分发检查通过，最终两候选截图已检查。

首次源码准备拒绝官方头文件链接，限定单个已知目标后物化通过；首次类型检查发现可选LibraryItem的undefined边界，修正为null。集中数据检查揭示持久计划展示遗漏AcoustID标识，修正实际读取投影；桌面首次测试错误调用不存在接口，改用真实撤销对话框并明确只选择歌名，后9项通过。相关失败保留。完整Native重编后再次执行18／3／9及原81项，对当前字节指纹重新核验，避免复用旧二进制报告。
