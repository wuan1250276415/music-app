# ADR-059：可编辑歌词自动优先级与缺失来源设置保护（schema v28）

日期：2026-10-01。状态：0.54.0 源码实现，运行与迁移待 MVP。对应架构 §17.1、FR10、WP03/WP10。保留 FR01–FR14、WP01–WP11 完整范围，ASIO 实机验证继续暂停。

## 自动排序与显式选择

歌词设置支持按具体来源身份编辑自动优先级，覆盖当前已接入的用户导入、本地同名／语言文件和内嵌来源。列表可上下移动，显示类型／语言、恢复默认顺序或显式清除暂不可用的优先项。没有新的 online 来源，也不把缺少标签的文本冒充翻译或字同步。

设置 JSON 增加可选 `sourceOrder`，最多 64 个不同 SHA-256 来源 ID。自动选择按已保存顺序取首个可用来源；尚未列入排序的新来源保留默认相对顺序并追加到已排序来源后。暂不可用的来源不参加当前候选，但其排序记录保留；相同身份恢复后再进入原排序。自定义排序只影响自动来源与显式选择缺失时的临时回退；已指定且仍存在的主歌词优先于自动排序。

缺少 sourceOrder 或空顺序时沿用既有默认：用户导入最近修订优先；普通文件的本地部分仍是内嵌同步、同名／语言文件、内嵌纯文本，CUE 本地部分仍是逐轨同名文件、源音频内嵌同步。不会静默改写旧设置为新默认。界面移动来源时将显示的来源身份排序保存；缺失记录与新来源合计超过 64 时，须先显式清除缺失排序项或恢复默认。清除排序记录不删除用户歌词，不清空主、辅助来源选择。

排序计算与主／辅助决定共用 shared helper，后台生效结果、界面草稿及旧单歌词读取接口遵守同一规则。主窗口侧栏和播放详情继续共用同一已保存设置。当前排序作用于具体 PlayableItem 范围，不自动跨新 CUE 范围或 Recording 复用。

## 保护缺失选择与偏移

修正原界面把暂不可用的主／辅助来源置为 null、用临时有效偏移覆盖保存偏移的问题。草稿现在保留完整原设置，缺失选项显示为暂不可用。用户只修改字号、双语开关或优先级时，不会顺带抹掉这些选择与绑定；恢复相同来源身份后继续使用保存值。

后台仍拒绝新选择一个未观察到的来源。只有对应字段与已保存旧字段一致时，才允许保留缺失 ID；优先级中缺失 ID 必须属于已有排序记录。缺失辅助偏移不可借此修改。原偏移的来源身份与当前临时主歌词不同时，仅允许保留未变更的原绑定、毫秒值及主选择；不会把数值应用到回退来源。改变自动排序使有效自动主来源变化时，界面把该次草稿主偏移清为零并绑定新来源，不搬运旧偏移；指定缺失主歌词时继续保留其原绑定。

自动来源因外部变化而与原偏移绑定不同时，界面保留原值、禁用该输入并解释当前未应用，可显式为当前自动来源重设零偏移。选择新主歌词也显式重置主偏移。辅助歌词与临时主歌词重复时暂不显示，允许保留原辅助选择／未改偏移；用户主动选择新主与辅助仍执行不同来源检查。通知可同时说明主、辅助、偏移与缺失优先项情况。

## 来源观察摘要与提交

Bundle 附默认来源身份顺序及 `sourceSetFingerprint`，摘要针对后台本次读取的默认顺序、已解析来源内容及描述字段计算，不针对排序后的列表。新界面保存任何歌词设置均携带观察摘要；带 sourceOrder 的新请求必须提供摘要。后台重新读取本地来源和当前启用导入版本，在保存事务中比较摘要、范围与设置 baseRevision，再写入设置与既有不可变 UUID 回执。内容、列表或默认顺序发生变化时拒绝旧审核，让用户重新读取。

本地异步读取后另核对当前条目范围、可用性与用于逐轨歌词命名的标题，避免标题改变后套用旧文件名读出的候选。摘要只证明两次观察到的解析来源相同，不是音乐／歌词原始字节快照、文件租约或监听保证；读取与提交之间外部文件仍可能变化。完整源原文观察与文件生命周期工作仍待后续。

Main 白名单提取固定偏移、字号、选择、排序和摘要字段，检查长度／类型；Repository 再检查唯一性、有效来源关系和历史保留规则。旧请求中没有新增字段时，规范 JSON 保持原有形状，不给历史 UUID 补默认数组或摘要。重试先核对持久回执，返回当前有效汇总，不重装历史设置；同 UUID 改内容拒绝。通知失败不抹掉已经提交的保存结果。未知结果仍保留原请求并提供核对入口，没有新增跨 Renderer 崩溃的待确认意图箱。

## 数据模型兼容

schema v28 是歌词设置 JSON 契约升级，没有新增物理表。升级前 pre-v28 一致备份，版本号事务提交；v27 上下文表创建已增加条件保护。旧应用会拒绝 v28 库，避免旧 validator 忽略 sourceOrder 后在普通设置保存中丢弃排序。现存 preference_json 和旧回执不改写，新字段只在用户提交新设置后保存。逆迁移夹具和当前 schema 断言同步到 v28；夹具仅用于隔离测试库，不能作为含新设置的用户库降级工具。音频 IPC 1.8 不变。
