# ADR-019：音频回调的逐帧缓冲金样

状态：0.15.0 软件金样通过；G1/G4 尚未验收。

## 决策

将 WASAPI 回调消费有界 PCM 环形缓冲的代码放在独立 `pcm-ring.hpp`，生产宿主直接调用同一函数；金样程序不模拟另一套实现。解码生产线程仍以 release 语义发布写入帧数，回调以 acquire 语义读取，只复制已发布的完整 PCM 帧。设备停止后才重置 seek 的读写游标，旧环形缓冲内的字节即使仍存在，也不能再次被当作已发布样本读取。

回调到达相邻 CUE 的整数 PCM 边界时只标记一次；边界处没有可消费帧时不提前发边界标记。取消预排第二段后只消费第一段剩余帧，其余回调缓冲补零并结束。文件/轨道的预期结束补零不计入缓冲欠载诊断；生产线程未及时供给时则累积回调次数和补零帧数。回调中不分配内存、不执行 IPC 或锁。

## 验证与界限

`pcm-ring-gold.cpp` 使用与生产回调相同的消费函数，逐字节检查环形缓冲回绕、3 字节 PCM 帧回绕、两段 CUE 边界连续性、边界前取消、空边界不提前触发、seek 后旧字节隔离、真实缓冲欠载计数及预期结束补零。`npm run test:native-ipc` 构建并运行金样。0.15.0 本机验证为 24 项单元、4 项原生 IPC/金样、16 项串行声卡测试通过；`npm run test:ui-pressure` 在 3 秒布局压力中记录 288 次回调、0 个补零帧。Electron 同文件 CUE 队列跨轨、第二首 seek 与重排取消回归也通过。

0.15.0 静默安装目录中的音频宿主与构建产物 SHA-256 一致；安装版的 3 秒界面压力仍记录 288 次回调、0 个补零帧，CUE 队列、独占输出策略和静默卸载回归通过。

该金样覆盖应用回调送出的字节，不覆盖 miniaudio/WASAPI 后续转换、驱动或 DAC 输出。它也没有证明所有多线程时序和设备组合；G1 的跨设备、长时压力、数字输出捕获及 G4 的硬件证据仍独立待验。
