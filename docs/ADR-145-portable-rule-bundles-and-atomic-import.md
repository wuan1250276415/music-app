# ADR-145 规则与筛选预设备份及跨曲库引用匹配

日期：2026-10-06  
状态：0.139.0 源码实现；运行验收集中到 MVP。

## 目标与边界

提供已保存智能歌单和筛选预设的 JSON 导入导出，补齐 WP05／WP06 用户规则管理。文件保存条件及必要引用资料，不保存动态歌曲成员，不包含音乐、封面、歌词、凭据、Provider 候选原文或活动数据库；不是整库一致备份、静态歌单导出或设备迁移的替代品。

导入始终创建独立的新歌单／预设身份，保留同名现有记录。不修改当前筛选或已提交队列。原身份历史恢复仍走 ADR-143 的单独流程。

## 文件契约

`aural-rule-bundle` version1 包含持久来源身份、导出时间、最多64个已保存条目及恰好覆盖规则所需的引用。条目以 kind＋原UUID区分，每种定义沿用现有 version1 白名单读取器；未知字段／版本、递归歌单范围、重复或缺失引用、超预算均拒绝。整个 JSON 最大1MiB，最多2048个类型化引用。

引用类型区分艺人、发行专辑、专辑概念、风格和曲库根文件夹。每项保存原身份、最多512字符名称／上下文及目录资料指纹。条件的艺人／风格 ID、分类 facetId、独立 genreFilter 和文件夹根身份全部进入引用集合；没有实体身份的原名称范围或文本检索继续保持原文本语义，不猜测实体或自动转换。

导出通过已选条目的保存修订核对，并在同一事务读取完整定义和引用资料。失效或已归档原资料保留明确名称／状态，方便导入时重新匹配，不能自动绑定为活跃目标。

schema67 新增固定单例来源UUID、禁止更新／删除的来源触发器以及不可变导入审计。迁移前使用既有 `VACUUM INTO` 快照，事务创建表并检查外键，再设置版本；旧应用拒绝 schema67。来源UUID随数据库一致备份恢复而保留，复制同一数据库不被当作新曲库。迁移／SQL尚未运行。

## 引用匹配

仅同一来源曲库、原身份仍活跃、且原指纹未变化的引用可自动建议匹配。跨曲库引用一律需要明确选择对应类型的目标，不以同名或相同UUID猜测。已关联到其他艺人身份的原候选和归档艺人／风格不作为可选活跃目标。

目标选择每次读取最多50项，使用已有自然排序和签名 keyset 游标，不获取全库 ID 或执行目录 COUNT。游标绑定进程、类型、检索、资料快照、末尾身份及自然键摘要；下一页在同快照下重新读取该末尾键，再寻址。完整自然键不装入小游标，长名称不因此截断或丢失分页能力。目标查询为名称子串，不额外声明拼音／纠错能力。

连接内独立 TEMP 修订跟踪 artist、artist_identity_state、artist_identity_binding、artist_credit／成员、release、release_group、genre、library_root；提交或回滚与其目录写入一致，另核对外部 data_version。播放统计的正常本连接写入不会仅因次数变化使目标分页失效。未运行 SQLite 触发器或并发真值验证。

重新核对可保留用户先前明确选择、当前仍具有完全相同指纹和展示资料的匹配；保留与自动建议分别返回。失效选择退场，其他人工匹配无需全部重做。最终提交仍在写入事务内重新核对每个目标。两个原条件身份映射为同一目标、导致条件重复时，沿用定义读取器拒绝，不静默合并或改变交／并语义。

## 一次提交与故障核对

导入请求含原命令UUID、规范化完整文件、选择和全部匹配，最多2MiB。Shared 字段／大小校验贯穿 Renderer、Main、Library；原子性由 LibraryDatabase 的外层事务和既有嵌套 savepoint 实现。

1. 首先核对全局持久命令回执；同UUID／同规范请求返回原结果，不受后来目标或新建规则被修改／删除影响，不再创建记录。不同请求重用UUID拒绝。
2. 核对目标当前资料及指纹，逐条替换实体身份；文字范围、角色、交并集、下级、相对时间、统计、排序和版本显示语义保留。
3. 确定性派生每项子命令UUID，经既有智能／预设创建仓库生成新的记录；子回执和智能历史也在外层事务中。
4. 保存父回执以及完整规范请求／来源SHA的审计。任何目标、定义、预设配额、子操作、回执或审计失败均回滚整批。
5. 只有真实新提交发送对应目录通知；原回执重放不重复通知。失去提交确认时查原回执；回执核对失败仍抛出未决错误，不能伪装成已知拒绝。

审计保留规范条件及映射，摘要使用固定域和与区域设置无关的引用键顺序，**不是原文件字节摘要或原文字节存档**。审计最多512次导入／128MiB请求内容，单项最多2MiB；不静默删除历史。治理／受控归档及清理仍是后续工作。父回执受审计外键保护，预算不足会在同事务拒绝整个新导入。

## 本机文件与界面

Renderer 不提供路径。可信主文档通过本机对话框选取 JSON；拒绝符号链接／非普通文件，校验读取前后句柄和路径的完整文件观察，限制1MiB并严格解码 UTF-8（允许 BOM），再读取文件结构。只读取所选文件，不访问其描述中的目录或媒体。

导出在选定目录创建独占临时文件、写入并同步后发布。覆盖普通文件前复核原观察并使用同目录 rename；这不是文件系统级 CAS。新文件优先以 link 实现不覆盖发布；不支持 hard link 的可移动盘或 NAS 可退到 COPYFILE_EXCL，并同步完成的副本。后者不是原子可见发布，严格导入会拒绝不完整 JSON；不宣称所有文件系统或断电下目录项耐久。退出时只清理当前操作确实创建的临时文件；崩溃遗留治理尚未实现。

歌单页提供全局导入／导出，当前智能歌单有快捷导出；导出可在智能规则／筛选预设目录间跨页选择，保存草稿不作为导出对象。筛选预设管理显示该入口位置。导入展示原范围、检索词、排序、版本、角色和风格范围；引用按16项分页，目标一次50项。全部引用匹配后可查看完整只读组合条件及当前目标曲库的数量／样本预览，预设预览明确以全部音乐作为示例范围。

规则或资料更新会使确认退场并要求重新核对；对话框来源代际、选取目标和预览有相应隔离。明确勾选创建新规则后才提交。IPC 前保存完全一致的待核对请求，单飞控制，严格检查父UUID、文件摘要、条目kind／source／name、结果数量及唯一新身份，再清除本机待核对记录。超时、异常回应或清除失败保留原请求；重启后可继续用原UUID核对。回执重放只证明原提交，界面随后重新读取当前目录，不宣称旧创建结果仍是当前状态。
