# ADR-203：整专辑曲目审核与持久文本批次 MVP

日期：2026-10-13。源码0.197.0；schema74、媒体协议15、音频IPC1.23保持。完整FR01–14／WP01–11／G1–5／AC01–19继续；仅ASIO实机验证暂停。

## 结果

从所选发行版的专辑上下文进入“审核整张专辑曲目”，比较完整本地发行成员和已载入的在线曲目。显示本地碟数、发行曲目数、可播放版本数，以及发行版的声明／已载入曲目数。不自动选择对应曲目或字段；不足、数量差异、碟数差异、隐藏／数据轨未审核继续明确显示。

逐条推荐结合繁简规范化后的曲名、碟号／曲号、时长与已有录音外部引用，最多显示5个建议。分数只是工程排序，不是正确概率。同一录音出现多次时提示核对具体发行曲目。用户可以分页浏览和检索全部发行曲目，手工选择推荐范围外的条目。

曲目署名使用该轨自己的 artist-credit，不以专辑艺人替代；缺少本轨署名时该字段不能勾选。MusicBrainz 的署名是特定发行、曲目等上下文中的署名，可能包含多位艺人、显示名称和连接词，见[官方署名说明](https://musicbrainz.org/doc/Artist_Credits)与[API示例](https://musicbrainz.org/doc/MusicBrainz_API/Examples)。这里更新的是歌曲署名显示文本；已确认的完整多人署名受到保护，身份／角色编辑仍使用已有单曲完整署名审核。

## 约束与保存

本地最多5000个可播放版本，页面25条；在线普通曲目沿用1000轨上限，浏览页面50条。审核最多4份，合计16MiB序列化快照预算；这不是整个进程内存预算达标证明。资料不再被访问时也会按期限主动从内存移除；关闭曲库时清除整专辑及发行字段审核状态。

Library Service 从已验证发行上下文创建内存凭据，绑定原曲目、候选、查询期限、本地发行及所有成员的基础资料、字段来源／锁、录音外部引用修订。界面只提交凭据、条目ID、发行曲目ID、字段枚举和范围确认，不接受界面提供的新值或来源URL。Main和Service均执行窄请求校验。

不同本地发行曲目不能重复占用同一在线发行曲目；同一本地发行曲目的多个版本可对应同一在线曲目，但不能分配到不同在线曲目。已有录音外部引用冲突不能采用。后续修改外部引用会使旧审核失效；引用改回原值也不能恢复旧授权。

明确选择歌名／本轨署名文本／专辑并确认范围后，保存到已有不可改写的批次计划，每个计划最多100个条目，可分批处理。计划包含所选发行曲目、录音、碟号、位置、印刷曲号和来源，以及执行所需的本地录音引用修订。计划不会在保存时立即修改曲库；进入已有执行界面后，可逐首执行、暂停、取消剩余项或补偿撤销。

逐首执行会重新检查审核期限、曲目资料、来源／锁与录音外部引用，冲突保留当前值。录音引用修订是独立且单调的执行检查，不把同批次更新其他版本的派生文本误当作引用修改。已保存计划及命令重试凭据可在重启、内存审核清除和离线时读取；新计划仍需有效在线候选和允许保存的核心文本政策。

源于具体发行轨目的歌名与本轨署名记录发行版URL，而不是错误标成录音通用标题来源。新的来源信息复用既有candidate_json、metadata_change及不可变观察记录，无SQL结构迁移。保留独立的Recording、ReleaseTrack与Release来源事实；这些事实不是外部身份已经绑定的证明。

“专辑”字段沿用现有可播放条目覆盖及目录派生规则，可能更新派生发行归属；手工绑定和引用不会被自动写成在线ID。完整Recording／Release身份接受仍待独立开发，不能把本次文本批次等同于身份匹配或全专辑原子提交。
