# ADR-114 内嵌缓存封面优先与播放详情队列检索

日期：2026-10-03  
状态：源码、类型与编译检查通过；真实歌曲与界面验证集中到 MVP。

## 问题与范围

按用户要求优先读取歌曲自带封面，并通过播放栏封面进入包含歌曲信息、完整封面、滚动歌词、播放模式和播放列表的详情页。现有在线封面两阶段读取和详情页已有这些入口，本批检查并修正回退路径，完善列表查找。用户报告的实际歌曲缺图尚未复现，不能据此宣称根因已确认或问题已实机修复。

## 封面选择

- 在线读取保持歌曲内嵌正面图片优先，其次其他内嵌图片。内嵌标签完整读取且没有可用图，才读取同名或目录图片。
- 标签读取或转换组件失败保留可重读反馈；不把失败当作已确认无图。文件观察、读取边界、转换预算、资源租约与旧结果隔离沿用既有实现。
- 离线或读取失败恢复保存图时，原查询先按请求尺寸排序，可能在已有 1024 内嵌图和 256 目录图时，优先展示 256 目录图。本批先按 embedded 来源排序，再按请求尺寸及较大尺寸排序。
- 同一文件仅有 256／1024 两个选择引用，查询仍最多读取两条。损坏字节、拒绝 token 或不满足观察要求的条目继续跳过；没有可用内嵌缓存时可使用目录缓存。
- 较小／较大缓存来源及离线／旧缓存标记继续显示。没有修改图片原文件、标签、缓存表结构或数据迁移。

## 播放详情

播放栏封面打开歌词详情，队列按钮打开播放列表。歌曲、专辑、艺人及风格信息显示；可检索字段跳到对应曲库分类，保留实体 ID 与艺人角色。封面完整显示；歌词可跟随播放、手动浏览、回到当前行及点击时间行跳转。顺序、列表循环、单曲循环和随机播放沿用持久队列命令。

详情播放列表新增本地搜索：NFKC 规范化、大小写折叠、空格分隔词全部匹配歌曲／歌手／专辑。仅过滤已有最多 500 条队列视图，不查询文件、创建新队列或改变播放顺序。

原始 entry ID 和完整队列序号保留，播放／上移／下移／移出操作继续调用原修订命令。过滤时移动仍按完整队列的相邻位置执行。当前条目保护、不可用状态及原忙状态不变。搜索结果数、清除、空结果提示和键盘可访问滚动区一起提供。

“定位当前曲目”在有搜索条件时先清除本地搜索，等待完整列表渲染后滚动定位；自动当前项变化不会擅自清除搜索。清除按钮将焦点返回搜索框，避免按钮消失后丢失键盘位置。搜索只在详情组件内保存，关闭详情后不持久化。

## 验证边界与 MVP 检查项

Main／Renderer 类型检查、Main 构建、最终 Renderer 构建（114模块，主块383.16 kB／gzip120.40 kB）、audio-host／waveform-worker／credential-vault／media-worker／system-media及既有金样程序编译、41个 CommonJS 语法检查通过。发行生成文件及分发清单（18个 npm运行依赖／5个 vendored组件）核对，源码另做 ZIP CRC核对；不增加或执行小功能单元测试，不运行应用、真实文件、SQL、图片解码、驱动或硬件。

MVP 集中核对：

1. FLAC／带 ID3 的 WAV／DSF／未压缩 DFF 的实际内嵌封面；正面与其他图片排序，无图目录回退，损坏标签／图片明确错误，同源 CUE 与切歌旧结果隔离。
2. 1024 内嵌图与 256 目录图并存时离线／重读失败优先内嵌缓存，缺损内嵌缓存回退、拒绝 token 和资源租约行为。
3. 封面点击详情、关闭返回焦点；艺人／专辑／风格检索，歌词滚动／暂停跟随／跳转，播放模式保存及队列编辑。
4. 搜索大小写／全角／多词、相同歌曲重复 entry、空结果、不可用曲目、筛选后移动原始相邻项及当前项定位；窄窗口和放大字体时控件可达。

DSD 私有会话和应用接入继续按架构开发。本批未新增 DSD 直通能力，也未生成新安装包。
