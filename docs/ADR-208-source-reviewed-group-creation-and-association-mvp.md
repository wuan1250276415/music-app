# ADR-208：来源审核的概念创建／关联及独立补偿 MVP

日期：2026-10-14；源码0.201.0，schema75／媒体15／音频IPC1.23。完整架构计划继续，仅ASIO实机验证暂停。

## 完整用户流程

从整专辑对应进入“审核专辑概念关联”。来源提供已验证的ReleaseGroup标识，且全部本地轨目已有对应、来源普通曲目表完整时，可以把当前单个发行版加入专辑概念；首次建立不要求虚构第二个本地发行版。

若来源标识已有本地概念归属，沿用该概念及其标题／标识，显示全部现有发行版；否则拟新建概念，采用来源标题／类型并记录核心文本来源及MusicBrainz引用。当前发行已有其他概念时，单独展示原概念的全体版本，明确说明本发行将退出原概念。只移动当前发行，原／目标的其他发行版、录音、文件及文本不会合并。

三个范围分别确认：当前发行及全部曲目、目标概念的全部成员、原概念退出影响。默认均不选。来源概念已是当前归属时，只说明已经关联，不产生重复修订；来源没有标识、发行曲目未完成审核、源发行已有其他本地归属时不能批准。

审核／撤销使用独立弹窗、焦点与背景隔离；全体版本保留在审核快照，界面按25条分页显示，避免一次绘制5000条。规范来源页面可主动打开。初始检查发现新弹窗未复用共享按钮／勾选样式，现已统一；最终界面截图单独检查。

## 保存和重试

Main、Service及仓库读取闭合请求，仅接收审核键、命令ID和范围勾选，拒绝调用者提供目标ID、标题、类型或来源。由已授权的整专辑上下文生成短期计划，并绑定当前发行资料／引用／全部成员、原概念和已有目标概念的完整资料／引用／成员。

审核最多4份、合计16MiB，期限继承原候选；无后续访问也主动清理。取消、暂停在线、维护及关闭曲库释放计划。返回的展示对象与私有快照分离，修改展示标题／标识或本地对象不能改变保存授权。

在同一事务中重新验证许可、原候选、全体对应、源标识归属和全部快照；然后创建或沿用概念、保存来源／引用、更新本发行归属和曲库修订／检索、记录catalog_change及聚合回执。末段审计失败会回滚新概念、来源字段、引用、成员、绑定及回执。授权后来失效、目标后来被其他本地概念声明或成员变化时必须重审。

新建的标题／类型使用现有metadata_observation／field_decision，记录MusicBrainz核心CC0授权快照；已有概念资料不被源文本覆盖。catalog_change记录onlineGroup来源、目标、当时发行、创建或沿用及前后成员／引用快照，不增加SQL结构。来源保存设置有独立概念关联计数、待撤销计数、分页记录及专门撤销入口。

已成功请求在授权前读取持久回执，事务开始后再次核对回执；取消、离线或重启后相同请求不会重复建立概念。相同命令ID的新请求拒绝。不会把新来源直接用作本地主键。

## 稳定关联、成员修订与补偿

明确关联将当前已审核的录音／轨目图绑定到可播放条目，保留原有所有ID，不复制或合并录音、曲目或发行。随后文件标签改变时，Catalog.sync不会把这个被绑定的同一轨目移动到新派生发行；原文件标签／展示值仍可独立更新。撤销先核对有效文本／路径、条目及实体修订，避免撤销覆盖后来的编辑或扫描变化。

在线概念关联与既有手工概念关联共同推进已有entity_reference_state的单调修订，包括移入和移出。增加成员后再补偿撤回，也不会重新放行旧审核／旧撤销；引用、资料或成员的后续改动保留当前关联。

独立撤销恢复当前发行的原概念和本次建立前的条目绑定，不修改其他发行或录音。如果此次新建概念，同时移除本次新增MusicBrainz引用；空概念、字段来源和审计保留。沿用的目标概念原引用保留。来源记录继续显示已经撤销，撤销命令也有持久回执。整个概念及其全体发行版的自动合并尚未实现。

## 集中 MVP 证据

集中命令`npm run test:metadata-identities-mvp`，需先完成当前原生构建。调用生产Main／preload／Service／渲染／监督图片处理／SQLite；在线部分只替换fetch边界，不注入候选或授权凭据。

- 概念关联仓库19项：单发行创建、独立确认、窄请求、完整对应／来源约束、返回快照隔离、末段失败全回滚、核心字段及引用来源、ID／文本保留、来源历史、重启／取消重试、创建撤销、已有概念采用与独立补偿、成员变化的单调失效、原概念退出确认、返回原归属、后获外部归属冲突、已绑定图的标签重扫保护、主动到期、75备份检查／重开和完整性。
- 既有身份27项、轨目／74→75升级14项继续通过。阶段性失败不作为最终成功；最终报告及MVP命令对应当前构建。
- 实际桌面链在原38项基础上增加已有目标弹窗采用第二发行及受控引用编辑回归，最终40项。新建／未勾选时禁提交／来源记录／关联撤销／离线重启经实际生产路径；第二发行采用同一概念，保留两个发行ID。后续手工概念／六身份／逐实体补偿回归保持。

重扫检查首次暴露了原候选轨目即使被绑定，仍在派生扫描时移动到新发行的缺陷；已限制同一被绑定轨目的派生更新。第一版保护误把首次扫描的两个undefined当成已有绑定，普通导入失败；明确区分新轨目后，最终导入、重扫及全链集中检查通过。失败日志保留。初始界面样式截图也保留为修正记录。

## 发布和边界

Windows0.201试用包单独构建、核对编译文件及资源摘要、未签名，不执行用户机器安装或网络发布。发布运行检查与源码在线夹具阶段在报告中分别标记；源码在线审核到实际发布目录离线接续不等于发布目录真实网络图像／匹配正确性验收。安装／升级／卸载完整流程、现实匹配真值集、其他发行范围及大库性能仍需验证，不能用原生编译证明硬件行为。

没有修改用户原曲库／音乐，也没有本轮现实网络概念接受、图片保存或新增音频设备验证。原《晴天》再次只读核对无内嵌图片且摘要不变。

完整概念／发行／录音实体合并及多人角色、整专辑真值集／召回、隐藏／数据轨、ISRC／指纹、多来源／更多字段、全库批量、完整来源生命周期／写回／恢复、规模与长时间性能、设备及发布门禁继续；完整V1未交付。
