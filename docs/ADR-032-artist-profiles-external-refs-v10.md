# ADR-032：独立艺人资料与外部引用（schema v10）

日期：2026-09-30。状态：开发原型采用；完整 WP03 和发布门槛仍待验收。

## 行为与领域

艺人管理不能依靠扫描到的姓名字符串或在线 ID 作本地主键。相同名字的不同人物可以有独立 UUID；创建后无需已经拥有音乐文件，也可以作为逐曲署名或跨目录身份关联的目标。

曲库工具栏“艺人资料管理”和署名面板“创建或管理艺人资料”提供独立身份创建、名称、排序名称、区分说明及外部引用编辑。区分说明参与资料检索和候选辨认，当前艺人分类显示说明。资料管理仅编辑人工身份，标签候选仍由扫描维护；原有来源关联指向稳定身份。

更名刷新所有当前曲目和专辑艺人引用、分类与检索，同时保留物理文件、PlayableItem、收藏、评分、重复歌单 entry 和队列。人工署名的名字按身份更新，原始复合标签呈现继续保留；修改复合署名显示可另用署名编辑。标签更换为新的姓名字符串会生成新的本地候选，不自动关联原身份。

## 外部引用

新增 `external_ref(entity_kind,entity_id,provider,external_id,url)`。实体种类限 Artist、Recording、Release 和 ReleaseGroup，触发器检查实体存在，Artist 限未归档的人工身份。本轮服务/UI 只提供艺人引用编辑；其他种类的编辑、查询和 Provider broker 仍未实现。

应用内 UUID 与在线 ID 分开。每个艺人可保存最多 32 条引用，同一实体允许多个来源 ID；同一个种类／Provider／外部 ID 只能由一个本地实体声明。冲突拒绝，不据此自动合并同名人物。来源标识规范化为小写，未知来源保留其不透明 ID；引用集合按确定的字串规则排序，避免回执和无修改判断依赖对象顺序或运行环境排序。

MusicBrainz 引用检查 36 字符 UUID 格式，规范化大小写，并生成与该艺人 MBID 一致的 HTTPS 地址；多个 MBID 可以保留。MBID 的稳定身份、合并后重定向和实体 URL 规则依据[官方说明](https://musicbrainz.org/doc/MusicBrainz_Identifier)。手动填入的 ID 没有经过在线实体存在／类型核验，不表示来源已连接或已同步。

其他引用接受可选 HTTPS 链接，拒绝非 HTTPS、账号信息、控制字符和过长值。用户点击打开时，Main 从 Library Service 重新检索所保存引用并检查艺人预览修订，随后校验协议并交给系统浏览器；Renderer 无法向该接口直接传任意 URL。本轮不自动联网读取引用或覆盖音乐元数据。

## 修订、归档与撤销

`artist_identity_state` 复用于人工身份和本地别名修订。资料编辑递增该身份及其全部绑定来源的修订，使旧署名／身份确认请求失效；当前引用项更新投影、曲库修订与搜索。

预览指纹覆盖身份字段、外部引用、全部来源别名、当前署名／专辑署名及项修订，包括隐藏 CUE 和离线文件。新增成员或别名即使没有增加目标身份修订，也使旧资料预览及旧资料撤销失效。Owned command 在单写入事务重新检查指纹，UUID 参数回执、字段、引用、相关修订、搜索和 `artist_profile_change` 审计一起提交，跨重启重放成功回执。

仅没有当前曲目引用、也没有来源候选绑定的人工身份可以归档。归档保留 UUID 和历史行，移出候选／管理列表并释放外部引用；可通过统一曲库修订记录撤销。撤销创建也采用归档。数据库防止把归档身份用于新的来源绑定、署名或激活历史署名／发行；旧署名恢复遇到归档人物时拒绝，须先恢复人物。

撤销资料／归档重新检查后置指纹和成员，恢复前置字段／引用并递增修订。已释放的外部 ID 被另一个身份声明时，恢复拒绝并完整回滚。后续重扫或编辑冲突时须重新整理，不静默覆盖新状态。排序名称采用显式文本键排序，语言区域排序和拼音规则仍待 WP05。

## 迁移与验证

v9 库先一致备份为 `.pre-v10-*.bak`，再事务增加 artist.archived、活动引用检查、external_ref 和资料审计表。投影增加区分／排序信息后，重建指纹与搜索，保持原项修订不因投影升级递增；旧关联、艺人和发行修订可继续撤销。迁移失败回滚到 v9 并保留备份。

单元测试覆盖同名独立身份、规范化回执、所有角色及别名修订、检索／分类、保留用户引用、重扫、成员冲突、外部归属冲突、非法地址、归档／历史署名拒绝、后段失败的完整回滚，以及 v9 备份／旧审计撤销／DDL 回滚。

桌面自动化使用真实 ID3 文件验证创建、同名区分、署名引用、跨目录别名、更名、外部引用保存、归档／修订撤销、详情检索、实际播放、强制重读标签和重启恢复。浏览器打开被替身拦截，断言 Main 交给系统的精确链接；未真实访问这些测试来源。既有封面、歌词、收藏、歌单和发行整理继续回归。

## 尚未完成的完整范围

本轮人工资料编辑每次最多影响 5000 个文件／来源身份；资料与关联曲目每页最多 100（UI 50），别名预览显示前 50 条并保留总数。成员指纹／全量更名仍待十万库与长时性能验收；主页面最小窗口横向溢出仍待 WP05。

尚需补其余实体的外部引用及完整发行字段／署名编辑、实体字段来源与锁定、Provider 在线核验／批量、CUE 任意改写身份对账、呈现时钟历史和故障恢复。ASIO 实机验证依用户要求继续暂停。完整 FR01–FR14 与 G1–G5 的完成标准保持原架构范围。
