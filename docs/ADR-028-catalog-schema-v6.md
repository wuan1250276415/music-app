# ADR-028：艺人署名、发行候选与曲库 v6

状态：已实现并进入开发版验证，2026-09-30。推进架构 §7–8、FR04/05/06、WP03/05；不宣称完整领域模型冻结或相应发布门禁通过。

## 当前行为

扫描保存 music-metadata 提供的多值曲目艺人、专辑艺人、作曲、指挥和全部风格标签，以及发行日期、国家、厂牌、目录号和条码。原始署名 display_text 与有序成员分别保存；没有明确连接词时 join_phrase 为 NULL，保留原始显示字符串，不猜造 feat. 等连接词，也不把 AC/DC 一类单个标签按斜杠拆分。乐团角色在仓储和界面中可表示，通用扫描适配器尚无可靠的跨标签乐团映射。

艺人视图可切换曲目歌手、专辑艺人、作曲、指挥和乐团角色。详情页逐个艺人、角色和风格可点击筛选；专辑链接按具体本地 release ID 检索，避免同名专辑混入。分类返回独立 ID、数量和目录/日期说明，至多 200 项；分类分页仍待大库工作包。搜索索引包含参与艺人、专辑艺人和所有关联风格。

本地发行候选按授权根、目录上下文、完整专辑名、专辑艺人、日期、国家、版本说明、厂牌、目录号和条码分组，不用专辑名作为唯一键。没有专辑艺人时保留空署名，不把合辑中每个曲目歌手冒充专辑艺人。明确碟号与 CD1/Disc2/Disk3/碟4 目录匹配时，使用父目录作为候选上下文，按碟号/轨号展示。此规则仅是本地候选推断；目录不匹配、日期或标签矛盾时保守分离，后续需要人工确认。未知专辑按可播放条目分离，CUE 的未知专辑按文档分离。

## 数据与一致性

v6 新增 artist、artist_credit/member、release_group、release、medium、recording、release_track、genre、item_genre、release_genre、item_catalog_source。PlayableItem 增加 recording_id、release_track_id、artist_credit_id 显式 FK。medium 中碟号唯一，release_track 中位置唯一；打印轨号另存，不以印刷轨号充当已确认的发行轨身份。本地实体使用 UUID，外部 ID 尚不作本地主键。

目前未确认的录音与发行曲目每个 PlayableItem 各有独立候选身份；不凭同名、相同轨号或指纹猜测就合并不同文件。多个本地版本指向同一已确认 Recording/ReleaseTrack 的人工关联、拆分/合并修订及外部引用验证仍待实现。artist 名称候选按根目录和精确文本限定，标记 local-tag-candidate；同名实体可存在，候选并不等于全球艺人身份确认。ReleaseGroup 暂不自动关联。

扫描的源标签 JSON 独立保存。扫描/元数据确认/撤销与关系投影、兼容字段及搜索索引在同一 LibraryDatabase 事务更新；曲目 ID、录音候选 ID、发行曲目候选 ID、收藏、评分和歌单引用保留。改变专辑标签时移到新候选，撤销时返回既有候选。重扫只替换 source=file-tag 的风格关系，其他来源不被删除。列表与队列用批量查询附带关系投影，不逐行往返 Library Service。

v5→v6 使用 VACUUM INTO 保存一致的 pre-v6 备份，DDL、回填及版本推进在事务中执行。迁移失败回滚并保留备份。旧版原有单值标签只能作为候选回填，不伪造此前丢失的多值标签；目录旁的“重新扫描”会补读未保存结构化源标签的文件，即使文件大小/修改时间未变。0.22.0 不能直接打开 v6；回退需使用迁移前备份，后续编辑不在旧快照内。

## 验证与剩余范围

新增仓储测试覆盖角色、署名顺序、精确斜杠名字、重复规范风格、自定义来源保留、同名发行分离、多碟目录、标签确认/撤销、FK/唯一约束、用户引用和队列保留、迁移备份/失败回滚，以及真实 ID3v2.4 多值文件扫描。

桌面测试从隔离 v5 曲库升级，重扫并按具体发行筛选，再验证作曲/专辑艺人角色、实际本机播放、封面、详情各个署名链接、多碟轨序以及原收藏/评分/重复歌单保留。发行版结果在 README 0.23.0 记录。

尚未实现领域身份人工审核/合并、外部 ID/署名连接词的完整 Provider 契约、ReleaseGroup 聚合、自定义风格层级操作与循环校验、字段决策/来源/锁定及 outbox。部分旧时间列仍为 ISO 文本；统一毫秒整数及大型曲库迁移性能需要后续显式迁移和基准，不能把本次绿色测试作为十万曲或完整 WP03 的验收。
