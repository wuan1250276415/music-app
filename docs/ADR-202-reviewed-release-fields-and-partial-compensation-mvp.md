# ADR-202：发行字段审核保存与逐字段补偿撤销 MVP

日期：2026-10-13。源码 0.196.0；曲库 schema74、媒体协议15、音频 IPC1.23 保持。完整 FR01–14／WP01–11／G1–5／AC01–19 目标继续，仅 ASIO 实机验证暂停。

## 问题与结果

0.195 能主动读取所选 MusicBrainz 发行版的上下文，但日期、地区、条码、唱片公司和目录号只有预览。歌曲关联的本地发行实体由多首曲目共用，不能把某一首歌的预览直接覆盖到整张专辑，也不能用整份旧快照撤销后来人工改过的字段。

本版本增加“审核并更新发行资料”：五个字段默认不勾选，显示当前值和在线值，明确影响的本地曲目条目数量；唱片公司与目录号按来源中同一条 label-info 配对，多个条目必须手工选一个，避免自动拼接或错配。未提供的在线字段不能清空本地值，无值差异或已锁定字段不能应用。明确确认发行版、更新范围和勾选字段后才保存。只更新曲库的这些共用字段，不改文件、歌曲标题、艺人署名、版本身份或曲目归属。

## 服务端边界与数据

生产 Provider 验证发行上下文，Service 在请求前后检查歌曲资料指纹、候选、在线状态和本地发行快照。只有已载入曲目表包含当前 Recording ID 的结果才生成发行审核凭据。列表缺失或隐藏／数据轨未审核继续明确显示，不能推断整张专辑已正确匹配；用户仍需核对版本和不完整本地曲库。

凭据只保留于 Library Service 内存，最多128份，期限继承来源上下文，绑定本地曲目、候选、发行修订和成员指纹、来源策略／锁指纹以及只读在线值。返回界面的对象与服务端保存的对象分离。新申请只接受命令 ID、曲目 ID、审核凭据、五字段枚举、label-info 索引和范围确认；不接受调用者提供的字段值、来源 URL 或发行目标。Main 与 Service 都执行窄请求校验。

新保存必须允许审核后的 MusicBrainz 核心文本保留；暂停新的保存不会删除既有信息。保存事务检查凭据、候选、期限、当前成员和字段锁，记录既有 CC0 核心授权快照下的不可变观察、选定来源和审计，更新成员修订与检索资料。复用既有 release_profile_change 和 user_command_receipt，无数据库结构迁移。已提交命令先检查持久凭据，重启、候选失效或暂停在线后仍能核对同一命令结果；相同命令 ID 改请求会拒绝。

## 撤销

发行保存保留五字段中的实际变更集合。逐字段撤销预览检查当前值、来源决定及其单调修订、选定模式、自动来源候选、字段锁和发行成员。后续人工编辑、锁定、来源变化或成员增减的字段保留当前值；其他未冲突字段仍可明确勾选恢复。

撤销追加补偿审计，恢复所选字段的旧值与旧来源决定，使用新的单调字段修订；不恢复整份旧发行实体或清除其他字段、署名、文件、播放列表。全部字段补偿后才把原修订标记为全部撤销。通用曲库撤销入口不能绕过逐字段预览。来源保存设置中合并列出歌曲和发行修订，并把发行记录导向专门的逐字段撤销界面。来源观察与审计保留，不等于彻底删除来源数据。

## 实际限制与后续

本轮没有把用户的真实《晴天》在线资料写入原曲库或文件。0.195 的真实查询证据仍为《叶惠美》2008 JP版2碟22轨，《晴天》第1碟第3轨，CAA 未返回封面；0.196 没有重复真实 CAA 查询，也没有新增现实有图歌曲的下载／保存证明。内嵌优先规则保留，不能凭文件有歌曲标签推断有图片。

尚未完成整张专辑匹配／身份接受、隐藏／数据轨的完整关联、指纹／多来源／更多字段、批量更新与完整写回、所有来源清除和恢复流程、规模性能及发布验收。发行源 URL 是这次已审核字段的来源，不是本地发行与 MusicBrainz 身份绑定的证明。最新内部试用安装包仍0.190.0；实际安装／升级／卸载没有新增验收，完整V1未交付。
