# ADR-135 英文错拼倒排召回与有界重排

日期：2026-10-06。状态：0.129.0 源码实施，SQL／迁移、真值集和界面验收留到MVP。对应架构10.2、FR05、WP05与AC09，完整检索功能尚未验收。

## 范围与索引

现有原文trigram、中文一／二字倒排和拼音／首字母继续保留。增加标题／艺人署名／专辑及相关资料／风格的拉丁词派生索引，不修改原始标签或人工覆盖。派生词采用NFKD、移除组合重音和小写ASCII拉丁词提取；是常见重音字母折叠，不代表完整繁简、任意语言转写或语义搜索。

schema59新增search_word、search_word_gram和search_item_word。gram为带词首／词尾边界的bigram与trigram，主键支持gram→word召回，word→item反向索引用于结构化过滤及归属核对。关联在PlayableItem删除时级联，最后关联删除时清理无引用词及gram；词是可重建派生数据。每字段只提取前4096个字符、最多64个不同的2–64字母词；截断尾部词不入库，防止造出原文中不存在的词。原文及拼音字段不采用这个截断。

SearchIndex算法标识包含拼音和独立英文词算法版本，升级时沿用现有building／ready／error、64项读取、25ms合作预算与cursor检查点。旧曲库先迁移空表，再后台补建；状态通知说明结果可能不完整。扫描、有效元数据更新、覆盖／撤销及删除在既有事务中同步更新派生索引和content_revision；不在Renderer计算全库编辑距离。

## 查询路径

错拼只针对最多4个不同拉丁词、查询≤256字符。每词2–64字母，至少一个词≥4字母；2／3字母伴随词要求完全一致，不对短中文或混合汉字查询宽松纠错。4–7字母词最多1处编辑，8–64字母最多2处；使用受限Damerau-Levenshtein／OSA，包含相邻字母换位。这不是允许任意重叠换位的完整Damerau距离。

按查询长度选择bigram或trigram，通过有界参数化gram查询、词长度区间和共享gram数召回。最多300个候选词，均分给查询词；以共享gram及词本身稳定排序，逐词计算距离。编辑距离是有界词计算，绝不对十万PlayableItem逐个计算。召回有截断，因此不能声称覆盖所有距离内词；超常长字段、候选竞争和真实词典分布需在MVP真值集验收。

候选词关联回条目，按查询词分组取最小距离，所有查询词均须命中。沿用原列表的歌手角色、发行、风格交并集／后代、目录、收藏、歌单及可见性SQL过滤，过滤后最多300个纠错条目，按总距离、字段优先级及itemId选出。歌单仍保留重复entry和原顺序；其他视图纠错按距离重排，并沿用原稳定的资料／碟轨／id排序。

原文／中文／拼音路径以参数化direct_matches CTE保持，所有直接命中优先于新近似召回。直接结果按标题精确、艺人精确、前缀、子串、署名或拼音基础层级排序；基础层级使用列表原字段，完整艺人身份／资料的精细相关度仍需后续补齐。纠错条目排名靠后，不挤掉明显直接命中。规范化词一致而原文字母写法不同显示normalized；实际编辑差异显示spelling及总距离。

LibraryItem增加可选searchMatch，列表对近似／字母匹配显示标记，悬停文本给出匹配原因。总数、版本折叠、分页和按查询播放使用同一列表计划；browse snapshot对拼音与英文查询都包含派生content_revision，构建／编辑期间旧分页及旧播放请求失效。
