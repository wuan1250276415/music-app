# ADR-221：识别异常分页、定点重试与事务进度 MVP

状态：0.214.0源码集中MVP通过；完整V1未完成。2026-10-15。

对应FR06／WP08及后台任务失败定位、继续和回执。原接口保留当前页明细，新接口按工作清单固定ordinal提供全部记录／失败记录，固定100项、稳定游标，并包含已移除成员。通过失败索引和重试成员集合合并定位异常，避免只显示最后一个识别页。Library仅对当前返回的最多100项读取歌曲标题／路径；界面按页加载，可从异常行打开当前歌曲文件管理，不触发播放或写文件。

新增retry-failed命令，使用既有UUID、修订比较和持久回执。可显式提交1–100个不重复ID，或省略ID由Library在事务中固定全部失败范围；不要求Renderer把整库失败ID加载到内存。任一所选项不属于任务、已成功或已保存计划／跳过时，整个请求拒绝，不静默缩小。相同命令先查回执，不能变更原意图或多建一份范围。界面发送前读取同一任务页代次的当前修订，未确认时保留原请求，只读核对回执。

schema79增加run.retry_active、metadata_recognition_retry及metadata_recognition_progress。重试成员保留job/item及原分类错误码，依旧属于固定工作清单。工作清单保存计划或明确跳过时，用同一事务内的触发器同步移除该重试成员并更新阶段／计数；不能在已保存计划旁留下无效待办。重试与原整库cursor分离，每次领取最多100个重试成员，完成一项才从重试范围移除；单项失败仍保留失败记录。限流、鉴权等全局错误停止并保留尚未处理成员。显式重试强制重新读取当前音频／关联，其他成功依据保持，不从头重新识别全部歌曲。缺失或不可见成员定位为来源错误后结束本次尝试，不发送网络请求。

暂停中止在途查询并等待实际工作排空，未完成重试成员及原错误原因仍在。真实进程退出后正常启动释放原页、标为中断；只有确认工作清单继续并确认后台继续，才处理原剩余重试范围。取消清除重试意图，把未完成项恢复为可解释的失败记录，不把取消当作成功。重试完成后若整库原cursor还有未推进部分，则回到暂停等待用户继续原整库，不通过定点重试跳过其余工作。工作清单暂停／取消或成员已处理会清理失效的重试归属；旧选择不能复活计划或跳过项。

进度汇总保留已存映射、失败行和待重试数量。迁移先根据现有记录初始化；SQLite触发器与映射／阶段／队列增删在同一事务更新，故障回滚也一起回滚。正常查询仅点查汇总与最多100项当前代次阶段统计，不再对整个映射和所有失败逐次COUNT。恢复检查独立重新计数、核对归属、命令读者、重试状态和原错误码；篡改汇总不能让恢复通过。此处给出205项数据、200次读取SQL观察及点查查询计划，不宣称十万首实机P95、吞吐或长期内存已通过。

Main/preload增加闭合异常分页请求，拒绝任意limit、额外字段或无效游标。Renderer保留跨页选择、最多100项选择预算，提供明确的全部异常重试。选择已变化时显示可读原因和核对入口，不自动采用新一轮范围。识别工作清单与批量审核错误提示移除内部RPC前缀，保留对用户有用的来源变化和重新扫描说明。

核心MVP16项使用声明为合成解析输入的205项生产SQLite工作清单／识别仓储，没有把它当作物理音乐或网络真值。覆盖三页失败保持、100+100+5无重复游标、闭合输入／超量／重复／外来ID拒绝、200次公开进度读取不再扫描映射与全部失败、跨页仅三项快照及回执重放、逐项完成与暂停保留、真实独立备份及只读十一域检查、实际数据库重开与明确剩余继续、队列插入后注入故障使成员／计数／状态／回执完整回滚、服务侧固定203项全部失败范围、取消不复活、处理成员与重试清理同事务并注入故障整体回滚、篡改汇总拒绝、构造保留205项失败记录的78→79升级及快照、首个ALTER后故障回滚全部旧结构和版本。
