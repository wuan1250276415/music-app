# ADR-050：歌词来源选择、独立偏移与辅助歌词（schema v24）

日期：2026-10-01。状态：源码实现；类型、主进程／界面（54 模块）／原生组件构建及清单核对通过，运行与迁移待 MVP。对应架构 §17.1、FR10、WP03/WP10。ASIO 实机验证继续暂停。

## 来源与时间基

保留原有自动顺序：普通音乐先选内嵌同步歌词，再选本地文件，再选内嵌纯文本；CUE 先选与曲名同名的逐轨文件，再选源音乐文件内嵌同步歌词。现在返回有界来源列表，用户可以指定主歌词和另一份辅助歌词。自动顺序尚不能编辑，显式来源选择覆盖自动决定。

本地文件支持同名 `.lrc/.txt` 及明确语言后缀，如 `track.zh.lrc`、`track.en-US.txt`。不按文件名推断“翻译”身份；辅助来源由用户明确选择。目录最多检查 4096 项、附加语言文件最多 14 个；过大目录后部候选可能不在当前列表中。每个本地文件用同一个只读句柄核对大小并最多读取 1 MiB + 1 字节，超额拒绝。UTF-8、带 BOM 的 UTF-16LE/BE 与 GB18030 回退记录编码；回退不是编码准确性的证明。

内嵌来源仍来自锁定的 music-metadata 11.16.1。以其本地 `lib/type.d.ts` 的 language/descriptor、毫秒同步字段为准；保留原始 LRC 标签解析优先及 MPEG 帧时间戳拒绝猜测的规则。普通文本没有逐字时间戳。第三方元数据解析前的内存分配不属于此模块的硬读限额，完整损坏标签压力验收仍待 MVP。

每个解析来源最多 5000 行、1 MiB 行文字；重复时间戳计入累计展示文字预算，避免序列化放大。返回最多 16 个来源、2 MiB 文档 JSON 预算。按来源类别／本地位置／语言／描述／LRC 偏移／类型／解析行内容生成 SHA-256 身份，原始与归一化的完全相同标签视图去重；不同语言或描述保留。这里的身份不保存原始字节和完整原文历史，原文持久化与导入留在完整 FR10 范围内。

LRC offset 单独记录在 sourceOffsetMs，已且仅已应用一次到解析时间。负时间保留，不预先压成零，防止提前的多行挤在同一时间；实际点击跳转最小为零。源音乐内嵌 CUE 歌词在应用来源偏移后，按 75 fps 轨范围截取并变为轨相对时间；逐轨同名文件原本就是轨相对时间，不再换算。源文件纯文本继续不自动复制给所有 CUE 轨。

用户主／辅助偏移分别是整数毫秒，范围 ±300000。正值让文字更晚显示。显示主行使用 `播放位置 - 主用户偏移`，点行跳转使用 `解析时间 + 主用户偏移`，不再次应用来源 offset。逐行定位使用二分检索，沿用现有 80 ms 高亮提前量；没有声称加入设备呈现时钟或 20–30 Hz 插值。

同步主／辅助行依据各自用户偏移后的时刻，以最多 750 ms 差距配对，同一辅助行最多使用一次；没有对应行就不拼接，不伪造字同步。辅助原文可展开查看。任一来源为纯文本时辅助文本独立显示，无时间对齐或点击同步假象。辅助开关、14–32 字号与主／辅助偏移保存后在侧栏和详情共同生效；紧凑侧栏字号按比例显示。

## 持久设置与迟到请求

schema v24 新增 lyrics_preference 和 lyrics_preference_receipt。设置作用域是曲目 ID、媒体文件身份／路径、普通或 CUE 类型及完整源范围的摘要；调整 CUE 范围后不复用旧偏移。主用户偏移另绑定所用来源身份，辅助偏移绑定选择的辅助身份。来源改变或缺失时暂时回到自动来源／不显示辅助，旧设置仍保存并提供提示；原偏移不应用到新来源。恢复同一来源可恢复对应设置。

请求带 UUID、scope 与 baseRevision，后台重新读取来源并核对当前曲目范围，再在同一事务中检查修订、来源身份、主辅不同与偏移归属，保存设置和不可变回执。已有库升级前作 pre-v24 一致备份，新增表和版本在事务中提交。v23 安装已增加条件保护，旧测试夹具逆迁移与四处最新版本断言同步维护，未运行迁移 SQL。

同一 UUID 必须携带同一规范请求，已提交回执只核对，不重放写入；重试返回当前有效设置，而非把历史设置重新安装。明确拒绝返回 rejected，可重新读取后作新操作；传输失败／超时保留原意图，界面禁止新保存并提供同一操作的核对按钮。若提交已成功而随后汇总失败，回执核对仍返回 saved，界面重新加载。意图当前在 Renderer 内存中，关闭应用后持久结果仍可读取，但尚无跨 Renderer 重启的待确认意图箱。

来源读取后再次检查曲目范围与可用性；迟到的界面读取和保存结果根据曲目／页面请求版本隔离，歌词点击沿用 expectedItemId 防止切歌后套用旧 seek。外部文件仍可能在读取与提交之间变化，未引入歌词文件写锁、文件监听或完整外部编辑事务。重新读取后依据内容身份重新判断偏移，不把上述检查称为文件系统原子快照。

## 验证范围与剩余工作

本批次类型检查、主进程／Renderer（54 模块）／原生组件构建、发行／分发清单及相关脚本语法核对通过。没有执行单元、SQL 迁移、桌面、真实歌词、播放或安装包验证；最新已验证安装包仍为 0.29.0。

MVP 矩阵：USLT/SYLT/FLAC 内嵌、多语言／描述重复、UTF-8/UTF-16/GB18030、后置正负 offset／重复时间戳／首行负时刻、5000 行／重复文字／1 MiB 边界、目录截断与缺失文件；CUE 内嵌时间与逐轨文件、不把整碟纯文本分摊；主辅独立偏移／无可配对行／纯文本／字号／侧栏详情同步／跟随手动滚动；切歌／重扫／CUE 编辑／内容变更／恢复原来源；修订冲突、超时后迟到提交、同 UUID 重试／不同请求拒绝、提交后汇总失败、重启读取、v23 备份升级与失败回滚。

完整 FR10 尚需用户导入、原文和编码版本持久保存、来源优先级编辑、Provider 校准与授权在线源、音译及按源逐字时间、呈现时钟插值、对比度设置及更多性能／无障碍验收。FR01–FR14、WP01–WP11 其余项目继续保留，不能把本批次编译成功当作 MVP 或 G1–G5 完成。
