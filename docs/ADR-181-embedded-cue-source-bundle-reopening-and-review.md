# ADR-181：内嵌 CUE 来源备份重开核对与解释复审

- 日期：2026-10-10
- 状态：0.175.0 源码接入，编译与发行静态核对；运行验收留至 MVP
- 对应：FR02、FR04、FR13、WP03、WP04、WP10、WP11；沿用 ADR-178–180

## 问题和决定

0.172提供内嵌 CUE 不可变来源历史及完整原始字节导出，但导出的JSON还不能重新打开。来源备份省略派生二进制轨道和文本解析树，避免重复原始字节与大量派生字段；直接把该备份当作原完整版本，或只比较文件内部声明的SHA，都不能证明原历史版本可重建。

本次提供本机选择、只读打开、原始来源独立核对及保存版本与当前解释的复审。沿用原 `aural-embedded-cue-source`／version1格式，不增加派生树，不修改历史导出文件、资产或回执。

| 内容 | 约束 |
|---|---|
| 根备份 | 固定7字段：format、version、versionId、capturedAt、source、binaryRawBase64、textFieldRawBase64；最大2MiB |
| 原来源 | 固定11字段，包括原文件／根身份、路径、字节数、艺人／专辑、来源种类和两类元数据 |
| 二进制元数据 | 固定10字段，已知parser1–4、块位置、原SHA、34字节STREAMINFO及其派生采样参数／CD／catalog／lead-in |
| 文本元数据 | 固定9字段，已知parser1–2、注释位置／字段序号、原SHA、STREAMINFO／采样参数和保存时诊断 |
| 原字节 | 二进制块256KiB以内、完整Vorbis CUESHEET字段512KiB以内；缺失元数据和缺失字节必须成对为null |

旧0.172完整源码归档中的原导出及版本构造公式已只读对照。固定根／来源顺序和派生来源属性顺序均按该实现重建；这属于源码依据，原始真实导出文件及旧解析器运行等价仍待MVP证明。

## 文件和进程边界

Renderer只触发固定的打开备份命令，不能指定读取路径、文件大小预算或解析器。Main使用原生文件选择器，限制一个JSON文件。新增私有 `source-json-file.ts` 与外部CUE入口共用原读取规则：独立普通文件、初始nlink1、同一打开句柄有界读取至EOF、前后句柄／路径属性观察、严格UTF-8，规范对象两空格缩进及末尾换行与原文件逐字节比较。根和嵌套重复键、额外字段、BOM、尾随资料或格式改写均不能通过规范字节比较。内嵌2MiB和外部8MiB各自保持，不向Renderer开放可调预算。

20秒守卫覆盖读取与JSON处理前后，是合作检查；不能中断阻塞中的OS调用，也不是Library同步解析的硬取消保证。Main保留本轮主文档epoch核对、整个IPC维护工作范围以及外部／内嵌导出与打开共享的CUE文件占用。窗口／文档改变后不发布旧结果；取消选择返回null。

Library收到私有内容后，再次核对固定形状／预算，并对规范完整JSON独立重算摘要，与Main实际读取的文件SHA比较。保存时间不在历史版本payload摘要中，本轮完整文件摘要核对仍覆盖它；这不能把未经签名的时间、路径和身份声明变成可信来源授权。

## 原版本重建与当前解释

Library不访问数据库、磁盘或音乐。它核对规范base64、原始字节SHA、来源位置与记录文件字节数范围，按原字节解析STREAMINFO和二进制结构，并比较所有保留元数据。二进制已知旧标记只在重建时恢复，原解析字段仍从原块独立生成；文本parser1调用ADR-180的固定parser3 FILE语言，文本parser2使用当前语法。坏UTF-8及无效文本文档仍生成对应保存版本的错误树及诊断，不把无效来源丢弃或强制改成有效编排。

按原来源11字段顺序重新构造完整payload，恢复原始二进制tracks和文本document的位置及字段顺序，计算其UTF-8字节数和SHA。只有2MiB以内且SHA严格等于保存的versionId，才显示来源复审。二进制与文本并存时STREAMINFO必须一致。未知parser及任何原字节／头部／参数／诊断／版本不一致都拒绝。

通过原版本核对后，另行用当前二进制parser4和文本parser2解释同一原字节，生成保存版本／当前采用状态、音轨数、采样率、完整采样数与提示，比较完整解释结果。Parser标记升级本身不构造语义变化；曲目信息、范围、字段或采用状态变化则显示不同。

当前音轨范围以BigInt按明确时间基准换算回原整数采样，须整除、非空且不超过保存的总采样数。此范围是来源解析结果，尚未核对任何实际文件、音频载荷、可用性、权限或当前曲库映射，不能据此播放或直接应用。

## 界面与显示预算

内嵌来源历史页新增“打开内嵌CUE来源备份”，空历史或当前来源不存在时也可使用。预览显示当时位置／时间／艺人专辑、保存版本与当前结果对照、原文及明确提示；摘要、解析标记、二进制索引、FILE名称和原采样范围放入可展开内容。新预览获取焦点，关闭后返回打开按钮。

文本与二进制预览各131072字符；二进制最多128轨、每轨32索引；当前轨道最多128条且标题／艺人各256字符；FILE名称最多64条且每条512字符；艺人专辑资料各512字符。所有省略状态明确显示，原文件字节保持完整。FILE、CDTEXTFILE和其它路径只显示文字，不读取声明路径。

该入口不注册来源、不绑定曲库、不重扫、不修改音乐或数据库、不恢复旧解释、不产生播放权限。原文件字节数和STREAMINFO不能代替原音频内容摘要。历史映射／本体与权利审核／重新应用和批次恢复继续作为完整目标中的后续工作。
