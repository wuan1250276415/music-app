# ADR-214：尚未更新项重新审核及发行资料留存 MVP

状态：0.207.0 源码集中MVP通过，完整V1未完成。2026-10-14。

旧批次执行出现冲突、过期、失败或取消剩余项后，需要重新读取当前曲库并重新匹配，不能继续使用已失效的旧候选。新增闭合 `{batchId,revision}` 请求，由可信Main验证后调用Service／仓储；服务端从原批次推导范围，拒绝调用方替换曲目ID和其他字段。包括待执行、冲突、失败、过期、取消剩余项；排除已更新、已撤销及撤销冲突项。离线仍可读旧计划与当前已保留曲库资料；缺失条目明确报告，媒体离线不自动丢弃已保存标签。

重新审核对话框显示旧原因、旧字段差异和版本资料，当前条目由服务端重新读取，候选与字段均清空；网络默认状态保持，明确启用并查询后逐字段确认。新计划记录原批次ID与审核时修订，创建时再次核对原修订和所有提交成员仍在未更新范围。旧计划不隐式取消、改写或替换；新旧执行都保留既有曲库／来源修订保护。字段可以在新审核中重新选择；新计划独立执行、取消及补偿，界面可返回原计划。

旧命令形状不变，retryOf可选。原请求身份／回执校验仍在事务入口，已成功的重试不依赖旧预览或网络；新建时原范围／修订、当前字段修订和私有候选全部核对后保存，末段错误完整回滚。没有新增SQL迁移：私有已接受候选JSON保存batchOrigin与batchEdition；展示对象中伪造同名字段不授予原范围或版本内容。根来源从各行保存数据闭合校验并要求一致。批次行展现发行标题、日期、地区、介质、说明、状态、条码与实际读取时间；未填写的值保留null，旧计划不会凭空补造历史版本资料。这些是字段来源的上下文，不建立录音、发行或专辑概念身份。

集中验证：生产Provider／Broker／缓存／SQLite批量26项，新增闭合读取、旧冲突当前快照／排除已补偿项、旧修订与越界成员拒绝、末段故障回滚、关联与回执、独立离线执行／补偿、过期／执行故障／取消剩余接续；schema75备份重开保留旧冲突、补偿、新关系和具体版本。既有身份27、轨目14、概念19、署名14、直接查询14、ISRC16通过。实际Main／preload／Service／Electron81项通过，新增旧修订／伪造范围拒绝、离线单曲重审未默认采用、明确新查询／字段／范围、独立计划／旧历史保持、离线执行补偿／返回原记录及媒体离线重启来源保持。

首次类型检查发现读取条目缺失的undefined／null边界，已修正；首次桌面检查点击返回原记录后尚未等到新结果即断言，测试改为等待真实原标题和错误提示。重启验证进一步发现原测试随机选择轨目撤销目标，后续重审使原歌曲旧轨目审核失效时，不能仍断言可撤销。展示结果增加实体标识供具体目标核对，明确只撤销另一首；重审后原曲目的旧身份撤销必须冲突并保留引用，另一首撤销保持。保存两次失败证据；最终隐藏内部修订次数后重新构建Renderer及81项桌面复验通过。界面最终调整后发行清单发现旧摘要，重新生成并核对通过，失败记录保留。最终类型、原生、发行清单与所有报告文件摘要检查通过，截图检查完成。网络仅替换fetch边界，没有注入候选或审核凭据；数据层原文件观察为显式夹具。不能据此声称真实识别质量、全容器写回、完整恢复或硬件认证。
