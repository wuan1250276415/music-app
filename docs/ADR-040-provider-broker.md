# ADR-040：统一在线数据源访问与可取消候选预览

状态：0.35.0 源码实现，2026-10-01；类型与构建检查通过，网络／桌面运行验收留到 MVP。对应 WP08 / FR06、FR13、FR14。schema 仍为 v16，本轮未增加迁移；此前 v13–v16 迁移待集中验证。

## 实现与入口

现有 MusicBrainz 录音搜索迁入 `ProviderBroker`。Provider 描述声明能力、固定 HTTPS origin／路径、调度、响应上限和预览保存策略；库服务中的当前在线 API 请求统一经 broker，Renderer 不能传入任意 URL、HTTP 方法或凭据。当前只注册 MusicBrainz 的 recording-search，Artwork／Fingerprint／Lyrics 等能力及其他供应商尚未接入，不因支持文本搜索而假设支持图片和歌词权限。

匹配面板增加在线查询开关、正在查询／等待／退避／拒绝访问的状态、取消当前搜索、清除候选缓存和跳过缓存重搜。开关保存在已有 app_setting 中；现有用户默认保留原主动查询行为，仅用户点击搜索才访问网络，打开面板或扫描不会自动联网。联系信息仍为公开维护者邮箱或项目网址，校验 ASCII 与头部控制字符，避免无效 User-Agent。

关闭面板、打开新搜索、曲库修订、取消、停用或清除候选缓存会使旧请求和候选令牌失效。UI 用请求 ID 检查异步结果，旧请求的完成和错误不能改写新搜索状态。启停／清理入口在 UI 串行处理，避免设置返回值互相覆盖。联系信息改变也会取消旧查询并清理旧预览。清理不会删除已确认的曲库资料。

## 调度与故障处理

每个 Provider 一个串行请求通道，MusicBrainz 的实际请求启动间隔为 1100 ms，排队和在途总数最多 32。每次响应处理上限 8 秒，包含排队和退避的总请求期限 40 秒；Main IPC 期限 50 秒，超时会通知服务取消对应请求。取消排队立即移出队列，在途取消中止请求、流读取与等待，不进行自动写入。

只发送幂等 GET。408、429、500、502、503、504 和网络／响应超时可重试，最多三次尝试；每次尝试仍经过限速。Retry-After 解析秒数或 HTTP 日期，作为后续请求的最早时间，不能通过清除缓存或启停开关跳过。没有有效服务器退避时采用指数等待和少量抖动。三个连续逻辑查询耗尽重试后，增加 30–120 秒的暂停；401、403、407 不重试并暂停新访问，修改联系信息或重新启用后可重新尝试。客户端限速不能保证控制同一公网 IP 上其他应用的请求。

HTTP 重定向不自动跟随，防止固定能力地址变成任意目的地；错误响应取消读取，不把 HTML 当成元数据。响应按流计数，最多 2000000 字节，检查声明长度、JSON MIME、UTF-8 和 JSON 格式，解析出有限核心候选后丢弃原响应。缓存键使用 Provider、能力、请求和头部指纹，不在状态事件中暴露曲名、路径、联系信息或请求 URL。

生产请求使用 Electron utilityProcess 的 net.fetch，通过 Chromium 网络栈采用系统代理设置；显式省略 Cookie，并请求不使用 HTTP 缓存。框架内 broker 仍可注入 transport，便于后续契约与故障夹具。具体 PAC、认证代理、证书、实际出口、取消时序和响应流行为未在本轮运行验证。

## 缓存、预览与权限

broker 只保留解码后的搜索候选，不持久化原始 API 响应、排序分数、评级或评论。候选排序分数仅供临时显示，仍不是正确率。进程内 LRU 最多 64 个条目、16 MiB 的序列化大小估算，单条最多 4 MiB。当前本地策略 TTL 最多 60 秒，HTTP no-store／no-cache 禁止复用，max-age、Age 和 Expires 可进一步缩短；过期不作为离线结果返回。

队列中的相同查询在执行前再次查看缓存，避免重复访问。清理递增代次，旧在途结果不能重新插入缓存。缓存不写 SQLite，重启即丢失；这是当前短期搜索预览策略，不宣称所有 Provider 内容可缓存或公开导出。每个候选的确认令牌限当前曲目和请求，最多保留 400 个、10 分钟；命中缓存保持原抓取时间与原确认期限，不续期。周期清理过期数据，解析／确认时再次检查；界面也移除过期预览。

用户确认只沿用既有核心文本写入路径，逐字段检查修订和锁，并记录 ADR-037 已核实的授权快照。暂停在线查询后旧令牌无法继续确认；清除候选缓存不撤销已经确认的库内编辑。临时搜索预览权限与持久核心字段权限分开，不能把传输结果的显示能力泛化为持久化、图片缓存、歌词离线或写回许可。

这轮未完成 durable provider_cache、供应商凭据／OS 凭据库、持久观察条款撤销清理、供应商注册管理 UI、多 Provider 排序、在线多值确认或批量作业。后续源必须声明能力和权限再接入，不能复用本地或 MusicBrainz 核心文本的许可标签。
