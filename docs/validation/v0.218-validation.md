# 0.218.0 验证记录

修复真实Windows测试发现的错误87：使用完整目标路径与空RootDirectory调用FileRenameInfo，保留固定父目录句柄、独占源句柄及ReplaceIfExists=FALSE。文件提交／恢复与目录移动共用此实现。该修复来自本机实际观察，不表示相对名称形式在所有Windows环境中均不受支持。接口依据：[FILE_RENAME_INFO](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_rename_info)。

通过的检查：

- 应用构建、Main与Renderer类型检查、发行版本及分发清单检查。
- 五个标签原生辅助程序重新编译成功。
- 原生候选36项：真实FLAC提交、旧文件恢复和备份恢复；各关键阶段实际终止；Unicode与长路径；硬链接、目录跳转、独占占用、备用数据流、过期源与备份、错误确认及目标已存在等负例；共享目录重命名原语的身份保持与禁止覆盖。
