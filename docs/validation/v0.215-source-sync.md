This commit preserves the current development work. It is not a completed MVP validation or a formal release.

Changes include synchronized application/native build identifiers, recognition-record layout adjustments, and a packaged-runtime test harness with an isolated provider fixture and an owned-process cleanup helper.

Checks completed for this synchronization:

- TypeScript type checking for Main and Renderer passed.
- JavaScript, Python and PowerShell syntax checks for the new test helpers passed.

The new packaged-runtime test has not been executed for this synchronization. Its playback, provider, restart and legacy-database upgrade assertions remain unverified. Test certificates are generated only in the isolated test directory; private keys, media, local databases and built installers are excluded from this source submission.
