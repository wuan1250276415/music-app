# ADR-036：封面重读与播放详情完善

状态：0.31.0 源码实现和编译通过，2026-09-30；运行验证待 MVP。schema v13 与音频协议 v1.6 不变。对应用户封面缺失与播放详情反馈，继续使用 WP04/05/06/10 已有路径。

## 封面

- 优先读取音频文件内嵌图片，CUE 使用引用的音频文件；没有可用内嵌图片时尝试同目录 cover、folder、front，最后显示首字占位。
- 内嵌图片支持 JPEG、PNG、WebP、GIF、BMP 的签名识别；目录回退仍为 JPEG、PNG、WebP，文件名忽略大小写。单图限制从 5 MiB 提高至 16 MiB，不接受 SVG。签名校验不代表完整图像解码成功。
- Library Service 与 Renderer 使用同一缓存实现，各自限制最多 32 张成功图片、64 MiB 字符串占用估算。保留在途请求去重，空值和异常不永久保存；清除后旧请求不得重新填回缓存。预算不包含标签解析、解码图像、正在显示图片及消息传输产生的副本。
- 详情页提供“重新读取封面与歌词”，以曲目 ID 通过受信任 IPC 使当前物理文件的 Service 封面缓存失效，刷新后更新列表、播放栏及详情封面。不写回文件或联网下载图片。
- Renderer 按文件 ID 和读取代次核对图片，切换到不同文件时立即隐藏上个文件的图片。读取失败可以主动重试，超限／无法解码时仍显示占位。

## 播放详情

点击播放栏封面进入，关闭按钮或 Esc 返回。显示歌曲名称、可点击检索的歌手／专辑／风格／署名角色、封面、音质、时长、文件名及既有发行／录音资料。

本地 LRC 跟随播放时间高亮和滚动，支持点行跳转；纯文本不执行跳转。持久队列停止时也可读取当前曲目歌词，播放开始前禁用跳转。歌词用曲目 ID 和读取代次隔离，切歌、重扫或主动刷新后不会短暂显示上首歌词。LRC offset 应用于整份文件，兼容后置 offset；本地文本补充 UTF-16BE BOM 解码。读取中和缺少歌词分别提示，歌词仍仅为本地 LRC/TXT。

播放模式继续使用顺序、列表循环、单曲循环和随机开关。详情播放列表提供跳转、上移、下移与移出非当前项，全部复用现有带修订号的队列命令。重复歌曲通过 entry ID 操作，不以歌曲 ID 定位；不可用文件不能跳转，当前播放项保持在可视区域。当前项移除仍遵循现有禁止策略。

## 验证

本轮类型检查、主进程／Renderer 编译、原生宿主编译通过；没有执行单元、桌面、音频、迁移、安装包或真实用户文件验证。此前 0.29.0 的测试只证明此前版本，不能作为本轮新增行为的运行证据。最新已验证安装包仍为 0.29.0，0.31.0 仅交付源码。

MVP 集中检查：

1. FLAC/WAV/MP3/DSF 的可解析内嵌封面、CUE 共用封面，以及内嵌与目录图片同时存在的优先级；大于 5 MiB 且不超过 16 MiB 的图片、超限和损坏图片。
2. Cover.PNG 等目录名称、GIF/BMP 内嵌图片、离线目录与缺图占位；读取失败后补图与主动重读，无需重新导入。
3. 多次快速切歌、重扫、延迟返回和缓存清理期间的旧请求，确认新曲目不显示旧封面或歌词；停止与重启后的当前队列歌词。
4. 全部播放模式、重复曲目重排／移出、不可用文件、队列保存与修订冲突；当前项滚动和最小窗口布局。
5. LRC 后置正负 offset、UTF-8／UTF-16LE／UTF-16BE／GB18030、点击跳转、自动滚动与减少动画设置。

ASIO 实机验证按用户要求继续暂停。字段来源与锁定草稿未接入 schema 或 API，待恢复 WP03/WP08 后独立完成；本批次不代表完整工作包或 MVP 验收。
