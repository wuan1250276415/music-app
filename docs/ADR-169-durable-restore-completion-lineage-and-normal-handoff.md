# ADR-169 恢复完成终态、历史关系与普通服务交接

状态：源码实现，运行验收待 MVP。日期：2026-10-10。版本：0.163.0。

## 决定

ADR-168 已经释放普通维护，但独立 Main、播放和历史屏障仍暂停操作。本批在私有恢复主流程追加不可变 completed 终态，并在实际持久读回和独立启动准入核对后交还普通服务、解除屏障。它不代表整库恢复已经经过运行验收，也不开放用户 apply 入口。

completed 绑定原恢复/完成 UUID、candidate/original 角色、实际目标与原曲库目录身份、来源 UUID、原完成决策和最终资源证明摘要、final-resources-held 实际规范记录 SHA。inputHeldAtCommit 明确为 true，restartPolicy 为 normal-existing-library；不能伪称持久提交时用户交互已经开放。全局链严格拒绝终态后的任何追加，最长 45/48 条。

## 多次恢复和原库回滚

只核对每项历史完成记录的目标是否仍位于 live，会在第二次恢复后错误阻止正常启动。完成证书因此显式记录前驱的事务/完成 UUID、完成记录 SHA 和目录身份。来源必须是之前完成链的末端；没有前驱只允许唯一链起点。重复身份、缺失前驱、摘要不同、分支、环和未连接事务均拒绝。

original 回滚完成可能保持相同目录身份。显式前驱仍形成先后关系，不以相同目录误判循环。候选完成把原目录保留在本事务 original-library；original 完成把未选候选保留在 candidate/library 或 retired-candidate。后续恢复可把前一末端移入新的原库保留槽，所有已知目录都由全局链独立映射到实际位置。

启动核对重新读取原全局规范字节/摘要链、原移动正常退出链和 pending 归档，再核对全部保留槽与最终 live。旧的未切换注册只有在没有任何原生/全局移动、没有原库/退役候选槽、原目录属于已确认历史关系时才可保留；其任务和快照不重放。未完成移动、未知注册、冲突位置或未归属原目录继续阻止启动。原局部移动观察可以因已完成后继而不再等于当年的位置，只能由明确的完整历史关系解释。

每项全局链串行读取，快照仅保留轻量目录/完成关系，不同时保存 64 项完整历史载荷。关系核对后再次读取每项规范链并比较实际末端 SHA、全部槽和根条目；不能只依赖目录时间戳。当前流程取消和所有者核对穿过这些等待，取消不能被当作完成证明。

## 提交和重新启动准入

Main 在三项独立屏障内核对实际同一 Library、原新文档/App/最终证明和已退出准备进程，再准备完成证书及目录关系投影。投影只供提交前核对，不能作为启动权限。实际 completed 写入并读回后，Main 重新读取真正落盘的完成链和保留目录，确认最终准入的完成 UUID、实际 completed 记录 SHA、目录和来源都与原证书一致，才进入同步交接。

后续正常启动取得完成链末端的准入，不自动选库、回滚、替换、清理或重放旧任务。Library 在普通仓储/迁移/任务构建前，确认目标是已存在的固定普通目录和单链接 library.db，先用独立只读 SQLite 连接核对来源 UUID、受支持版本、完整性和外键。缺失或不同数据库禁止创建空库。普通连接构建后再次核对来源和目录，真实进程就绪回执必须绑定该原准入摘要/身份。Main 仍核对实际 PID/当前构建；正常迁移和现有故障整理遵守原流程。

只读预查是 Library 内的源码行为，不是 Main 启动目录检查中的数据库打开。WAL 内容会继续正常变化，不按冻结 DELETE 清单比较当前库，也不声称完成证书认证后续所有数据变化。

## 当前进程同步交接

最终释放前所有前提在占用内统一核对。此后没有 await：清除 final/App/Renderer 原监听和挑战，结束原准备协调器占用；同一实际 Library 继续运行，清除 bootOperationId 及恢复准备/释放归属，交还普通进程监督。旧恢复取消和迟到退出不能杀死已经交接的普通服务。

历史恢复正常观察和保存计时器，播放解除完成屏障但保持停止，Main 最后解除独立输入屏障并按原决策刷新后台界面。只有实际输入可用后才发布 checked/held=false，并发送 thaw。Renderer 不再允许孤立 thaw 解开仍 held 的受保护 storage；实际非占用状态负责解除惯性限制。恢复完成提示与普通备份记录分开，停止按钮路由原整库切换操作。

Cutover 原操作、结果和各阶段 Promise 在成功后清理，保留一项原完成回执供重复查询。下一次备份恢复可建立新所有者。完成持久后、交接前取消或失败仍保留当前屏障和资料；下一次启动只信实际完整完成链。后台界面刷新失败报告诊断，不倒推已经持久的完成决定。

## 限制和后续工作

私有成功/原库回滚流程源码已接到 completed；完整用户恢复应用、未决/缺失回执/不确定移动重启核对和操作界面、原文导出复审与授权重新提交、完整领域/迁移校验和、实际配额和清理仍须实现。保留记录依赖原来源、归档和目录继续存在；本批不删除这些资料或放宽未知数据的准入。

schema68/音频IPC1.22/媒体10保持，全部 FR01–FR14、WP01–WP11、G1–G5、AC01–AC19 保留。源码/编译检查不能证明真实恢复、多次恢复、原库回滚、真实 SQLite/WAL、重启、异常窗口、音频或图片效果。按用户要求运行与故障演练留到 MVP，ASIO 实机验证搁置，真实缺图尚待复现，无新安装包。
