# ADR-150：主窗口资源维护暂停与待保存播放历史

状态：0.144.0 源码实现；类型与编译检查，不是运行验收。

## 问题与范围

ADR-149 的 Library 停止不能代替 Main 的停止。播放宿主、设备枚举、能力查询、ASIO 面板、设备通知、系统媒体面板、Main 的资料读取、设置保存及播放历史都可能仍在工作。已有查询超时和面板 completion 可以先于实际进程 close，因此不能据此允许曲库快照。

本次增加内部 Main 资源组与各参与组件的可恢复维护暂停。没有新增数据库迁移、音频或媒体协议，也没有新增 Renderer 备份执行入口。完整备份需要后续调用方先冻结 Renderer 待核对资料，再调用 Main 资源组、Library 私有维护及快照；本次没有调用这些维护函数。

## 所有权与普通请求

`MaintenanceHold` 使用经验证的 UUID、唯一 owner、一次 drain Promise 和 frozen 标志。同 owner 共享原工作，另一 owner 被拒绝；失败保留 held，不能直接释放。新请求和仍未执行的请求在入口及执行微任务再次检查。已经执行的请求保留至 Promise 实际结束，维护等待集合为空。

Main 的普通 IPC 已统一经主窗口／主 frame 校验及资源组请求登记。桌面播放、上一首、下一首、停止及音频重新打开增加相同维护约束。托盘、外部文件和系统媒体资源也分别登记自己的任务；暂停期间拒绝新设置、队列和资料操作。后续备份状态、冻结回执及取消需要专门且同样可信的接口，不能经普通入口绕开维护。

资源组同时登记播放输出及 13 项资源的暂停，等待全部结果后再确认普通 Main 请求结束。失败消息保留组件名称。只有全体停止后才暂停并落盘播放历史；此时 Library 仍须接受原历史检查点。

## 各组件停止证据

- 播放协调器停止输出、递增原操作代次，等待已有串行链及 AudioController 输出／DSD 分析释放，再确认输出已释放。原输出释放超时仍是失败，不能作为已退出。停止不自动恢复音乐；保存队列保持原有记录。
- WASAPI 枚举／能力、ASIO 查询／面板、设备通知和系统媒体均先登记 close 监听，再请求停止；只能在实际 close 及组件原 owner 清理后继续。没有将 deadline、kill 返回值、RPC 拒绝或面板 completion 当作 close。没有假定驱动硬件结果已认证。
- 设备通知保留维护前是否处于连接中／已连接及已有系统休眠状态。只有明确允许、原先启用且未退出／未休眠时才尝试重连；失败状态不自动重试启动。
- 系统媒体登记完整歌曲资料、封面及控制 Promise 链，撤下待启动资料，等待实际进程退出、原设置和所有链结束。暂停阻止媒体键备用路由重新注册；媒体键等待原设置结束并再次解绑，解绑未知则失败。
- 历史导出请求停止并等待原任务及实际 utilityProcess owner 退出。已经进入发布的原任务允许完成，维护必须等待；不把取消响应等同于进程退出。
- 外观暂停缩放计时，等待原设置，并在 Library 仍可用时显式保存已经排队的缩放意图。结果未确认则拒绝备份。
- 窗口位置暂停自动保存，等待原设置／写入，捕获并保存当前位置；仍有未确认保存则拒绝备份。退出期间不能再通过维护开始备份。
- 外部文件保留 Inbox 和原扫描请求，停止新接收／刷新／提交／播放，等待原任务及检查 lane，失效原播放代次。没有清理未决扫描身份。
- 封面资源登记读取及租约 Promise，保留完整清理工作集合。维护中的窗口文档 reset 只登记延后意图，在明确释放后再清理租约；不在快照过程中触发新的曲库清理。
- 窗口关闭政策和托盘设置登记完整 Promise。维护中的普通关闭保持窗口可达，明确退出仍沿既有退出清理。维护时禁用托盘播放与设置，结束后刷新菜单。

资源 end 只能使用同 owner 且已经 frozen 的组件。资源组固定首次释放意图及 Promise，等资源释放后再释放播放和总入口。调用方必须先确认 Library 已明确 released，再恢复 Main；重新连接不等于音乐自动继续。资源组尚无持久回执或跨进程重启恢复。

## Main 播放历史

历史开始维护前输出观察必须已经停止。维护清除基线、暂停 15 秒计时器及新观察，等待原保存、按原身份尝试保存并 `sync` 落盘所有剩余检查点。Library 保存失败可以保留待保存条目，但文件落盘失败必须拒绝备份；不能把仅存在于 Main 内存的数据当作已经包含在快照中。

待保存文件无法核对、Recorder 尚未初始化或已退出时，备份拒绝开始，原文件保留。维护中退出不再启动新的 history flush，避免静止快照期间改写待保存文件；已有 flush 由原 drain 等待。结束后恢复周期重试，原检查点身份和回执语义不变。

## 尚未接通与验收

Renderer 的 localStorage 冻结与可信挑战回执、Main／Library 联合维护编排、备份 worker 监督／取消／退出、持久操作回执、选择保存与正式文件发布、恢复应用／回滚和 UI 尚未接通。内部资源组不能单独授权曲库捕获，不能宣称完整备份可用。

本轮不运行应用、SQL、媒体、进程、维护、测试或驱动。MVP 必须验证设备实际退出与不能退出、原设置对话框／写入、托盘／媒体键控制、旧队列和关闭／休眠交错、历史保存失败及原文件损坏、租约文档变化、释放失败与真实备份字节。等待原生 close 没有超时释放退路；未来 UI 必须保留任务占用并展示等待，不能在超时后发布或恢复源操作。
