# ADR-086：系统托盘与窗口关闭策略

日期：2026-10-02；源码 0.81.0；音频 IPC 1.19／schema v38／媒体协议 6 不变。

## 问题与范围

架构 §16 要求将关闭窗口与退出应用区分，首次关闭说明后台行为并允许设置。此前 window-all-closed 总会退出，没有后台播放的托盘入口。本批增加 Main 所有的 DesktopLifecycle、首次关闭选择、记住选择和设置入口；后台不自动发出播放／恢复命令。

默认 closeBehavior=ask，首次关闭显示“后台运行／退出应用／取消”，默认选后台，但只在用户实际点击后隐藏。勾选“记住这次选择”才持久化 tray 或 quit；未勾选继续每次询问。侧栏和托盘的“窗口与托盘”可改为 ask／tray／quit，设置只影响后续关闭，不立即改变窗口或播放。

## 托盘与窗口

Main 用 first-party 32×32 单色波形 bitmap 创建托盘，不依赖安装路径、远程图片或额外资源。菜单提供打开音乐库、播放／继续或暂停、上一首、下一首、停止、窗口设置和退出。曲目跳转使用现有队列修订命令；停止保留高优先级，菜单状态依据实际 PlaybackState／QueueState。状态身份未改变时不随高频位置通知重建菜单。

双击托盘或第二实例启动恢复隐藏／最小化窗口并聚焦；窗口已销毁时可重新创建。初始化未完成或正在退出时不提前创建窗口。hide／show 沿用已有分析可见性控制，后台保留音频和库任务，视觉分析按现有规则停止。后台隐藏不释放整个窗口的媒体资源租约；窗口关闭／页面重载的现有释放逻辑保留，完整后台缓存生命周期仍需继续完善。

托盘创建失败不静默隐藏窗口；关闭时提示退出或取消，不能保存新 tray 策略。托盘后续菜单更新失败时恢复主窗口并停用托盘，保持应用可达。是否真正创建／呈现托盘、不同 DPI 的图标和系统壳层变化都需实机验证，编译不证明系统托盘可见。

## 保存与退出

DesktopPreference v1 三字段 version／revision／closeBehavior，规范字段及安全整数修订校验。使用已有 app_setting 的 desktop_preference 键，Library Service 单写入事务核对完整旧值／修订后保存新值；相同新值回读可确认重试，不增加 schema。不是跨会话 commandId 回执表，也不覆盖其他配置。

Main 在记住选择的保存结果确认后才隐藏／退出；保存调用失败则回读当前值，仅当完整新值一致时视作保存成功，否则保留窗口并报错。设置过程与 close 弹窗共用 busy 防重入。未知保存不猜测成功，后续设置先重新读取。Renderer 仅能请求受可信窗口检查的原生设置对话框，不能提交任意退出／隐藏或数据库参数。

明确“退出应用”经 app.quit／before-quit 标记 quitting、销毁托盘、停止音频、关闭设备与能力／通知组件并结束 Library Service；退出中的 close 不再被后台策略阻止。音频与媒体 Job 的既有父退出守护继续存在。Windows query-session-end 绕过后台关闭选择发起退出，避免将注销／关机误处理为隐藏；系统通知／退出时序仍待真实运行验收。

正常后台关闭使用 hide，window-all-closed 仅在退出或没有托盘时退出；意外窗口销毁有托盘时仍可重建。应用启动、隐藏、恢复、设置保存和设备重新连接均不自动起播；只有明确菜单播放／用户界面控制才发出播放命令。

## 验证与后续

版本身份与发行摘要更新；内嵌封面、播放详情、资料检索、滚动歌词、模式／队列和 0.80 音量重规划保留。没有新增迁移或安装包，最新已验证安装包仍 0.29.0。只做类型、Main／Renderer／Native 编译、发行／分发清单、维护脚本语法和源码归档 CRC；最终结果见实施状态。按用户要求不执行 UI／音乐／进程／SQL／迁移／硬件／网络或安装验证，集中到 MVP。

MVP 覆盖首次关闭三个选择／复选框、重启持久策略、完整值 CAS／保存失败及丢回执回读、重复关闭／设置重入、后台播放与任务、隐藏分析停止、托盘菜单状态和修订冲突、窗口销毁重建／第二实例恢复、不同 DPI／托盘初始化和运行失败、app.quit 清理／注销关机／初始化退出交错。睡眠唤醒重新协商、暂停超时释放、媒体快捷键、完整服务恢复／诊断／签名更新和 macOS／Linux 后端仍待实现或验收；完整 FR01–FR14／WP01–WP11／G1–G5／AC01–AC19 保留，ASIO 实机验证搁置。
