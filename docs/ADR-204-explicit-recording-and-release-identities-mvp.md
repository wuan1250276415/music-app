# ADR-204：录音与发行身份分别确认 MVP

日期2026-10-13；源码0.198.0，schema74／媒体15／音频IPC1.23保持。完整FR01–14／WP01–11／G1–5／AC01–19继续，只有ASIO实机验证暂停。

## 用户流程与范围

整专辑审核选择发行曲目后，新增“审核录音与发行身份”。即使没有勾选文本差异，也能读取身份目标。录音与发行版分别列出原有外部引用、拟确认的MusicBrainz标识、来源标题／网页、曲目对应以及全部关联条目／发行版范围。录音标题使用返回的录音层标题，发行轨目的显示标题仍独立保留。

确认方式默认“暂不确认”。可以明确追加标识并保留已有引用，或只替换该实体的MusicBrainz标识，其他Provider引用保留。涉及录音和发行时分别确认影响范围。录音可能覆盖多张本地发行版，不能只看本次专辑的一份文件；对应关系和完整影响范围均显示。

没有完成全部本地发行曲目对应，或发行曲目表不完整／包含未审核隐藏及数据轨时，发行身份不能确认，已验证的普通曲目录音可独立确认。部分本地专辑与完整远端发行版数量不同继续警告，由用户核对具体版本。同一远端标识已属于其他本地实体，或被多个不同本地身份同时声明时，阻止自动确认，先使用现有本地关联／编辑流程解决；不自动合并本地主键。

## 权限与事务

身份来源来自已通过Provider校验的发行上下文及用户明确选择的轨目。请求只提交短期审核凭据、条目／轨目对应、服务器发行的目标键、追加或替换方式和两种范围确认，不接受调用者提供的新标识、实体目标或来源URL。Main和Service均校验窄请求。

身份预览绑定原候选和整专辑快照；正式保存在同一SQLite事务内重新检查候选、期限、成员、字段／录音引用快照、每个完整实体引用修订以及外部标识归属。所有目标先验证，全部成功后写入；后段写入失败会撤回先前引用、审计与聚合命令凭据。新保存继续遵守MusicBrainz核心文本保留策略。

本地主键、PlayableItem／Recording／ReleaseTrack／Release关联、文本字段、文件、歌单和收藏保留，只更新所选外部引用。每个实体产生独立审计，记录来源发行、时间、核心授权快照ID、确认方式及核对位置；一份聚合回执用于重试。已成功请求先检查回执，重启、离线或预览销毁后核对请求不会重复保存。

追加别名时，后续文本审核可使用任一已确认录音标识，而不是只比较排序最前的一条。引用变化的单调修订继续使旧文本或身份审核失效，需要重新读取。身份确认不自动修改文本，也不自动执行先前计划。

## 撤销与来源记录

新增来源保存设置中的身份确认计数、待撤销计数和分页记录。每个确认可单独读取撤销预览并核对旧／当前引用及影响范围；默认不勾选。撤销一个发行身份保留其他录音确认。后续引用编辑、实体资料或成员改变导致冲突时保留当前状态。撤销使用已有实体引用事务和单调修订，审计保留；不是彻底删除来源记录。

身份审核最多4份，合计16MiB序列化快照预算，期限继承来源。无后续访问也主动到期清理，关闭曲库和暂停／清除在线状态时释放预览；这不是总进程内存达标证明。身份审计复用entity_reference_change与user_command_receipt，SQL结构不变，没有宣称数据库层全部历史表新增了不可改写触发器。

## 尚待完成

本轮是用户明确确认的外部引用接受，不是自动判断录音真实性、外部实体自动合并或完整ReleaseTrack／ReleaseGroup绑定。整专辑召回与标注真值集、隐藏／数据轨完整对应、ISRC／指纹、多来源、更多字段和批量完整多人身份／角色、完整来源清除／写回／恢复／旧计划跨版本兼容，以及规模性能、8小时运行、设备和发布门禁继续。最新内部试用安装包仍0.190.0，完整V1未交付。
