# ADR-136 曲库与分类共用组合筛选

日期：2026-10-06。状态：0.130.0 源码实施，SQL／迁移、真值、性能和界面验收留到 MVP。对应架构 §10.1／10.2、FR05、WP05 与 AC09；完整检索功能尚未验收。

## 查询契约

ListRequest、BrowseQuery 和 CatalogBrowseQuery 增加可选 MusicFilters。Shared 严格校验未知字段、枚举、整数区间、布尔值、重复值和容量；身份和集合排序后形成稳定查询。未选条件省略，显式 false 保留。不同条件组按 AND 组合，艺人和风格组可以选择 any／all。

艺人使用最多16个已存在的身份 ID，可选择曲目艺人、专辑艺人、作曲、指挥和乐团。沿用人工身份关联及已有录音署名有效性规则，专辑艺人取发行署名。风格最多16项，可纳入未归档下级，匹配条目或发行的风格关联。所有 ID 和数字均作为 SQL 参数；Renderer 不提交 SQL，也不读取全库后自行过滤。

发行年份取 Release.date，接受有效 YYYY、YYYY-MM 或 YYYY-MM-DD，验证月份、日及闰年。未知／不合法日期不命中年份区间，不猜测录音年份；完整日期精度排序另行实施。

音频条件取 MediaFile 记录的源参数。编码族包含 FLAC、PCM、ALAC、MP3、AAC、Vorbis、Opus、DSD 和未知；保守识别锁定解析器的明确编码名称，不根据任意扩展名判断质量。DSF 解析器没有独立 codec 时，仅在记录采样率且 bits=1 的情况下识别 DSD；DFF 原始 DSD 同样需要明确特征，DST／未识别／混合编码归入未知。无损组包括 FLAC、PCM、ALAC、DSD；有损组包括明确识别的 MP3、AAC、Vorbis、Opus，其他不自动归类。

PCM 采样率区间为 1–1536000 Hz，位深可选8／16／20／24／32／64；只匹配明确识别的非 DSD 编码。DSD 倍率可选64／128／256／512，对应源采样率44100×倍率。位深缺失不补值，PCM 与 DSD 条件同时设置取交集，可能没有结果。条件不证明解码认证、输出格式或设备能力。

收藏支持已收藏／未收藏，评分支持至少1–5星；缺失个人状态按未收藏／0星处理。可用性与现有曲目规则一致：可见、正常收录、文件在线、根目录未离线且 CUE 无待解释请求；反向条件包括这些不可用原因。普通分类继续只展示可见且正常收录项目，个人收藏及歌单保留原有历史条目规则，因此“不可用”不等于所有隐藏条目。

## 共用执行与快照

Library.list 在原视图、角色、风格及目录条件之后、直接／拼音／英文词召回之前应用 musicFilterPlan。总数、分页、版本折叠和按查询播放使用同一计划；纠错的300条目上限在组合过滤后执行，歌单的重复 entry 与原始顺序保持。

CatalogBrowser 通过 Library 提供的参数化条目子查询限制 members，随后再计算歌手、发行和专辑概念的曲目／文件／发行／碟数、格式及代表封面。避免显示未经组合筛选的数量或封面。不物化任意规模 ID 数组到 Renderer。独立资料详情仍展示完整实体资料，风格选择导航仍展示全曲库风格。

规范化条件纳入已有查询快照；曲库、个人状态和关联修订沿用 BrowseClock。旧分页或旧按查询播放请求不可跨条件继续使用。艺人选择器每页60项，以同一查询快照翻页；目录变更时提示刷新，已选身份保留。200ms防抖、请求代次与卸载标记隔离迟到结果；名称缓存只保留当前页和最多16个已选身份。

## 界面

曲库工具栏增加“组合筛选”、条件组数量和清除入口。弹窗按需加载，支持艺人角色及分页搜索、层级风格、年份范围、编码与质量、PCM 源参数、DSD 倍率、个人状态；应用前严格校验，取消保留原条件。焦点进入／循环、Esc关闭、选项说明和窄窗口样式沿用现有界面规则。条件是当前应用会话状态，未新增持久筛选预设或自动歌单。

内嵌封面优先、播放栏封面进入详情、可点击资料检索、滚动歌词、模式及播放列表保留。实际缺图歌曲尚未复现，详情交互尚未运行验证；本批组合筛选不代替这些验收。

## 版本与验证边界

schema60在旧库迁移前生成 pre-v60 快照，事务新增发行日期和源音频参数两个普通索引，再提高 user_version。不修改标签／音乐文件，不增加依赖自定义函数的表达式索引。历史退回 fixture 先移除这两个索引，四处当前版本断言同步；本批没有执行 SQL 或迁移。

Main／Renderer类型检查及构建通过（132模块，主块382.64kB／gzip120.06kB）；全部生产原生组件及既有金样编译通过，未运行。41个CommonJS语法、发行生成文件及分发清单（18个npm运行依赖／5个vendored组件）静态核对通过。来源清单新增契约、查询、弹窗及样式摘要。源码包为 outputs/aural-prototype-v0.130-source.zip；归档检查仅验证文件完整性。

音频IPC1.22、媒体10、暂存1、核对1／2／3、恢复2及历史1不变。ASIO实机搁置，最新已验证安装包仍0.29.0；没有生成新安装包或执行应用、测试、真实媒体、驱动及硬件操作。

MVP需验证艺人身份与各角色 any／all、风格交并集及下级／归档、部分日期及非法日历、未知编码、PCM／DSD参数交集、缺失位深、收藏false和评分下限、离线／隐藏／忽略／CUE待解释、文字／拼音／错拼过滤、歌单重复、版本折叠、分类数量及代表封面、条件切换旧快照拒绝、选择器迟到请求与翻页目录变化、旧库升级及十万条目查询计划和延迟。筛选预设、动态歌单、完整繁简及自然序／相关度、后台分类投影、跨平台和全架构其余工作继续。
