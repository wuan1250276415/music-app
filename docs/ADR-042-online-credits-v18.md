# ADR-042：在线主署名审核与当次署名名称

状态：0.37.0 源码实现；2026-10-01。对应 WP03/WP08，schema v18，音频协议 v1.6 不变。当前仅编译与静态清单检查，不代表在线匹配、迁移或 MVP 验收。

## 主署名与身份

- 用户选定 MusicBrainz 候选后，主动读取录音及可选具体发行版的完整主署名。请求沿用统一 broker、固定 HTTPS 能力路径、限速、大小限制、系统代理、取消和短期缓存。两次读取共享 40 秒期限；校验返回实体 ID、成员数量、艺人 ID、文字和连接词，不把不完整返回当成可确认署名。
- schema v18 为 `artist_credit_member` 增加可空 `credited_name`。艺人资料名与当次署名名分开：展示保留作品上的署名，身份检索仍按稳定本地艺人 ID。允许主署名末尾连接词；资料编辑、发行复制、来源记录与撤销保留该值。
- 已有库升级前保存一致备份；新列在独立事务内安装。旧迁移阶段和旧审计记录保持不含空署名字段的兼容形状。v13–v18 尚未运行迁移验证。
- 只按已绑定的 MusicBrainz 艺人 ID 复用本地身份，不按同名自动合并，也不覆盖已有全局艺人资料。缺少绑定时创建独立艺人资料及来源引用；引用归属冲突、归档身份或预览后身份变化会拒绝提交。

## 预览与确认

- 可选择当前歌曲、共享录音或发行版专辑艺人中的一个范围；先显示当前归属、影响文件数及锁定状态。每次最多 64 个成员、影响 5000 个文件。更大范围等待后台批量任务。
- 默认保留当前成员，不自动选中候选。用户明确选择候选、保留或移除本地成员、指定角色、调整顺序及连接词，并确认预览。候选录音主署名不推断演唱、作曲、指挥或乐团角色；发行版范围使用专辑艺人角色。
- 原始来源观察保存采用成员的原署名、连接词、来源链接与抓取时间，不声称来源提供了用户指定的角色；用户决定的角色、顺序和本地成员组合另存人工观察。应用投影与两份来源记录在一个写事务内保存。
- 保留已确认结构化署名时，旧单值在线“歌手”确认入口禁用，后端同样拒绝该字段覆盖，避免界面宣称修改但人工署名仍生效。
- 提交校验集合修订、依赖指纹、成员身份、归属和锁；提交时刷新受影响条目与索引。扫描继续保护人工结果。界面在读取期间或之后检测曲库变化；取消、关闭、网络关闭和过期候选不能提交新变更。

## 回执、来源和撤销

- 命令 ID、完整参数摘要及结果写入既有持久回执。同一请求重试先读取回执，成功结果可在候选已过期或在线查询已关闭时重放；同 ID 不同参数拒绝。
- 审计记录采用的来源、创建的艺人身份、抓取时间和确认期限。曲库修订记录支持完整集合的补偿撤销，依赖变化后要求处理冲突。
- 撤销恢复此前集合选择和绑定，但保留新增艺人身份、引用及不可变来源观察；身份清理属于独立整理操作。当前没有逐成员或逐字段部分冲突撤销。
- 短期查询响应仍仅在内存保留；确认路径只保存此前白名单中的 MusicBrainz 核心文本，沿用 `musicbrainz-core-cc0-2026-09-30` 权限快照。主署名与用户角色决定分别记录来源权限。未接入在线风格、标签、评分、指纹或封面下载，不扩展核心数据授权范围。
- 本轮官方文档检索核对主署名结构；数据许可正文访问返回 429，没有把旧权限快照表述为本轮重新完成完整条款核验。持久 Provider 保留策略、条款撤销清理、凭据库及其他 Provider 仍待开发。

官方依据：[Artist Credits](https://musicbrainz.org/doc/Artist_Credits)、[API examples](https://musicbrainz.org/doc/MusicBrainz_API/Examples)、[数据库结构](https://musicbrainz.org/doc/MusicBrainz_Database/Schema)、[数据许可](https://musicbrainz.org/doc/About/Data_License)。主署名名称与艺人身份名可不同，连接词可位于尾部；关系角色须另行处理。
