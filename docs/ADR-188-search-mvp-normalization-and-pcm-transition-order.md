# ADR-188：检索 MVP、繁简派生索引与 PCM 状态切换顺序

日期：2026-10-11。源码版本 0.182.0；schema72、音频 IPC1.23、媒体协议14保持。完整 FR01–FR14、WP01–WP11、G1–G5、AC01–AC19范围继续，只有 ASIO 实机验证暂停。本轮没有生成新安装包。

## 问题与决定

实际导入的 FLAC 真值集发现，“后来”“刘若英”无法检索原标签“後來”“劉若英”。采用锁定的 `opencc-js@1.4.2`、通用 t→cn 转换生成检索副本，与原文一同进入 FTS及中文短字索引；保留原文件标签、显示名称、实体身份和路径。查询同时使用原文与规范化变体，支持已有中文、拼音／首字母、重音和有界英文错拼逻辑。原文精确匹配优先；规范化等价标题优先于仅标题前缀。该转换不代表任意地区语义同义词或完整艺人别名功能。

索引算法完整描述纳入 SHA-256，以 `aural-search-v3:` 加摘要作为传输标识。原拼接版本字符串超过共享状态契约128字符上限，导致索引已完成却显示状态失败；摘要保留完整算法版本身份，并继续遵守原契约。算法变化沿用64项分批重建，事务内一起更新原文／规范化索引和拼音、拼写、排序字段；重建期间原文仍可检索。未修改数据库schema或放宽状态校验。

FLAC/CUE 回归还发现，暂停／继续命令被接收后，音频端可能仍在切换；紧接着定位会被拒绝为 seek in progress。Main定位现在等待本会话实际暂停／播放完成事件，等待后重新核对会话和条目。原生 WASAPI 将命令受理和状态发布按同一控制锁排序，在发布完成事件前清除过渡标志；超时、失败和停止清理等待者。没有执行 ASIO硬件验证。

## 已执行的有限验证

- 9首真实生成且保留有效音频数据的FLAC，28项预期结果集合／排名：中文短字、拼音／首字母、繁简双向、重音、英文错拼、全角输入、字面通配符、引用输入负例，以及歌手／专辑／风格限定查询。全部通过。
- 在当前实际曲库构造旧v2派生索引状态，重开、观察重建、保持原标签并完成繁简检索。此为受控派生索引升级验证，不是全部旧schema或历史备份升级认证。
- 实际改写标签并重扫，旧词撤出、新词及风格进入；文件缺失保留可检索的不可用记录，恢复后条目ID、首次加入时间、收藏和评分保持；重新打开数据库通过。未模拟NAS或整个根目录掉线。
- 实际Electron搜索与风格筛选、连续输入最终结果、索引提示收尾通过。连续输入最终正确不证明所有乱序响应及取消情形。
- MP3/WAV播放详情回归通过；FLAC16/24、封面像素、CUE前间隙、歌词时间基与历史回归通过，新增“立即暂停／继续后定位”完成状态和位置核对通过。输出为静音WASAPI共享模式，不作设备位完美声明。
- 最终Main／Renderer类型检查与构建、全部生产原生初次构建以及修复后的音频宿主重建退出0。本轮既有金样随构建编译，未重新运行全部金样。
