# ADR-120：FLAC 文件标签桌面预览与持久待写入任务

日期：2026-10-03。状态：0.114.0 源码实现；Main／Renderer 类型与构建（123模块）、音频／波形／DSD分析／媒体监督／凭据／系统媒体及既有金样编译、41个CommonJS语法和发行／分发清单静态检查通过。WP09／FR12／AC12 仍未验收。

在 ADR-119 的只读 FLAC 适配器、暂存核心和阶段日志之上，接通 Library Service → Main → preload → Renderer 的预览及任务准备入口。格式认证目录继续默认为空；不发布原文件替换 API。

## 桌面流程

歌曲元数据面板增加「文件标签预览」，采用延迟加载的对话框。支持歌曲名称、歌手、专辑、专辑歌手、风格、发行日期、曲序、碟序、备注、版权声明、ISRC。手工输入每行一个值，保留空格；空输入不是清空，必须显式选择清空。只有明确勾选的字段进入计划。

手工字段需要单独确认可用于本地标签；不默认拷贝在线来源。曲库模式目前只映射 title／artist／album 标量，且已选择观察值必须精确等于当前曲库值、来源策略必须允许 persist／writeback、未过期，并满足 MusicBrainz 已审核保存设置。完整集合、多角色、多来源权限映射留给后续批次；不拆分拼接的歌手字符串，不扩大既有 local-private-v1 权利。

逐字段展示实际 FLAC 原标签与目标值，显示保留的内嵌图片块数量。预览不读取音频载荷，也不证明音频完整性。保存按钮为「保存待写入任务」，明确提示音乐文件尚未修改；没有「立即写入」或可绕过认证的按钮。

## 来源与修订绑定

请求只接受曲库曲目身份和审核字段，Renderer 不能指定文件路径。禁止离线／非 active 曲目、CUE 虚拟轨、与任何 CUE 曲目共享的镜像（含归档轨）、非 .flac 文件、未建立扫描观察的文件；实际格式由媒体子进程再次解析，内部 CUESHEET 同样拒绝。

预览绑定文件身份、完整曲库／来源选择快照、权限指纹、内容修订与文件属性观察。Library 校验授权目录、实际目录范围、既有目录锚点（如已保存）和处理前后的目录设备／文件身份、常规文件／非符号链接／单链接、扫描属性，并在受监督只读解析前后和保存前复核。属性观察不是完整文件哈希；实际暂存仍须 ADR-119 的全文件与音频载荷复核、原生独占句柄及最终替换前检查。

预览最多 8 个并发请求、64 个短期令牌／8MiB 缓存，令牌有效 5 分钟；等待上限 55 秒并支持取消，媒体进程仍沿用既有监督预算。Main 期限 60 秒，超时请求取消预览。保存操作先查询原 commandId 的不可变回执，之后才检查过期令牌或当前资料；未知保存结果沿用原操作 ID 重试。源码中的 UI 会冻结未知保存操作的编辑内容；应用退出后任务可从持久列表发现，尚未实现重启后自动恢复 UI 的未确认请求。

## schema47 与任务边界

迁移源码在原 schema46 之后先保留 .pre-v47 数据库快照，再建立任务、不可变操作回执、单文件内容／租约修订表。迁移和 SQL 尚未执行。已有历史迁移夹具按 schema47 更新期望值和逐级回退源码，未增加或运行小功能测试。

任务冻结原始预览、字段来源确认、权利指纹、授权目录和文件属性；初始 prepared、revision0，不持有写入租约，不阻塞正常播放。按时间／UUID 分页，8 条一页。prepared 可按 revision CAS 取消；重复原取消操作返回原结果。4096 个任务／512MiB、65536 个回执／256MiB 上限保留原历史，不静默删除或覆盖。

扫描发布时拒绝覆盖 held／recovery 文件，并仅在扫描属性证据变化时递增内容修订。内部租约接口校验可信格式认证、冻结资料及内容修订，租约修订单调递增，任务／文件身份受约束；默认空目录使租约获取不开放。启动将未知 running 任务和 held 租约保留为 recovery_required／recovery，不凭超时释放。

新播放曲目解析、媒体读取和扫描发布已增加租约状态拒绝检查，但这只是协调底座：正在播放的宿主与分析副本释放、读租约登记、后台扫描在读取前的协调、实际阶段日志与任务状态联动、认证执行计划、完成／恢复后租约释放仍待长任务写入流程接通。内部 acquire 没有当前调用者；不能将本批描述为已完成完整读写协调。
